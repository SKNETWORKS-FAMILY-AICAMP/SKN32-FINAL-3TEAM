# 서비스시험 — 명령 하나로 시험 · 로그 · 보고서

> **담당** 소성민 · **작성** 2026-10-22
> 떠 있는 서비스(기본 `https://copylane.site`)를 **밖에서 API 로 불러** 확인한다. 화면 캡처는 하지 않고 요청마다 로그를 남긴다.
> 저장소의 `tests/`(서버 없이 코드를 재는 단위 시험)와 따로 돈다 — 이 폴더의 `pytest.ini` 가 그 설정을 막는다.

## 실행 (내 PC · 저장소 루트 · PyCharm 터미널)

```powershell
uv run python docs/ssm/배포/서비스시험/run.py
```

- 실행하면 **시험 계정(일반 회원) 이메일 · 비밀번호**를 묻는다. 비밀번호는 화면에 안 보인다. 비우고 Enter 면 로그인 시험만 건너뛴다.
- 매번 묻지 않게 하려면 `svc.env.example` 을 `svc.env` 로 복사해 값을 넣는다 (`svc.env` 는 git 에 안 올라간다).
- 서버(g4dn)를 켜 두고, main 반영(`bash ~/deploy_server.sh update`)이 끝난 뒤에 돌린다.

| 옵션 | 뜻 |
|---|---|
| `--with-llm` | 지적 문장 고쳐 쓰기(sLLM)까지 시험 — 20초 안팎 더 걸린다 |
| `--no-login` | 계정을 묻지 않는다 |
| `--admin-open` | 관리자 허용 IP 에서 실행 — 관리자 로그인 · 오류 로그 화면을 시험(관리자 아이디 · 비밀번호를 묻는다) |
| `--only 검수` | 이름에 그 글자가 든 시험만 (예: `--only SEC`, `--only judge`) |
| `--base http://127.0.0.1:8000` | 다른 주소로 (로컬 서버 등) |

- 판정의 **옳고 그름은 합격선으로 두지 않는다** — 고장의 신호(200 아님 · 계약 밖 값 · 미판정 · 판정기 판 미상 · 답이 흔들림)만 실패로 본다. 판정 결과는 보고서 「5. 판정 결과 관찰」 표에 그대로 남긴다.
- 로그인한 상태로는 검수를 돌리지 않는다 — 이력 보관에 동의한 계정이면 시험 문구가 이력에 쌓인다.
- 틀린 비밀번호 시험은 지어낸 이메일로 한 번만 한다 — 시험 계정이 5분 잠금에 걸리지 않게.
- 카피 생성(GPT 비용) · 광고 만들기 화면 스크립트는 자동 시험에서 뺐다 — 보고서 「7. 수동 확인」에 적힌다.
