## 다음 접속 때 순서

```bash
# 0. 인스턴스 시작 → 상태 검사 2/2 → MobaXterm → tmux new -s deploy

# 1. 스크립트 교체 — ssm 이 main 에 머지되기 전이면 파일만 가져온다 (🚨 git checkout ssm 금지 — 앱 코드가 바뀐다)
cd ~/SKN32-FINAL-3TEAM && git fetch origin ssm
git show origin/ssm:docs/ssm/배포/deploy_server.sh > ~/deploy_server.sh && chmod +x ~/deploy_server.sh
#    머지된 뒤면: git pull && cp docs/ssm/배포/deploy_server.sh ~/

# 2. 오전의 임시 구성 걷어 내기
bash ~/deploy_server.sh cleanup-adhoc

# 3. .env 를 배포 값으로 (EDITION=cloud · SESSION_SECRET · DB 비밀번호)
bash ~/deploy_server.sh env
nano ~/SKN32-FINAL-3TEAM/.env          # sLLM 을 싣기 전까지 COPYLANE_SLLM_URL=off

# 4. 기본 비밀번호로 만든 DB 볼륨을 새 비밀번호로 — 적재 전이라 지워도 된다 (§4-2)
cd ~/SKN32-FINAL-3TEAM && docker compose down -v
uv run python launcher.py db-up && uv run python launcher.py migrate

# 5. Caddy 임시판 교체 (닫는 경로 포함)
sudo cp ~/SKN32-FINAL-3TEAM/docs/ssm/배포/Caddyfile.ip /etc/caddy/Caddyfile   # 머지 전이면 git show 로 꺼낸다
sudo caddy validate --config /etc/caddy/Caddyfile && sudo systemctl reload caddy

# 6. 확인 · 상시 가동
bash ~/deploy_server.sh embed-cache
bash ~/deploy_server.sh services
bash ~/deploy_server.sh check
```

그 뒤는 절차서 순서 그대로 — 2단계 `fetch`(커밋 고정) · `data`(판정 ② 와 `pack_store.py` 묶음이 먼저) · `verify` → 3단계 `sllm-model` · `sllm` (`COPYLANE_SLLM_URL` 되돌리고 `services` 다시) → 4단계 도메인 · `Caddyfile`.
