# LLM 카피 생성 — 최소 입력(분기 + 대상 + 간단한 문구) · 프롬프트 · 모델별 생성 결과 (2026-10-03)

- 작성: 권소라(ksr) · 실행 보조: Claude Code
- 실행 2회 · GPT 호출 2회 · 모두 1라운드(모델당 호출 1회 · 20개 요청)
- 사용 모델: `gpt-5.6-luna` · `gpt-6-luna` (섞지 않고 각각)
- 표의 「결과」 — ★ 최종: 서로 가장 다른 3개로 뽑힘 · 보관: 코드 필터와 판정엔진(탈락 판정용)을 지남

---

## 1. 입력

| 칸 | 값 |
|---|---|
| 분기 | 화장품 · 인증 아니오 (일반) |
| 대상 | 야근이 잦은 30대 직장인 |
| 간단한 문구 | 끈적임 없이 산뜻한 수분크림 |

제품명 · 제품 유형 · 특징 · 성분 · 인증은 비웠다.

---

## 2. 프롬프트

호출 한 번에 시스템 프롬프트 1개와 사용자 프롬프트 1개가 나간다. 두 모델에 같은 프롬프트를 보냈다.

### 2-1. 시스템 프롬프트

```
너는 한국어 광고 카피라이터다. 제품 정보와 규칙을 받아 광고 문구 후보를 만든다.

원칙
1. 제품 정보에 적힌 것만 사실로 쓴다. 적히지 않은 수치 · 성분 · 인증 · 시험 · 수상을 지어내지 않는다.
2. 「쓸 수 있는 것」 안에서 다양하게 쓴다. 말투 · 길이 · 문장 끝을 서로 다르게 한다.
3. 최고 · 유일 · 1위 · 타사 대비 같은 비교 · 최상급을 쓰지 않는다.
4. 문구 하나는 한 문장, 15~40자 안팎이다. 「광고」 표시나 주의 문구는 붙이지 않는다.
5. JSON 만 출력한다: {"candidates": [{"angle": "<각도>", "text": "<문구>"}, ...]}
```

### 2-2. 사용자 프롬프트

```
[분기] 화장품 · 인증 아니오 (일반)

[제품 정보 — 이것이 사실의 전부다]
이용자가 적은 문구: 끈적임 없이 산뜻한 수분크림
대상: 야근이 잦은 30대 직장인

[쓸 수 있는 것]
- 사용감 · 제형 · 발림 (산뜻하다 · 촉촉하다 · 끈적임 없다)
- 쓰는 장면 · 시간대 (세안 후 · 메이크업 전 · 자기 전)
- 입력에 적힌 성분 이름 (효능을 붙이지 않고)
- 보습 · 수분감 · 피부결 정돈 같은 화장품 본래 범위

[지킬 것]
- 의약품처럼 말하지 않는다 (치료 · 재생 · 여드름 · 흉터)
- 기능성화장품 효능을 말하지 않는다 (미백 · 주름 · 자외선 차단)
- 천연 · 유기농 · 무첨가 · 저자극은 입력에 있을 때만

[좋은 예 — 다른 제품의 것이다. 범위만 참고하고 문장 틀 · 낱말을 따라 쓰지 않는다]
- 샤워 후 물기 남은 몸에 쓱, 가볍게 퍼지는 바디로션
- 뻑뻑함 없이 부드럽게 감기는 샴푸 거품
- 자기 전 립밤 하나로 마무리해요
- 손등에 덜면 금세 사라지는 묽은 제형의 토너

[나쁜 예]
- 지친 피부를 재생시키는 바디로션 → 의약품으로 오인 — 재생
- 피부과 테스트를 마친 순한 토너 → 입력에 없는 시험 사실
- 바르는 순간 환해지는 미백 로션 → 기능성 심사 없는 미백

[제품명] 주어지지 않았다 — 제품 이름 · 브랜드 이름을 지어내지 않는다.

[요청] 후보 20개. 각도는 사용 장면 · 감각 · 대상 3가지이고 각도마다 7개 안팎으로 나눈다.
```

앞선 실행(제품명 · 유형 · 특징 · 성분을 넣은 입력)과 달라진 점

- `[제품 정보]` 에 「이용자가 적은 문구」와 「대상」 두 줄만 들어간다.
- 재료가 없는 각도는 요청하지 않는다 — 성분이 없어 「원료 이야기」, 제품명 · 유형이 없어 「제품 사실」이 빠지고 세 각도에 7개씩 요청한다.
- 제품명이 없으면 `[제품명] 주어지지 않았다 — 제품 이름 · 브랜드 이름을 지어내지 않는다.` 줄이 들어간다.

## 5. 결과에서 보이는 것

- 최소 입력으로도 20개가 모두 보관됐다 (두 모델 모두 탈락 0건).
- 제품명을 지어내지 않았다 — 두 모델 모두 「수분크림」 · 「크림」으로만 썼다.
- 대상을 넣은 효과가 크다 — 「야근을 마친 밤」 · 「퇴근이 늦은 날에도」처럼 페르소나에서 장면을 가져온다.
- `gpt-5.6-luna` 가 더 다양하다. `gpt-6-luna` 는 20개 중 15개가 「~수분크림」 또는 「~크림」으로 끝나고, 감각 7개는 「산뜻」 · 「촉촉」의 순서만 바꾼 수준이다.
- 입력에 없는 낱말이 조금 섞였다 — 「보습」 · 「피부결 정돈」 · 「매끈한」은 프롬프트의 「쓸 수 있는 것」에서 온 표현이다. 「업무 사이 건조함이 신경 쓰일 때」는 피부 고민을 전제하는 표현이라 확인이 필요하다.
- `gpt-6-luna` 의 출력 토큰이 문구 분량에 비해 크다(2,154) — 내부 추론 토큰으로 보인다. 단가가 낮은데도 비용이 더 나왔다.
- 코드 필터 · 판정엔진이 걸러 낸 것은 0건이다. 화장품은 판정 사전에 화장품법 항목이 없어 엔진이 사실상 보지 못한다.
