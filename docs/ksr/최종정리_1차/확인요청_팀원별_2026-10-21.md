# 최종 산출물 — 팀원별 확인 요청 (2026-10-21)

각 작업 폴더 `작업\NN_*\변경표.md` 의 마지막 「미확인」 목록을 사람별로 모았다. 같은 질문이 여러 문서에 있으면 한 줄로 합치고 문서 번호를 함께 적었다. 문서에는 이 항목들이 모두 「확인 중 / 대기 / 기록 없음」으로 적혀 있어, 답이 없어도 틀린 내용은 아니다. 답이 오면 해당 문서만 고쳐 다시 빌드하면 된다.

- 근거 위치의 「NN #k」는 `작업\NN_*\변경표.md` 최종 미확인 목록의 k 번이다(07 은 A · B 번호, 14 는 §7 번호).
- 12(서비스 테스트)는 다른 작업이 시나리오를 다시 돌리는 중이라 그 항목은 바뀔 수 있다(🔁 표시).
