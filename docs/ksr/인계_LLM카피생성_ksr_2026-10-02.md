## 2. 확정한 설계

| 항목 | 값 |
|---|---|
| 최종 출력 | **3개** (`PARAMS.candidate_n=3` 과 같음) |
| 1회 생성 | 후보 **20개** (GPT 1회 호출) |
| 자동 생성 상한 | **3회** (최대 60 후보) — ✅ 확정 · 팀 기본값과 같다(`max_attempt=2` · D-126) |
| 부족 시 | **탐색 실패(`search_failed`)** + 「3개 중 n개를 찾았습니다」 + [더 탐색하기] [이대로 쓰기] [입력 고치기]. 기준 낮추거나 억지로 채우지 않는다 (D-59 · D-125). ⛔ `hold` 가 아니다 — `hold` 는 재판정이 보류·근거없음을 남긴 경우 |
| 「더 탐색」 | 통과분을 들고 라운드 묶음(3회)을 한 번 더. **횟수 상한은 ⬜ 미정 — 상의해서 정한다** |
| 통과 기준 | 판정 코어 결과 **확정 ∧ R0 만** (D-125). 보류·근거없음·미판정은 탈락. 🔴 통과 = 「위반을 못 찾았다」 — 기획서 §9 |
| 재생성 | 통과분은 두고 부족분만. 프롬프트에 「통과 문구와 겹치지 않게」 + **탈락 사유 유형·건수만**(탈락 문구 원문은 넘기지 않는다 — 생성에 영향을 준다) |
| 판정 전 코드 필터 | 형식·중복 · 수치 · 인증·시험 · 성분 · 비교·최상급 · 분기별 금지어 · 고정 문구 — 입력에 없는 사실은 탈락(D-30 · `claim_ledger` 자리). 표·예시는 기획서 §4-1 |
| 화면 표현 | 「검수 통과」가 아니라 **「후보」** (D-59 · `frontier` 취지) |
| 「광고」 표시·필수 병기 | GPT 에 맡기지 않고 **코드가 붙인다** |

**입력 — 분기 버튼 → 입력창** (입력창 내용 = 「제품 사실」의 전부)

| 분기 | 규칙 |
|---|---|
| 식품 · 인증 N | 기능성·효능 금지(건기식 오인) · 질병 금지 |
| 식품 · 인증 Y (HACCP·유기농 등) | 위 + 인증 **사실만** 언급 가능. 인증은 효능을 열어 주지 않는다 |
| 건기식 · 인증 Y (기능성 인정) | 인정 기능성 문구 **원문 그대로** — 다듬기 대상 아님 · 그 외 효능 금지 · 자율심의 고지 |
| **건기식 · 인증 N** | ✅ 확정 — 「건강기능식품 인정이 없어 **일반식품으로 생성합니다**」 안내 후 **식품 분기로 진행** |
| 화장품 · 인증 N (일반화장품 — 대부분) | 의약품 오인 금지(치료·재생·세포·염증…) · **기능성 효능 금지**(미백·주름·자외선 등) |
| 화장품 · 인증 Y (기능성화장품 심사·보고) | 심사·보고된 효능 범위만 · 그래도 치료·의약품 표현 불가 |

**인증 3종 차이** — HACCP = 제조 공정 위생·안전(효능 무관) / 건기식 기능성 인정 = 원료의 기능성(인정 문구만) / 기능성화장품 심사·보고 = 제품의 특정 효능(화장품법 제4조 · 심사 범위만). 버튼 라벨에 뜻을 풀어 쓴다. 화장품 「인증 Y」는 기능성만 뜻하게(천연·유기농 화장품 인증은 별개).

### 4-1. 팀장님께 확인할 것
1. **「더 탐색」 — 횟수 상한 · DB 에 적는 법** — 자동 3회는 팀 기본값(`max_attempt=2` · D-126)과 DB `CHECK attempt BETWEEN 0 AND 2`(`ck_judgment_attempt` · `alembic/versions/20260909_6c1f5f12e174_runtime_layer.py:138`) 안에 든다. 버튼을 누른 뒤 라운드가 `attempt` 3 이상이 되면 **판정 저장이 거부된다** → 버튼 한 번을 **새 실행(attempt 0 부터)** 으로 적고 앞 실행과 잇는 방식이 맞는지. **횟수 상한은 ⬜ 미정 — 상의해서 정한다**
2. **판정 코어 호출 방식** — 생성 그래프 `assemble` · `claim_ledger` · `rejudge`(`app/graph.py`)는 셋 다 아직 스텁(W9) · 판정이 안 적히면 거부로 처리된다. 코어 문장 모드 배선을 기다릴지, 그 전엔 검수 API 를 문장 단위로 부를지
3. **외부 API 전송** — 사용자 제품 정보가 GPT 로 나간다 → 고지·약관
4. 화장품 지침 사전 편입 (4-0 결과와 함께 · 기획서 §9)
5. **판정 코어가 새 문장에 무엇을 돌려주나** — 사전에 안 걸리는 문장이 「확정 ∧ R0」인지 「근거없음」인지 (기획서 §8-9 · 무해한 새 문장 몇 개로 실측)
