# [CopyLane] 사전 매칭 오탐 — 띄어쓰기를 걸쳐 「한약」이 잡힙니다 (권소라 · 10-12)

## 1. 현상

「편안한 약속을 드립니다.」 한 문장을 검수에 넣으면

- 강조되는 글자: 「한 약」 (편안"한 약"속)
- 식품 · 건기식(인정/비인정) 전제: 위반 확정 · R2 · 사용 불가 · 의약품 오인 → 종착 「합법화 불가」
- 화장품 · 일반상품 전제: 보류
- 품목을 안 고른 첫 화면: 보류 · 품목 선택 필요 · R2 · 사용 불가 · 의약품 오인

같은 꼴로 「순한 약품처럼 부드럽습니다」도 「한약」이 걸립니다.
(ksr @779ab67 · 사전 c6e29452c81b · 로컬 서버에서 확인)

## 2. 원인

- `app/dictmatch.py` — 문장의 공백을 전부 지운 뒤 사전 낱말이 부분문자열로 들어 있으면 적중입니다(`norm()` → `find()`). 「편안한 약속」 → 「편안한약속」 안에 「한약」.
- 사전의 「한약」은 단독판정 자격이 있고 유형이 의약품_오인(013094:제8조제1항제2호)입니다.
  절대형이라 걸리면 보류가 아니라 확정 · 증명서로 갑니다.

## 3. 얼마나 나오나 (`data/derived/golden/golden.jsonl` 8,383문장 · 사전 단독판정 347항목)

- 「한약」: 붙여 쓴 것 5건 · 띄어쓰기를 걸쳐 잡힌 것 2건(예: 「진귀한 약재」)
- 「키약」: 붙여 쓴 것 0건 · 띄어쓰기를 걸쳐 잡힌 것 2건(「키 약」)
- 단독판정 자격이 있는 두 글자 항목은 13개입니다:
  간약 · 긴장 · 꿀잠 · 난임 · 링거 · 붓기 · 비만 · 이명 · 키약 · 탈모 · 한약 · 항암 · 해독
  나머지 11개는 골든에서 띄어쓰기를 걸친 적중이 0건이었습니다.
- 띄어쓰기를 걸친 적중 전체는 540건인데 대부분 정상입니다(「면역력 강화」 · 「업계 최초」 등).
  공백을 지우는 것 자체가 문제는 아니고, 짧은 낱말이 낱말 경계를 넘어 맞는 것이 문제입니다.
- 골든에서는 드물지만 사용자 입력에는 「~한 약…」 꼴(순한 약산성 · 편안한 약속 · 건강한 약국)이 흔할 수 있습니다.
- 공백 없이도 같은 종류가 납니다 — 「준비만」 안에 「비만」. 이쪽은 수를 세지 않았습니다.

## 4. 고칠 곳 — 판정을 부탁드립니다

### (가) 사전

- 「한약」 등 짧은 항목의 단독판정 자격을 내린다(확정 → 보류 + 유형 후보).
  - 자리: 사전 원천과 빌더(`preprocess/dictionary.py`) → `data/derived/banned_terms.jsonl` 의 「단독판정」
    → DB `dict_entry.exact_match`. 사전 지문이 바뀝니다.

### (나) 매칭 규칙

- 짧은 낱말은 공백을 걸쳐서는 맞추지 않는다(또는 낱말 경계를 본다).
  - 자리: `app/dictmatch.py` `find()` · `norm_with_map()`. 그래프 `match_dict` · `scripts/eval_rule.py` ·
    사전 빌더가 같은 함수를 쓰므로 평가 수치가 같이 움직입니다.

### (다) 고쳐 쓰기 관문

- `docs/lse/stage_gate.py` 가 사전의 단독판정 항목을 금지어로 씁니다. 같은 방식으로 맞춘다면
  고친 문구가 「~한 약…」 때문에 관문에서 막힐 수 있습니다. (가)/(나)가 정해지면 같이 확인 부탁드립니다.
  (관문 코드는 제가 읽어 보지 않았습니다.)
