## 1. 개요 — 무엇을 하는 모델인가

CopyLane 검수(판정 코어)가 광고 문구에서 위반을 찾으면, **자체 sLLM 이 그 문장을 그 자리에서 고쳐 쓴다(재생성).**
고친 문장은 다시 판정 코어로 돌아가 재판정을 받는다. 입력 · 출력 · 2단계 다듬기는 2차와 같다.

| 입력 | 출력 |
|---|---|
| 위반 문장 + 위반 유형 + 품목(사용자가 고른 분기) | **후보** — 위반 표현만 지우고 사실(원산지 · 원료 · 제조 · 용량)은 살린 문구 + 필수 병기(조건) |
| | **조건부 후보** — 인정 · 심사 받은 제품에서만 쓸 수 있는 공식 문구 + 조건. 사람이 조건을 확인한다 |
| | **보류** — 안전장치에 걸림 → 사람 검토 |
| | **만들지 못했어요** — 살릴 사실이 없음(질병 치료 · 의약품 표방 등) |

예 (직접 만든 문구):

| 입력 (위반 유형) | 결과 |
|---|---|
| 고혈압 낮추는 오미자청, 문경 오미자를 설탕에 100일 숙성 (질병) | 문경 오미자를 설탕에 100일 숙성한 오미자청 |
| 이 크림 바르면 주름이 완전히 사라집니다 (거짓 과장) | 🟡 조건부 후보 — 피부의 주름 개선에 도움을 줍니다 + (주름 기능성화장품으로 심사 · 보고된 제품에 한함) |
| 암을 이기는 꾸지뽕 진액 (질병) | ⛔ 만들지 못했어요 |

**설계 원칙 — 「다 맞히기」가 아니라 「틀리면 멈추기」.** 위반을 그럴듯하게 포장해 내보내는 것(위반 포장)을 가장 큰 실패로 둔다.
후보도 **적법 확정이 아니다** — 재판정과 사람 검수가 남는다.

## 4. 전체 흐름 (모델 + 안전장치)

```
검수(판정 코어) ─ 위반 유형 · 품목 ─▶ ① 1단계 sLLM            위반만 지운 문장 / 고칠 수 없으면 「불가」
                                       ▼
                                      ①' 되살리기 (🆕)        「불가」라도 화장품 기능 주장이면 공식 문구 + 심사 조건
                                       ▼
                                      ② 후처리 (postfix.py)   원료명 되찾기 · 지어낸 기능성 → 공식 문구 · 필수 병기
                                       ▼                       🆕 화장품에 건기식 기능 문구 → 보류 · 제품 이름만 남음 → 보류
                                      ③ 관문 (stage_gate.py)  금지 사전 · 질병 · 의약품 · 원문 숫자 · 뜻 바뀜 · 조건 확인 필요 …
                                       ▼                       🆕 화장품 가이드라인 출처 사전 낱말(30)은 화장품일 때만
                                      ④ 2단계 sLLM (다듬기)   식품 · 건기식 · 화장품만
                                       ▼
                                      ⑤ 재판정 (팀 판정 코어)
                                       ▼
                   후보 / 조건부 후보 / 보류 / 만들지 못했어요
```

- ①' ②③은 규칙(파이썬)이다 — 되살린 문장은 「조건 확인 필요」(조건부 후보)로만 나가 위반 포장이 생길 수 없다.

## 9. 한계 — 증명하지 않는 것

- **최종 문장의 적법성** — 「위반 못 찾음」은 통과가 아니다. 사람 검수가 남는다.
- **식품 · 화장품 밖 업종** — n2 는 분양 · 학원 같은 업종의 문장을 살릴 수 있어도 거절하는 경우가 많다(dev 후보 81 → 27).
- **규칙의 낙관** — 되살리기 · 안전장치 일부를 정답표 87 · 직접 만든 문제를 보고 골랐다. dev 는 고친 뒤 한 번 쟀다.
- **dev 오염** — n2 학습 묶음에 dev 문장 101 이 있었다. 다음 판부터 뺀다.
- **표본 크기 · 정답** — 살릴 수 있는 실제 광고가 21 개라 1~2 개 차이는 우연과 가르기 어렵다. 학습 정답 · 정답표 · dev 표본 판정이 Claude 초안이고 법률 검토 전이다.
- **교사 모델 의존** — 확장 데이터의 정답 일부(A · B 의 교정)는 GPT 가 썼다 — 교사의 판단(불가 위주)이 모델에 옮겨졌다.
