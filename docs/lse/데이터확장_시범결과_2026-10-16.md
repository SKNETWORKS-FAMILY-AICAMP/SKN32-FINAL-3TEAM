# 1단계 데이터 확장 시범 결과 (2026-10-16)

10-15 회의에서 멘토가 "재생성 학습 데이터가 너무 적다(1만 건 정도 필요)"고 지적했다. 목표를 **약 8천 행**으로 잡고, 실제 위반 문장을 씨앗으로 교사 모델(GPT)이 고쳐 쓰는 방식을 시범으로 돌렸다.

**결론: 교사는 gpt-4.1 로 간다. 다만 그대로 늘리면 "불가" 행이 70~90% 가 되어 거절 쪽으로 기운다. 본 생성 전에 변형(B) 지침을 "사실이 섞인 위반 문구"로 바꿔야 한다.**

스크립트: [gen_expand_stage1.py](gen_expand_stage1.py) · 생성물과 결과는 전부 `_private/`(재배포 불가 원문 포함) · 사용액 기록: `_private/expand_spend.json`

## 구성안 (8천 행)

| 묶음 | 내용 | 시범 기준 예상 |
|---|---|---|
| A. 실제 문장 교정 | golden 실제 위반 문장(식품 · 건기식 · 화장품) 2,605 → 교사가 고쳐 씀 → 거름 | 약 2,200 (대부분 불가) |
| B. 실제 문장 변형 | 씨앗마다 같은 위반 방식 · 다른 제품으로 새 문구 → 고쳐 씀 → 거름 | 씨앗당 1개면 약 1,450 |
| C. 식약처 수정쌍 | 사람이 쓴 정답 245 중 관문 통과 72 (2배 반영) | 약 150 |
| D. 기존 q4b-v14 | 그대로 | 약 2,000 |

- 씨앗 2,605 = 실제 위반 문장에서 중복 18 · 길이 116 · 정답표(평가 전용 105문장)와 닮은 119 를 뺀 수.
- C 가 245 중 72 만 남은 까닭: 원본이 2017 특수용도식품(환자식 · 영아식) 기준이라 지금 관문 정책과 다른 표현이 정답에 있고(151), 낱말 조각 · 표기 지시가 많다(14).

## 드러난 것

1. **교사 품질이 병목이다.** 관문 · 재판정은 교사의 실수(효능 · 비교 주장이 남은 고침)를 다 거르지 못한다. 4o-mini 는 받아들인 고침의 약 절반이 학습에 쓰면 안 되는 수준이었고, 4.1 은 같은 문장에서 판단이 대부분 맞았다.
2. **golden 씨앗은 대부분 "불가" 감이다.** 가이드 문서에서 잘린 목록 · 소제목, 효능 주장만 있는 짧은 조각(길이 중앙값 17자)이 많다. 맥락 때문에 위반인 사실 문장도 있어(원문 그대로) 이 용도에는 버려진다.
3. **팀이 걱정한 편향은 이번에는 반대쪽으로 컸다.** "다 지워서 통과"보다 "불가로 빠지기"가 쉬웠다. 지금 모델의 약점이 "살릴 것을 못 살림"(정답표에서 살릴 수 있는 20 중 3)이라, 불가 위주 데이터는 그 약점을 키운다.
   - 막이: 원문에 사실 신호(수치 · 원료 · 산지 · 제조)가 있는데 불가면 버린다(`FACT_SIGNAL`). 교사의 사실 목록만 믿으면 교사가 목록을 비우고 불가라고 할 때 못 잡는다.
   - 사실 보존 막이(사실 빠짐)는 4.1 에서 거의 걸리지 않았다(B 1건).

## 다음 (본 생성 전)

1. **B 지침 변경** — 변형 문구에 **사실 하나 이상 + 위반**을 함께 넣게 한다(v9 「사실 + 위반 짝」과 같은 생각). 고침 행이 늘어 불가 쏠림이 줄어든다.
2. **불가 비율 상한** — 최종 묶음에서 불가를 3할 안팎으로 맞춘다(A 의 불가는 골라 쓴다).
3. **낱말 조각 막이 보강** — 받아들인 고침에 사실 없는 나열(제품 이름 둘만 남은 것 등)이 남았다.
4. **비교 학습** — ① q4b-v14 ② 실제 문장 기반만(A + C) ③ 전체. 평가는 사람 정답표(87)로만 한다(거르기에 쓴 재판정으로 재지 않는다).

## 비용

- 예산 상한 **$10**(사용자 10-16). 시범까지 누적 **$0.22**(기록은 보수 가격 · 실제는 이보다 적다).
- 문장 10개를 묶어 부르면 한 문장씩 부를 때보다 약 1/4 비용이다.
- 4.1 로 본 생성 시 보수 견적: A 전체 약 $1.7 · B 씨앗당 1개 약 $3.4 → 합계 약 $5. B 를 씨앗당 2개로 늘리면 상한에 가까워지므로, 1번(사실 섞인 변형)으로 고침 비율을 먼저 올린다.
