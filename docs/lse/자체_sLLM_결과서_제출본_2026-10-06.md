## 1. 개요 — 무엇을 하는 모델인가

CopyLane 검수(판정 코어)가 광고 문구에서 위반을 찾으면, **자체 sLLM 이 그 문장을 고쳐 쓴다(재생성).**

| 입력 | 출력 (셋 중 하나) |
|---|---|
| 위반 문장 + 판정 코어가 찾은 **위반 유형** | **후보** — 위반 표현만 지우고 사실(원산지 · 원료 · 제조 · 용량)은 살린 문구 + 필수 병기(조건) |
| | **보류** — 고친 문구가 안전장치에 걸림 → 사람 검토 |
| | **합법화 불가** — 살릴 사실이 없음(질병 치료 · 의약품 표방 등) → 증명서 경로(D-32) |

예 (직접 만든 문구 · 실제 출력):

| 입력 (위반 유형) | 결과 |
|---|---|
| 고혈압 낮추는 오미자청, 문경 오미자를 설탕에 100일 숙성 (질병) | ✅ 문경 오미자를 설탕에 100일 숙성한 오미자청 |
| 이 크림 바르면 주름이 완전히 사라집니다 (거짓 과장) | ✅ 피부의 주름 개선에 도움을 줍니다 + (주름 기능성화장품으로 심사·보고된 크림에 한함) |
| 흉터 치료 연고보다 좋은 크림, 마데카소사이드 함유 50ml (의약품 오인) | ✅ 마데카소사이드 함유 크림 50ml + (원재료 함량을 함께 표시) |
| 암을 이기는 꾸지뽕 진액 (질병) | ⛔ 합법화 불가 — 질병_예방치료_표방 |
| 한 달이면 키 10cm 크는 우유 (거짓 과장) | ⛔ 합법화 불가 — 거짓_과장 |

**설계 원칙 — 「다 맞히기」가 아니라 「틀리면 멈추기」.** 위반을 그럴듯하게 포장해 내보내는 것(위반 포장)을 가장 큰 실패로 두고,
확신이 없으면 보류해 사람에게 넘긴다. 🚨 후보도 **적법 확정이 아니다** — 재판정과 사람 검수가 남는다.

## 2. 왜 자체 sLLM 인가

| 이유 | 내용 |
|---|---|
| 데이터가 밖으로 나가지 않는다 | 광고주 문구를 외부 API 로 보내지 않는다 — 로컬 GPU 1장에서 돈다 |
| 도메인 규칙을 가르칠 수 있다 | 「고칠 수 없음」 판단 · 식약처 인정 문구 · 기능성화장품 공식 문구 · 조건 병기를 학습으로 넣었다 |
| 비용 · 통제 | 호출 비용 없음 · 모델 버전을 고정해 같은 입력에 같은 출력(재현성) |
| 크기 | RTX 3080(10GB)에서 학습 · 추론이 되는 크기 — 1.5B 에서 시작해 핵심 내용 손실 · 오타 때문에 **3B 로 올렸다**(4차) |

## 3. 모델 구성

| 항목 | 값 |
|---|---|
| 베이스 모델 | `Qwen/Qwen2.5-3B-Instruct` |
| 미세조정 | **LoRA** — r=8 · α=16 · dropout 0.05 · 대상 `q_proj` `k_proj` `v_proj` `o_proj` |
| 학습 설정 | 3 epoch · lr 2e-4 · cosine(warmup 5%) · 최대 길이 640 토큰 · bf16 · gradient checkpointing |
| 어댑터 ① **1단계(위반 제거)** | `copylane_sllm_lora_adapter_v12` — **최종 채택**(10-05) |
| 어댑터 ② 2단계(페르소나 말투) | `copylane_sllm_persona_adapter` — 고객층을 고를 때만 |
| 출력 형식 | JSON — `{"body", "mandatory_note", "placement"}`(팀 계약 `RewriteSet`) 또는 `{"infeasible": "<위반 유형>"}` |
| 하드웨어 | 학습 · 추론 RTX 3080 10GB · 추론 VRAM 약 7GB(bf16) |

## 4. 전체 흐름 (모델 + 안전장치)

```
검수(판정 코어) ─ 위반 유형 ─▶ ① 1단계 sLLM (v12)        위반만 지우고 사실을 살린다 / 고칠 수 없으면 손을 든다
                              ▼
                             ② 후처리 (postfix.py)       원료명 잘림·오타 되찾기 · 지어낸 기능성 → 식약처 공식 문구 · 조건(필수 병기) 붙이기
                              ▼
                             ③ 관문 (stage_gate.py)      금지 사전 · 질병·의약품 · 원문 숫자 · 원문에 없는 낱말 · 원료명 잘림 · 인정되지 않은 기능성
                              ▼
                             ④ [2단계 페르소나 말투]     고객층을 고를 때만 — 주장 범위는 그대로, 말 거는 대상만
                              ▼
                             ⑤ 재판정 (팀 판정 코어)     고친 문구를 다시 판정 — 위반 유형이 붙으면 후보에서 탈락(D-119)
                              ▼
                     후보 / 보류 / 합법화 불가
```

- ②③은 규칙(파이썬)이다 — 모델이 틀려도 **막는 쪽으로** 틀린다. 고친 문장도 관문을 다시 지난다.
- 모델이 낸 위반 문장을 관문이 막은 실제 꼴(직접 만든 문구로 재현): 원문에 없는 제품명(「…저온 로스팅한 **곶감** 200g」) ·
  인정되지 않은 기능성(「흰모발의 개수를 감소시키는데 도움」) · 원문과 무관한 화장품 기능(미백 문구에 「주름 개선」) · 효과 수치 남김(「5kg 감량」).

### 5-2. 누수 · 저작권 관리 (팀장 조건: 「누수만 없으면 진행」)

| 관리 | 방법 |
|---|---|
| 인코더 평가셋과 겹침 | 판정 인코더의 평가 문장과 같거나 부분으로 겹치는 행은 학습 · 평가에서 뺀다 |
| 평가 오염 | 실제 광고 정답표 문구가 학습 문구 **안에 부분으로** 든 경우를 찾아 `seen_in_training` 표시 → **학습에 없던 87개**로 따로 잰다 |
| 합성 거르기 | 골든 겹침 0 · 정답표 고유 원료/표현 제외 · 학습 문구와 유사도 0.6 이상 제외 |
| 재배포 불가 문구 | 광고주 문구는 공개 저장소에 싣지 않는다 — `check_redistribution.py` + pre-commit 훅이 막는다 |
| 채점 | 판정 인코더로 채점하지 않는다(학습 · 채점에 같은 것을 쓰면 짜고 치는 판) — 정답표 · 규칙으로 잰다 |

⚠️ 학습 정답 · 합성 데이터 · 정답표는 **Claude 초안 → lse 확인**이며 법률 검토 전이다.

## 9. 한계 — 증명하지 않는 것

- **최종 문장의 적법성** — 판정 코어가 인코더 연결 전(사전 판정)이라 「통과」를 낼 수 없다. 사전이 식약처 인정 기능성 문구를
  `건강기능식품_오인` 으로 잡는 오탐도 있다(사전 개편 중).
- **실전 살리기 수준** — 살릴 수 있는 실제 광고 20개 중 8개(40%). 나머지는 보류(사람 검토)로 간다 — 안전 쪽으로 기운 결과다.
- **표본 크기** — 살릴 수 있는 실제 광고가 20개라 1~2개 차이는 우연과 가르기 어렵다. 연습 문제(살리기 40 · 원료명 14)는 직접 만든 문제라 점수가 후하다.
- **안전의 상당 부분이 규칙에 기댄다** — v12 는 기능성 주장을 적극적으로 쓰고, 위반 포장 0 은 관문 · 후처리 덕분이다.
- **후보 1개** — 팀 설계의 3안(D-34 N=3) · 재판정 탈락 시 다시 만들기(D-126 K=2)는 아직 없다.
- **데이터** — 학습 정답 · 정답표가 Claude 초안이고 법률 검토 전이다. 정답표 v2(74개 추가분)는 사람 검토 대기다.
- 🔴 **실제 광고 수치는 낙관적일 수 있다** — 정답표 v2 의 원천(식약처 사례집 2021 · 화장품 광고 Q&A)은 판정 인코더의 평가 원천이다.
  10-05 에 그 정답표의 미리보기 결과를 보고 관문 · 후처리를 보강했으므로(결과서 16차), 「학습에 없던 87개」는 **규칙을 조정할 때 본 문구**다.
  10-06 부터는 그 문구로 규칙을 조정하지 않고, 회귀는 학습 정답과 직접 만든 연습 문제로만 본다(팀장 전달 · D-175 관계는 팀장 판정 대기).
