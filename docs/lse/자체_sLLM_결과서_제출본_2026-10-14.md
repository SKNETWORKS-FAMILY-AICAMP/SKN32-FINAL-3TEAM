## 1. 개요 — 무엇을 하는 모델인가

CopyLane 검수(판정 코어)가 광고 문구에서 위반을 찾으면, **자체 sLLM 이 그 문장을 그 자리에서 고쳐 쓴다(재생성).**
고친 문장은 다시 판정 코어로 돌아가 재판정을 받는다.

| 입력 | 출력 |
|---|---|
| 위반 문장 + 위반 유형(사전 판정 · 사전이 조용하면 AI 추정 유형) + 품목 | **후보** — 위반 표현만 지우고 사실(원산지 · 원료 · 제조 · 용량)은 살린 문구 + 필수 병기(조건). 식품 · 건기식 · 화장품은 「다듬은 안」과 「담백한 안」 두 개 |
| | **조건부 후보** — 인정 · 심사 받은 제품에서만 쓸 수 있는 공식 문구. 후보가 아니고 사람이 조건을 확인한다 |
| | **보류** — 고친 문구가 안전장치에 걸림 → 사람 검토 |
| | **만들지 못했어요** — 살릴 사실이 없음(질병 치료 · 의약품 표방 등) |

예 (직접 만든 문구 · 채택 판의 실제 출력 · 2026-10-14):

| 입력 (위반 유형) | 담백한 안 (1단계) | 다듬은 안 (2단계) |
|---|---|---|
| 고혈압 낮추는 오미자청, 문경 오미자를 설탕에 100일 숙성 (질병) | 문경 오미자를 설탕에 100일 숙성한 오미자청 | …오미자청, 차갑게 두었다가 한 숟갈씩 드세요 |
| 이 크림 바르면 주름이 완전히 사라집니다 (거짓 과장) | 🟡 조건부 후보 — 피부의 주름 개선에 도움을 줍니다 + (주름 기능성화장품으로 심사 · 보고된 크림에 한함) | — (공식 문구라 다듬지 않음) |
| 암을 이기는 꾸지뽕 진액 (질병) | ⛔ 만들지 못했어요 | — |

**설계 원칙 — 「다 맞히기」가 아니라 「틀리면 멈추기」.** 위반을 그럴듯하게 포장해 내보내는 것(위반 포장)을 가장 큰 실패로 두고,
확신이 없으면 보류해 사람에게 넘긴다. 🚨 후보도 **적법 확정이 아니다** — 재판정과 사람 검수가 남는다.

## 2. 왜 자체 sLLM 인가

| 이유 | 내용 |
|---|---|
| 데이터가 밖으로 나가지 않는다 | 광고주 문구를 외부 API 로 보내지 않는다 — 로컬 GPU 1장에서 돈다 |
| 도메인 규칙을 가르칠 수 있다 | 「고칠 수 없음」 판단 · 식약처 인정 문구 · 기능성화장품 공식 문구 · 조건 병기를 학습으로 넣었다 |
| 비용 · 통제 | 호출 비용 없음 · 판을 잠금 파일로 고정해 같은 입력에 같은 출력(그리디 생성 · 재현성) |
| 라이선스 | 베이스를 Qwen2.5-3B(qwen-research · 이용 제한)에서 **Qwen3-4B-Instruct-2507(apache-2.0)** 로 옮겼다 |
| 크기 | RTX 3080(10GB)에서 학습 · 추론이 되는 크기 — 추론 VRAM 약 8~9GB(bf16) |

## 3. 모델 구성

| 항목 | 값 |
|---|---|
| 베이스 모델 | `Qwen/Qwen3-4B-Instruct-2507` |

| 어댑터 ① **1단계(위반 제거)** | `copylane_sllm_lora_adapter_q4b-v14` — **채택**(D-335) · 가중치 지문 `ea832ca31750` · 판 지문 `fc7b1e8f916f` |
| 어댑터 ② **2단계(자연스럽게 다듬기)** | `copylane_sllm_persona_adapter_q4b_polish` — **채택**(D-335) · 가중치 `15c24339ab34` · 판 `13cdbea17408` |

## 4. 전체 흐름 (모델 + 안전장치)

```
검수(판정 코어) ─ 위반 유형 · 품목 ─▶ ① 1단계 sLLM (q4b-v14)      위반만 지운 「담백한 안」 / 고칠 수 없으면 손을 든다
                                       ▼
                                      ② 후처리 (postfix.py)       원료명 되찾기 · 지어낸 기능성 → 식약처 공식 문구 · 필수 병기 조건
                                       ▼
                                      ③ 관문 (stage_gate.py)      금지 사전 · 질병 · 의약품 · 원문 숫자 · 원문에 없는 낱말 · 원료명 잘림 ·
                                       ▼                           인정되지 않은 기능성 · 뜻 바뀜 · 「무」 뒤집힘 · 조건 확인 필요
                                      ④ 2단계 sLLM (다듬기)       식품 · 건기식 · 화장품만 — 「다듬은 안」 → 관문 다시(말투 · 쓰는 법 검사 추가)
                                       ▼
                                      ⑤ 재판정 (팀 판정 코어)     두 안 모두 — 위반 유형이 붙으면 그 안은 뺀다(D-119)
                                       ▼
                   후보(최대 2안) / 조건부 후보 / 보류 / 만들지 못했어요
```

- ②③은 규칙(파이썬)이다 — 모델이 틀려도 **막는 쪽으로** 틀린다. 다듬은 문장도 관문을 다시 지난다.
- 다듬은 안이 재판정에서 떨어지거나 다듬은 안에만 AI 추정 유형이 남으면, 담백한 안을 후보로 올린다(더 보수적인 쪽).
- **모델 판 잠금(D-333 · D-335)** — 서버는 시작할 때 `models.lock.json` 과 어댑터 파일 전부의 sha256 을 대조한다. 1단계가 잠금 밖이면
  서버가 뜨지 않고(앱은 「연결하지 못했어요」), 2단계가 잠금 밖이면 다듬기 없이 뜬다. 응답마다 그 문장을 쓴 판(`lock: {stage1, stage2}`)을 싣는다.

## 8. 배포

| 항목 | 내용 |
|---|---|
| 서빙 | `docs/lse/sllm_service.py` — FastAPI `POST /rewrite` · `GET /health` · 모델 1회 로드 · 요청 직렬 처리 · 시작 때 잠금 대조 |
| 분리 | 앱(`.venv` · CPU torch)과 sLLM(`.venv-sllm` · GPU torch)을 **별도 프로세스**로 — HTTP 로 부른다 |
| 앱 연결 | 검수 결과의 위반 문장 아래 **「✨ 이 문장 고쳐 쓰기」** → `POST /u/review/rewrite` → sLLM → 두 안 재판정 → 「다듬은 안 · 담백한 안 · 조건부 후보」를 그 문장 아래에 표시. 고쳐 쓰는 동안 단계 표시(위반 짚기 → 지우기 → 다듬기 → 다시 확인) |
| 보안 | `127.0.0.1` 에만 연다 · 서버가 없으면 후보를 만들지 않는다 · 모델이 지어낸 불가 사유는 표시하지 않는다 |
| 지연 | 문장당 약 8 초(RTX 3080) · 앱 고쳐 쓰기 13~20 초(다듬기 · 재판정 포함) |
| 모델 전달 | 팀 공유 드라이브 `copylane-models/` 의 어댑터 폴더 · 베이스는 Hugging Face · 판은 `models.lock.json`(팀장 등재) |
| 테스트 | `tests/test_user_rewrite.py` · `tests/test_sllm_meta.py` · `tests/test_sllm_lock.py` — GPU · DB 없이(골든 픽스처 · 가짜 서버) |

실행:

```
.venv-sllm\Scripts\python.exe docs\lse\sllm_service.py --serve --port 8765   # sLLM (GPU)
.venv\Scripts\python.exe -m uvicorn app.api:app --port 8000                  # 앱
```

## 9. 한계 — 증명하지 않는 것

- **최종 문장의 적법성** — 재판정은 사전 근거로만 탈락시킨다(D-323). 「위반 못 찾음」은 통과가 아니다 — 사람 검수가 남는다.
- **실전 살리기가 낮다** — 살릴 수 있는 실제 광고 20 중 3. 안전망(조건 확인 필요)을 우선한 결과이고, 그 문장들은 「조건부 후보」로 보인다.
- **다듬기의 질** — 안전은 지키지만 처음 보는 제품에서는 쓰는 법이 어색할 수 있다(약 절반). 그래서 담백한 안을 함께 보이고, 식품 · 건기식 · 화장품에서만 켠다.
- **표본 크기** — 살릴 수 있는 실제 광고가 20 개라 1~2 개 차이는 우연과 가르기 어렵다. 직접 만든 문제는 점수가 후하다.
- **데이터** — 학습 정답 · 정답표가 Claude 초안이고 법률 검토 전이다. 정답표 v2 원천은 10-05 이전 규칙 조정에 쓰인 적이 있다(그 뒤로는 쓰지 않음).
- **후보 수** — 다듬은 안 · 담백한 안 최대 2 개. 팀 설계의 3안(D-34) · 재판정 탈락 시 다시 만들기(D-126)는 아직 없다.
