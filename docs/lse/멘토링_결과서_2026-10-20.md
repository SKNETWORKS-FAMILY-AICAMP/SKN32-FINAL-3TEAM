## 2. 데이터를 어떻게 늘렸나

| 단계 | 방법 | 결과 |
|---|---|---|
| 1차 확장 | 실제 위반 문장을 GPT가 고쳐 쓰기 · 변형 → 4,720행 | 살림 3 → 1 · 위반 포장 1 — **실패**. GPT가 쓴 「정답」이 틀린 경우가 섞임 |
| 2차 확장 | **정답은 공개 원천에서 규칙으로**(고시 기능성 문구 · 기능성화장품 범주 · 원료명), GPT는 위반 문구 쪽만 | 위반 포장 0 유지 · 불가 판단 개선 |
| 섞는 비율 | 사실 남기기 34% · 조건부 28% · 불가 33% · 식약처 수정쌍 5% | 팀 지적 「위반만 피해 통과하는 편향」을 막으려고 불가 비율을 일부러 남김 |

- **배운 점:** 양보다 정답의 질이 먼저였어요. GPT에게 정답까지 맡기면 틀린 정답이 학습되고, 정답을 규칙으로 고정하니 안정됐어요.
- **비용:** API 누적 약 $8.7(상한 $10).

## 3. 멘토 제안 — 기존 vs 새 데이터 전용 비교

실제 광고 87개 (학습에 없던 문장 · 사람이 만든 정답표)

| 판 | 학습 데이터 | 불가를 불가로 | 살림 | 🔴 위반 포장 | 지나친 거절 | 보류 |
|---|---|--:|--:|--:|--:|--:|
| q4b-v14 (기존) | 2,019 | 55 | 3 | 0 | 6 | 23 |
| q4b-v17 (기존+확장) | 4,589 | 67 | 2 | 0 | 15 | 3 |
| q4b-n2 (확장만) | 2,570 | 66 | 4 | 0 | 14 | 3 |
| **q4b-n2 + 되살리기** | 〃 + 규칙 | **66** | **4** | **0** | **6** | **11** |

- 확장 데이터를 넣은 두 판(v17 · n2)은 「불가를 불가로」가 크게 좋아졌지만, **지나친 거절**(살릴 수 있는 문구를 버림)이 6 → 14~15로 늘었어요.
- 확장만으로 학습한 n2가 기존을 섞은 v17과 거의 같은 성능이라, 더 가볍고 빠른 n2를 골랐어요(문장당 3.9초).
- **되살리기 규칙:** 모델이 불가라 해도 질병 · 의약품 · 시술 표현이 없는 화장품 기능 주장이면 「공식 문구 + 심사 조건」으로 살려요. 지나친 거절이 14 → 6으로 줄었어요.
- 직접 만든 시험 문장 119개에서는 n2가 처음에 위반 포장 3건을 냈어요. 막는 규칙 2개를 더해 0건으로 만들었어요(v14 성적은 그대로).

## 4. 처음 보는 문장 — 솔직한 한계

팀 평가 묶음 dev 511 (정답 없음 · 화면에 후보로 나가는 비율만 볼 수 있음)

| 지표 | q4b-v14 | q4b-n2 + 되살리기 |
|---|--:|--:|
| 화면 후보 | 81 (15.9%) | 27 (5.3%) |
| 보류 · 불가 | 297 · 133 | 34 · 450 |
| 재판정 탈락 · 새 위반 | 0 · 0 | 0 · 0 |
| 문장당 지연(중앙) | 7.3초 | 3.9초 |

- n2는 처음 보는 문장 대부분을 「불가」로 답해요.
- 그런데 v14가 후보로 낸 문장 15개를 사람이 봤더니 6개는 내보내면 안 되는 문장이었어요(위반 뜻이 남거나 원문과 뜻이 달라짐). 그래서 **거절이 많은 쪽이 안전한 쪽**이라고 판단했어요.
- n2 학습 데이터에 dev 문장 101개가 섞여 있던 것을 발견했어요. 다음 판부터는 자동으로 뺍니다. dev 결과는 겹치지 않는 329개로 따로 봤어요.

## 5. 통합 · 배포 진행

- **배포 서버 GPU(T4):** bf16을 못 써서 fp16으로 자동 전환되게 했어요.
- **새 판정 그래프 연결:** 사용자가 고른 품목 분기, 사실 확인 질문에 한 답으로 다시 판정한 결과를 기준으로 고쳐 써요.
- **화면:** 검수 화면에 고쳐 쓰기 · 조건 질문 · 「일반식품_기능성」 분기가 붙었어요.
- **🆕 고쳐 쓸 수 없는 문장 → 새 카피로 잇기 (10-15 회의 제안):** 고쳐 쓰기가 「불가」인 문장 아래에 「이 제품으로 새 카피 만들기」 버튼이 나와요.
  누르면 카피 생성 화면이 품목과 위반 표현을 뺀 제품 정보로 미리 채워져 열려요(예: 「위암을 예방하는 양파즙」 → 식품 · 제품 종류 「양파즙」).
  「다 잘렸다」로 끝나지 않고, 판정을 거친 새 카피로 이어져요.
- **기기 동기화 확인 (10-20):** 정본과 같은 판정 숫자가 나와요. 테스트 2,104 통과 · 판정 0.4초 · dev 743행 확정위반 32 · 확정무위반 53 · 보류 658.
- **시연:** 검수 → 위반 확정 → 고쳐 쓰기 → 사실 확인 답 → 카피 생성 → 광고 생성 → 이력까지 한 번에 돌아가요.

## 6. 멘토께 여쭤볼 것

1. **데이터 양:** 1만 건은 못 채웠어요(예산). 지금 양(2.5~4.6천)에 정답을 규칙으로 만드는 방식이면 충분한지, 더 늘린다면 어디에 쓰는 게 좋을지요.
2. **거절과 안전:** 위반 포장 0을 지키느라 거절이 늘었어요. 서비스 관점에서 이 방향이 맞는지요.
3. **평가:** 처음 보는 문장에 「살릴 수 있는가」 정답이 없어요. 사람 표본 검토 말고 쓸 만한 방법이 있는지요.
