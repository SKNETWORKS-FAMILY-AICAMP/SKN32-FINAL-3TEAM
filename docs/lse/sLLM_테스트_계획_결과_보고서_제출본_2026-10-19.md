## 1. 시험 대상 — 재생성 에이전트

CopyLane 에서 sLLM 은 **검수(판정 코어) 뒤에 붙는 재생성 에이전트**다. 검수가 지적한 문장을 그 자리에서 고쳐 쓰고, 고친 문장은 판정 코어로 돌아가 재판정을 받는다.

```
[판정 코어 에이전트]  문장 분할 → 품목(모르면 사용자가 분기 선택) → 근거 검색 → 사전 · 인코더(D4-20) → 판정 → 조건부 위반 질문
        │ 지적 문장 + 위반 유형 + 고른 품목 분기 + 사용자의 답으로 다시 판정한 결과
        ▼
[재생성 에이전트 (sLLM)]
   ① 1단계 LoRA — 위반만 지운 「담백한 안」 또는 「합법화 불가」
   ①' 🆕 되살리기 — 「불가」라도 질병 · 의약품 · 시술 표현 없는 화장품 기능 주장이면 공식 문구 + 심사 조건
   ② 후처리 — 원료명 · 공식 기능성 문구 · 필수 병기 · 🆕 화장품에 건기식 문구 / 제품 이름만 남음 → 보류
   ③ 관문 — 위험 출력이면 보류 · 🆕 화장품 가이드라인 출처 사전 낱말은 화장품일 때만
   ④ 2단계 LoRA (다듬기) — 식품 · 건기식 · 화장품만
        ▼
[판정 코어 에이전트]  ⑤ 재판정 — 같은 품목 분기로 읽는다 (D-119)
        ▼
  화면: 후보 / 조건부 후보(사람이 조건 확인) / 보류(사람 검토) / 만들지 못했어요
```

| 시험 대상 | 구성 요소 | 소스 |
|---|---|---|
| 모델 | 베이스 Qwen3-4B-Instruct-2507 · 1단계 LoRA **q4b-n2**(채택 결정 · 잠금 등재 대기) / **q4b-v14**(지금 서버 판) · 2단계 `q4b_polish` | `train_stage1_v5.py` · `sllm_meta.py` |
| 데이터 확장 | 교사 모델(gpt-4.1)이 위반 문구 · 교정 생성, 조건부 정답은 공개 원천 규칙 | `gen_expand_stage1.py` |
| 안전장치 | 되살리기 · 후처리 · 관문 | `postfix.py`(`rescue_cosmetic` · `label_check`) · `stage_gate.py` |
| 에이전트 간 연결 | 서빙 · 앱 BFF(분기 · 답 전달) · 재판정 | `sllm_service.py` · `app/routers/user.py`(`review_rewrite`) · `app/routers/sllm_client.py` |
