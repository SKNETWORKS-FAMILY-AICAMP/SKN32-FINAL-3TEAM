## 2. 착수 순서 — 무엇이 무엇을 막나

### 🔴 이 계획의 결론 한 줄

> **층 2·3(사람·실측)은 코드를 기다리지 않는데, 지금 둘 다 안 돌고 있습니다.**
> 층 0·1 을 끝낸 뒤 시작하면 **그때 리드타임이 통째로 남습니다.** 지금 병렬로 엽니다.

```
층 0  값이 한 바퀴 돈다          ①→②      ← 여기가 Phase 0 게이트
층 1  값을 채운다                ③ ④       ← 층 0 뒤
층 2  사람만 하는 것             ⑤ ⑥       ← 🔴 지금 시작 (코드 대기 없음 · 리드타임)

층 4  나중                       ⑩ ⑪ ⑫
```

이 문서를 쓰며 인용한 **D 44개를 원장 본문과 전문 대조**했습니다 (D-100 자신이 *「색인만 보고 인용하지 않는다」*고 정한 절차입니다). 내 쪽 오인용 넷은 고쳤고, **저장소 쪽에 남은 것이 둘**입니다.

| 부르는 이름 | 원장 본문이 실제로 말하는 것 | 어디서 그렇게 부르나 |

| **「D-100 = 근거 없이 판정 적지 않는다」** | D-100(1,607자 전문)은 **「매트릭스 id ↔ 레지스트리 키를 `ALIAS` 로 잇고 게이트 19 로 지킨다」** 입니다 | 작업 지침 |

🚨 **그런데 「D-72 fail-closed」가 두 가지 뜻으로 갈려 쓰이고 있습니다.**

| | 뜻 | D-72 본문과 | 쓰는 자리 |
