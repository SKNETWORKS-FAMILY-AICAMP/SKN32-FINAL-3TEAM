## 수집기 공통 규약

| # | 규약 |
|:-:|---|
| 1 | 모든 수집기는 **`registry.require(source_id, use="U1")`** 로 시작 |
| 2 | 원본은 `raw/` 에 **무손상 저장 · 덮어쓰기 금지** |
| 3 | `manifest.jsonl` 에 1행 append — `{source_id, fetched_at, url, sha256, bytes, rows}` |
| 4 | `sha256` 동일하면 스킵 |
| 5 | API 호출 `sleep(0.5)` 이상 + 재시도 3회 (지수 백오프) |
| 6 | 크롤링형은 **`robots_checked_at` 기록 후**에만 실행 |
| 7 | 🚨 **모든 산출 행에 `provenance` + `redistributable` 기록** — AI Hub 유래가 섞이면 그 데이터셋은 공개 배포 불가 |
| 8 | 업체명·대표자명·상표명은 **등급 무관 수집 직후 마스킹**. 제품 유형명·수치는 보존 |
