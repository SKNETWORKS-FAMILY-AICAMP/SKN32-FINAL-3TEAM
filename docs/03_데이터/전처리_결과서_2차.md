### 6-3. 🆕 적용 제외 목이 검색 상위를 차지한다 (㊷)

D-238 은 「다만 … 제외한다」의 하위 목(해당하면 **위반이 아닌** 경우)을 위반 근거로 쓰지 않기로 했고, 라벨 쪽은 게이트로 집행됐다. **(c) 청크에 제외 표시를 다는 것은 아직 청크에 없다** (정본 B · `law_norm` 재추출).

| 본 것 (A · `1742009` · 질의 1건 · D-40) | |
|---|---|
| 「이 제품은 암 예방에 좋습니다」 식품표시광고법 근거 상위 5 | [별표 1]제1호가목1) · 제1조 · 75449 제1조 · 69549 제2조제1항제3호 · [별표 1]제1호라목2) |
| 그중 별표 둘 | **둘 다 적용 제외 목**(특수의료용도식품 · 질병정보 병기) |
| 금지 본문 — 제8조제1항제1호 · [별표 1]제1호가목 | 청크는 **있다**(A `chunks.jsonl`) · 상위 5 에 **없다** → 코퍼스가 아니라 순위 문제 |
| 목적 조항(제1조) | 법 둘의 근거 10 칸 중 3 칸 |

- 짐작되는 기제 — 제외 목 청크의 `context` 에 부모 목의 금지 문장이 통째로 들어가고, 임베딩 · 리랭커 입력은 `context + text` 다. 제외 목이 금지 문장을 그대로 들고 부모와 경쟁한다. 부모가 점수로 밀렸는지 규범당 상한으로 밀렸는지는 **안 쟀다**
- 🔴 **탐침 정답도 제외 목을 정답으로 센다** — 질의 31건 중 **12건**의 `want` 가 D-238 표의 제외 목을 덮는다(와일드카드 11 · 「면역력 강화」 는 `[별표 1]제3호나목` 하나). §6 의 「상위 5 안 7/31」 에 제외 목으로 맞은 줄이 섞였을 수 있다 — 갈라 세지 않았다
- 제외 목을 어떻게 다룰지(검색에서 뺄지 · 표시하고 위반 좌표는 부모 목으로 올릴지)는 **판정 대기**다
