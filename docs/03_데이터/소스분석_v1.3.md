## 2. 판정

### 2-0. 🚨 v1.1 정정 — AI Hub 판정을 뒤집습니다

**v1.0에서 AI Hub 데이터 전부를 「배포 모델 학습 금지」로 판정했는데, 틀렸습니다.**

#### 무엇을 잘못 읽었나 — 두 개의 축을 하나로 뭉갰습니다

이용정책 본문의 *"승인을 받지 않은 다른 법인·단체·개인에게 제공, 양도, 대여, 판매하여서는 안 됩니다"* 를 보고 **U4(배포)가 막힌 것**으로 읽었습니다. 그리고 기획서 4-2절의 전파 규칙을 적용했습니다.

```
배포 모델 학습 = { f | f.U1 AND f.U4 }
        ↓ U4가 막혔으니
     U1도 막힌다  →  "AI Hub는 배포 모델 학습에 못 쓴다"     ← 🚨 여기가 오판
```

**AI Hub FAQ 원문이 정확합니다.**

> - AI허브에서 다운로드 받은 데이터로 학습하여 만들어진 **AI모델과 서비스는 자유롭게 배포, 활용하실 수 있습니다.**
> - AI허브 데이터를 활용해 개발한 모델을 **영리적으로 판매, 활용하는 행위는 제한하지 않으나** AI허브 데이터를 사용하였음을 명시하여야 합니다.
> - 다만, NIA 및 구축기업과 사전 협의한 경우를 제외하고 **데이터를 재가공하여 배포하는 행위**는 원칙적으로 불가합니다.

**막히는 것은 「데이터 재배포」이지 「모델·서비스 배포」가 아닙니다.** 둘은 다른 축인데 제가 같은 것으로 취급했습니다.

#### 고친 방법 — `NOREDIST` 플래그로 축을 분리

```
U4  모델·서비스 배포     ←  다섯 질문의 「배포」 열이 답한다
NOREDIST  데이터 재가공·배포 금지  ←  제약 플래그로 따로 표시한다

수정된 전파 규칙
  배포 모델 학습 = { f | f.U1 AND f.U4 }      ← NOREDIST는 여기 걸리지 않는다
  데이터셋 공개  = { f | NOREDIST 없음 }
```

## 6. 광고 카피는 어디서 오는가 — 결론

**「실제 집행된 한국어 광고 카피를 대량으로 합법 수집」은 경로가 없습니다.** 세 곳을 다 확인했습니다.

| | 카피 텍스트 | 대량 수집 | 판정 |
|---|:-:|:-:|:-:|
| **Meta 광고 라이브러리** | ✅ UI에서 **본문 전문 열람 가능** | ❌ API가 KR 상업광고 0건 · UI 자동수집은 약관 위반 | **수기 평가셋용** |
| **Google ATC** | ✅ 헤드라인·설명문 열람 | ❌ 공식 API 없음 · BigQuery는 정치광고 전용 | **수기 보조** |
| **KOBACO AiSAC** | ❌ **애초에 없음** | ❌ 다운로드·상업이용 금지 | **탈락** |
| **국내 이커머스** | — | ❌ **공식 리뷰 API 경로 부재 확정** (쿠팡·네이버·올리브영) | **탈락** |

### ★ 그래서 경로를 바꿉니다

**규제기관 데이터가 오히려 낫습니다** — 광고 문구가 **라벨과 함께** 공개돼 있기 때문입니다.

```
❌  "실제 광고를 많이 모으자"           →  경로가 없다
✅  "위반 판정이 붙은 광고를 모으자"     →  공정위 의결서 · 식약처 행정처분 · 부당광고 보도자료
✅  "심의 통과한 광고를 모으자"          →  기능성표시식품 공개목록 · 인정 기능성 문구
✅  "결함 주입으로 부족분을 채우자"      →  규칙표 10종 양방향 (수집·전처리 기획 4-7절)
```

> ★ **광고 카피가 아니라 「라벨이 붙은 광고 카피」가 필요했던 것**이고, 그건 이미 1·2층에 있습니다.
> Meta 광고 라이브러리는 **수기 100~200건을 `test_holdout`에만** 넣습니다 — 학습 출처(의결서)와 기관이 달라 홀드아웃 품질이 크게 오릅니다.
