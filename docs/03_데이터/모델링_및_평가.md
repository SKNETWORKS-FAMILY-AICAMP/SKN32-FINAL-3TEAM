## 1. 판정 구조 — 무엇을 학습하고 무엇을 학습하지 않나

| 구성 | 학습 | 무엇 | 상태 |
|---|:-:|---|---|
| 판정 인코더 | ✅ 파인튜닝 | 문장 → 위반 유형 후보와 신뢰도 | 3차 재학습 · test 1 회 결과 대기(인코더 담당 보고서) |
| **사전 + 판정 규칙** | ❌ | 금지 표현 사전의 적중으로 위반을 확정한다 · 그 밖은 보류 | ✅ 그래프에서 돈다(§2) |
| **위험도 하한** | ❌ | 처분 기준표에서 읽는 등급의 바닥 | ✅ |
| **품목 분기 · 증명서 사유** | ❌ | 전제 표와 승인받은 문안 | ✅ |
| 검색 임베딩 | ❌ (사전학습 모델 적용) | KURE-v1 · 조문 청크 벡터화 | ✅(§5) |
| 리랭커 | — | 두 모델을 나란히 재기로 했다 | ⬜ 미선정 |

**왜 학습하지 않는 쪽을 따로 두나** — 인코더와 사전이 같은 데이터로 배우면 오류가 함께 난다. 사전은 학습이 없어 오류가 독립이다. 인코더가 붙은 뒤 코드 하한을 거는 재료는 **법령 · 고시가 열거한 용어와 제품 사실 규칙뿐**이고, 사례에서 뽑은 낱말은 하한 재료가 아니라 유형 후보다(D-313 ③)

### 2-2. 판정 규칙 (`app/graph.py` `_judge_one` · 판 `rule-0.3.0-dict`)

| 순서 | 조건 | 판정 |
|:-:|---|---|
| 1 | 사전을 훑지 못했다 | 미판정 |
| 2 | 자격 있는 항목이 이 법의 인용으로 걸렸다 | **위반 확정** — 근거 조문 · 뺄 구간 · 불가 사유가 붙는다 |
| 3 | 유형은 잡았는데 인용 좌표를 세우지 못했다 | 근거 없음(D-224) |
| 4 | 그 밖 | **보류** — 자격 없는 항목이 걸렸으면 유형 후보를 싣는다(D-269) |

- 임계값이 없다 — 규칙 판정에는 점수도 문턱도 없다. 문턱은 인코더가 붙을 때 생긴다
- **불가 사유 표**(`INFEASIBILITY_OF`) — 유형 하나에 사유 하나: 질병 예방 · 치료 표방 · 의약품 오인 · 후기 · 체험기 기만 = 절대형 / 건강기능식품 오인 · 기능성화장품 오인 = 자격형 / 거짓 · 과장 · 소비자 기만 · 부당 비교 · 비방 · 실증책임 위반 = 실증형(D-59 · D-308)
- 이 표를 학습 분할의 라벨 조건과 대조하면 방향이 어긋나는 행이 6.8% 다(226 / 3,339 · 원장 10-03 ㊿-36). 표를 품목 · 법 · 호로 쪼개도 줄지 않았다 — 사유가 유형이 아니라 문장의 표현 부류에 달렸기 때문이다

### 2-3. 위험도 하한 · 품목 분기

- **하한** — 처분 기준표(서명된 판)에서 읽는다. 한 전제 안에서 두 법이 걸리면 높은 쪽이고 근거는 모두 붙인다(D-272). 기준이 없으면 위험도를 지어내지 않고 보류로 내린다
- **품목 분기** — 전제 여섯 · 전제마다 법 묶음과 기준 문안 한 줄. 품목을 모르면 모든 전제에서 같은 위반일 때만 확정한다(D-319)
- **증명서 사유 문안** — (법, 유형, 사유)로 꺼내는 승인된 일곱 줄(D-320)
- 구조는 [`../02_설계/AI_시스템_아키텍처.md`](../02_설계/AI_시스템_아키텍처.md) §3 ~ §6

### 3-3. 인코더 학습 때 지켜야 하는 것

1. 조건 M 은 학습에서 뺀다 · 조건 D · L 은 음성 · 그 밖은 `근거` 의 호가 양성이다(D-296 개정 2)
2. 평가 분할로 모델 · 문턱을 고르지 않는다(D-175) — 고르는 것은 학습 분할 안의 검증 묶음으로
3. 인코더 학습에 사전을 입력 특징으로 넣지 않는다 — 넣으면 둘의 오류가 독립이라는 전제가 깨진다
4. 모델을 고르는 기준은 종전 6종 그대로 두고 결과 표는 6종 기준 · 8종 기준을 둘 다 낸다 — 기준을 바꾸면 앞 판과 견줄 수 없다
5. 골든셋과 라벨은 공개 git 에 올리지 않는다 — 공유 저장소로 받는다(D-249)

### 4-1. 읽는 법

- 확정 재현율이 낮은 것은 규칙이 보수적이어서다 — 사전에 안 걸리면 보류하고, 품목을 모르면 모든 전제에서 같을 때만 확정한다
- **무조건부 0.1% 는 「찾지 못했다」가 아니다** — 찾은 것 대부분이 「품목을 골라야 한다」는 보류(`cat_unknown` 89 행)로 나갔고 정답 품목의 분기 안에는 확정이 남아 있다(78 행 · 유형 맞음 57)
- 적법 오탐 0 은 보수적 규칙의 다른 얼굴이다 — 인코더가 붙은 뒤에도 유지되는지가 볼 것이다
