⚠️ 팀의 운영 판정이지 법적 확정 판단이 아닙니다. 학내 프로젝트 범위에서 5인이 같은 기준으로 판단하기 위한 것입니다. 상업 배포 전에는 각 소스의 이용조건을 다시 확인하고, 경계 사례는 2인 확인 + 근거 URL 기록을 남기십시오. ❔는 확인되지 않았다는 뜻이지 허용된다는 뜻이 아닙니다 — G0는 확정될 때까지 G2로 취급합니다. 비용은 금액만이 아니라 리드타임(승인 대기)을 포함합니다 — 9주 프로젝트에서는 2주 심사가 3만원보다 비쌉니다.

등급이 뜻하는 것

등급은 소스가 아니라 추출물(FRAGMENT)의 속성입니다 — 한 문서 안에서도 조각마다 갈립니다.

「써도 되는가」와 「쓸 가치가 있는가」는 다른 질문입니다. 써도 되지만 가치 없는 것, 가치 있지만 못 쓰는 것이 각각 있습니다.

4

다섯 질문과 판정 규칙

질문무엇을 묻는가판정 규칙막히면 무슨 일이
학습
U1
 AI 모델 학습에 투입할 수 있는가 G3 → 원문 그대로 · G2 → 추출한 사실만 · G1 → 금지 · NC/재배포금지가 붙고 배포 모델이면 → 금지 DAPT·sLLM 파인튜닝에서 제외. 군집화 같은 배치 분석은 별도 판정
상업 상업적으로 써도 문제가 없는가 NC 없음 AND U4 허용 → ✔가능 · NC → ✕불가 · BY만 → 출처표시 △조건부 학내 진행은 되나 제품화 경로가 막힘. 지금 구분 안 하면 나중에 데이터를 뜯어내야 함
원문 문장 원문을 그대로 쓸 수 있는가 G3 → ✔가능 · G2 → ✕불가 (사실·어휘·수치만) · G1 → ✕불가
🚨 저작권은 표현을 보호하고 사실은 보호하지 않는다 — 이것이 G2의 근거		 금지 표현 목록은 취해도 해설 문장은 못 취함. 원 출처(법령·고시)로 소급하면 G3로 올라감
인용
U3

배포
U4

U4 모델 배포 → 이 열이 답한다 · NOREDIST → 데이터 재가공·배포 금지 플래그로 따로 표시

이 표에서 바로 나오는 조치

🚨 오늘
KLUE-RoBERTa를 kcbert-base로 교체할지 반나절 안에 결정
모델 카드와 HF API를 교차 확인한 결과 license 키가 아예 없습니다. 데이터셋의 CC BY-SA가 모델 가중치에 적용된다고 볼 근거가 없습니다. beomi/kcbert-base는 Apache 2.0이고, 댓글·구어체 사전학습이라 광고 문구 도메인에 오히려 더 적합합니다. 나란히 베이스라인을 돌려 성능차를 재고 결정하십시오 — 지금이면 비용 0, 파인튜닝 후에 알면 트랙 하나가 날아갑니다. (D-60)
오늘
법제처 OPEN API OC 키 신청
3층 전체와 4층 별표가 이 키 하나에 달려 있습니다. 발급 1~2 영업일 — 선행기간(~8/27) 내에 던져야 1W 수집이 밀리지 않습니다.
오늘
문의 2건 동시 발송 — 화장품협회 · KOBACO
협회는 해설서 이용조건(G2→G3 승격), KOBACO는 MCR의 재배포·AI 학습 조항입니다. MCR 약관에는 그 조항이 아예 없는데, 없다는 건 허용이 아니라 미정입니다. 서면 답변을 받아두는 것이 이 프로젝트에서 가장 값싼 리스크 제거입니다.
선행
KREI 식품소비행태조사를 먼저 받아 본다 — 절차가 0이다
신청·승인·회원가입 없이 SPSS 원자료가 즉시 나옵니다(3,188가구 / 성인 5,851명). 다만 건강기능식품 문항 포함 여부가 미확인이니 성인 설문지 PDF를 먼저 열어보십시오 — 1시간.
1W
기능성 원료 소스 3중 중복을 하나로 정리
식품안전나라 게시판(고시형 96 + 개별인정형 472) · API 15058359 · API 15074311이 같은 데이터를 다르게 담고 있을 수 있습니다. 셋을 열어 대조하고 하나를 정본으로 정하십시오. 안 하면 세 벌을 다 수집합니다.
2W
Meta 광고 라이브러리에서 수기로 100~200건 — 평가셋 전용
API는 한국 상업광고를 0건 반환합니다(EU 외 지역은 정치·이슈 광고만). 하지만 UI에서는 현재 집행 중인 한국 화장품·건기식 광고 본문 카피를 그대로 볼 수 있습니다. 자동 수집은 약관 위반이니 수기로, 평가셋에만. 학습 출처와 분리되어 홀드아웃 품질이 크게 오릅니다.
🔄 정정
AI Hub 격리 정책을 뒤집습니다 — 막을 곳이 반대였습니다
FAQ 원문 확인 결과 모델·서비스 배포와 영리 판매는 자유이고, 막히는 건 데이터 재가공 배포뿐입니다. 앞서 잡았던 data/g2_nc/(학습 스크립트에서 제외)는 과잉 차단이었습니다. 바꿀 것: 디렉터리를 data/g2_norepub/로, doctor 14번을 「학습 스크립트가 참조하는가」에서 「데이터셋 공개·배포 스크립트가 참조하는가」로. 그리고 골든셋 각 행에 provenance 필드를 두어 AI Hub 유래분을 추적하십시오 — 그 골든셋은 공개 배포할 수 없습니다.
선행
디렉터리 물리 분리 + doctor 검사 + 캐스케이드 삭제 테스트
5인이 각자 작업하면 문서 안내만으로는 반드시 누가 그냥 엽니다. 경로 정책은 grep으로 강제하십시오. 캐스케이드 삭제는 데이터가 쌓인 뒤에는 만들 수 없습니다.
