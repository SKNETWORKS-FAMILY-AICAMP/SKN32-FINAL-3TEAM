## 2. KURE-v1 — 검색 임베딩

| 항목 | 값 |
|---|---|
| 식별 | `nlpai-lab/KURE-v1` · 라이선스 MIT(설계결정기록 스택 대조) |
| 출력 | 1024차원 · 코사인 거리(pgvector `<=>`) |
| 최대 입력 | `max_seq_length` 8192 — 우리 입력 최대는 564 토큰(원장 ㉛ · ㊴) |
| 입력 문자열 | `context + text` (`scripts/embed.py` `embed_input()`) · 벡터마다 입력 sha256 을 `chunk_embedding.input_sha256` 에 적는다(D-176) |
| 모델 고정 | 🚨 코드에 이름을 상수로 두지 않는다 — `chunk_embedding.model_id` 를 DB 에서 읽어 **저장 벡터를 만든 그 모델**로 질의를 인코딩한다(`app/retrieve.py`) |
| 색인 규모 | 청크 6,667 (클론 B · `332184a`) |
| 측정 | 첫 30건 이상 탐침 — 상위 5 안 7/31 · 후보 50 안 12/31 · 조회 중앙 약 250 ms (학습결과서 2차 §4) |
| 재현 | `launcher.py` 의 `embed` — 선언에 없는 청크를 거두고 「DB 가 선언과 같다」를 확인하며 끝난다 |

## 3. 판정기 B 사전 — 규칙 산출물

| 항목 | 값 |
|---|---|
| 파일 | `data/derived/banned_terms.jsonl` · DB `dict_entry` |
| 크기 | **574** 항목 · 단독판정 자격 452 |
| 만드는 곳 | `preprocess/dictionary.py` — 🔴 **`train` 문서에서만** 만든다(사례집 2026 · 공정위 · 기능성 원료). 해설서는 안 넣는다 |
| 항목 칸 | 표현 · (유형, 근거) **짝** — 근거는 조문 인용 꼴(D-282 ⑦) · 신뢰도(단독판정 / 모호 / 적법중첩) |
| 매칭 | `scripts/eval_rule.py` — 정규화문 위 부분 문자열 · 적법중첩 · 모호 항목은 단독으로 위반을 내지 않는다(D-156) |
| 성능 | 적법 오탐 3/60 (5.0%) · 식품 1호 R 0.471 · 3호 R 0.052 · 5호 R 0.055 · 4 · 6 · 7호 0(구조적) (학습결과서 2차 §3) |
| 한계 | 사전에 항목이 없는 호는 구조적으로 못 맞힌다 · 부분 문자열이라 대상 · 사람 소개 안의 병 이름(「당뇨 전단계 환자」)을 가르지 못한다 |
