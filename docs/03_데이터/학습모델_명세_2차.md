## 2. KURE-v1 — 검색 임베딩

| 항목 | 값 |
|---|---|
| 식별 | `nlpai-lab/KURE-v1` · 라이선스 MIT(설계결정기록 스택 대조) |
| 출력 | 1024차원 · 코사인 거리(pgvector `<=>`) |
| 최대 입력 | `max_seq_length` 8192 — 우리 입력 최대는 564 토큰(원장 ㉛ · ㊴) |
| 입력 문자열 | `context + text` (`scripts/embed.py` `embed_input()`) · 벡터마다 입력 sha256 을 `chunk_embedding.input_sha256` 에 적는다(D-176) |
| 모델 고정 | 🚨 코드에 이름을 상수로 두지 않는다 — `chunk_embedding.model_id` 를 DB 에서 읽어 **저장 벡터를 만든 그 모델**로 질의를 인코딩한다(`app/retrieve.py`) |
| 색인 규모 | 청크 6,667 (클론 B · `332184a`) · 🔄 적용 제외 표시(0021) 뒤에도 6,667 = DB = 임베딩(원장 09-25 ㊹ · 클론 B / ㊺ · 클론 A) |
| 측정 | 첫 30건 이상 탐침 — 상위 5 안 7/31 · 후보 50 안 12/31 · 조회 중앙 약 250 ms (학습결과서 2차 §4) |
| 재현 | `launcher.py` 의 `embed` — 선언에 없는 청크를 거두고 「DB 가 선언과 같다」를 확인하며 끝난다 |
| 🔄 그래프 연결 | 판정 그래프의 `retrieve` 노드가 넓은 검색 `rt.wide()` 를 한 번 부르고(법마다 폭만큼 · 두 갈래 따로) 법별 노드가 `rt.law_view()` 로 제 법 근거를 거른다(W4 · 원장 09-25 ㊷ · 클론 A). 🚨 지금 판정은 검색 결과로 위반을 정하지 않는다 — 근거 조문은 사전 항목의 인용에서 온다([`모델링_및_평가.md`](모델링_및_평가.md) §5) |
| 🔄 허용 목록 | 앱이 내려받을 수 있는 모델은 `nlpai-lab/KURE-v1` 하나다(`app/settings.py` `ALLOWED_MODELS`) |
