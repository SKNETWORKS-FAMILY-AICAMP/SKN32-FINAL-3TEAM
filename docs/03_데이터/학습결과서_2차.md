## 1. 판정 구조 — 무엇을 학습하고 무엇을 학습하지 않나

| 구성 | 학습 | 무엇 | 상태 |
|---|:-:|---|---|
| **판정기 A** 인코더 | ✅ 파인튜닝 | 골든셋 `train` 으로 문장 → 위반 조문(호) | 박수진 보고서 |
| **판정기 B** 룰 매칭 | ❌ | 사전(`banned_terms` 574)을 문장에 맞춘다 · **학습 데이터를 공유하지 않는다** | 기준선 측정 완료(§3) |
| 검색 임베딩 | ❌ (사전학습 모델 적용) | KURE-v1 · 조문 청크 6,667 벡터화 | 측정 중(§4) |
| 리랭커 | — | `bge-reranker-v2-m3`(0.6B) vs `bge-reranker-base`(0.3B) 나란히 재기로 함 | ⬜ 미선정 |

**왜 A 와 B 를 따로 두나** — 둘이 같은 데이터로 배우면 오류가 **상관**된다. B 는 학습이 없어 오류가 독립이고, **둘의 불일치가 곧 위험 신호**다(`scripts/eval_rule.py` 머리말 · 기획문서 6-2). 그래서 B 의 낮은 점수는 실패가 아니라 **「그래서 모델이 필요하다」의 근거**다(D-156 — 같은 표현이 위반이자 적법이다).

### 2-1. 누수를 막는 규칙 — 인코더 학습 때 지켜야 한다

1. **주입 행은 평가 split 에 못 들어간다** — DB CHECK `ck_golden_injected_not_holdout`(평가 split 전부 · D-170)
2. **학습에 나타난 문구는 평가에서 뺀다** · 반대로 **적법 평가 문장과 겹치는 학습 행은 학습에서 뺀다**(09-21 · 팀장 판정 (나))
3. **해설서는 전량 평가 쪽이다** — 학습에도 사전에도 넣지 않는다. 넣으면 식품 평가가 누수된다(⑰)
4. **평가 조건 칸** — 해설서 행은 조건 C · A · B → 위반 기대 · M → 저신뢰(`low_conf`) · D → 판정 대상 아님. 채점에서 D · M 은 뺀다(D-286)
5. **다중 라벨 문서 98건은 평가에서 뺐다** — 두 호를 함께 건 의결서는 문구가 어느 호인지 적혀 있지 않다. 학습 다중 라벨은 1,662행(25.9%)
6. **재배포 불가** — `redistributable = false` 7,394행. 🚨 골든셋 · 라벨은 **공개 git 에 올리지 않는다** — 공유는 Google Drive 공유 저장소(`data-sync` · D-249)
7. 변경금지(ND) 원천의 행은 쓰기 직전에 멈춘다(원장 ㉖) — 현재 ND 행 0
8. 🆕 2026-09-30 (D-296) — **학습 입력은 `golden.jsonl` 의 `split = train` 행 전부다.** 조건 칸(`조건`)으로 행을 거르지 않는다 — 라벨 없는 행(조건 D 인정 조건문 · 조건 L 결정문 무혐의 문구)은 음성(위반 유형 0)으로 넣는다. 🚨 DB `golden_sample` 은 조건 D · M 행을 싣지 않으므로(D-285 개정 4) 학습 입력이 아니다. 승인 문구는 조건 A · 3호 양성이다(D-294) · 이 문서의 수(6,425 · 음성 194)는 D-294 전의 판이다

### 2-2. 알고 있는 학습 데이터의 약점

| | 약점 | 인코더에 주는 영향 |

## 3. 판정기 B 기준선 — 인코더가 넘어야 할 선

**평가 구성** — `test_sentence` 2,007행 중 채점 **1,555** (해설서 1,364 · 공정위 131 · 적법 60) · 뺀 행 452 (조건 D 271 · M 181). `scripts/eval_rule.py` · 클론 B · 팀장 실행(⑱).

### 3-1. 식품표시광고법 제8조① — 해설서

| 호 | 정답 | 적중 | R | P (⑰ 판) |
|---|--:|--:|--:|--:|
| 1호 질병 예방 · 치료 | 70 | 33 | **0.471** | 0.917 |
| 3호 건강기능식품 오인 | 465 | 24 | 0.052 | 0.774 |
| 4호 거짓 · 과장 | 404 | 0 | 0 | — |
| 5호 소비자 기만 | 219 | 12 | 0.055 | 0.923 |
| 6호 비방 | 148 | 0 | 0 | — |
| 7호 부당 비교 | 70 | 0 | 0 | — |

- ⑱ 은 합의 채택 26행의 조건을 바로잡은 판이다 — **적중 수는 그대로**이고 R 이 움직인 것은 분모다. P 는 ⑰ 판 값을 적었다(⑱ 에서 적중 수가 같다)
- **1호 R 0.471 은 누수가 아니다** — 해설서 행이 `train` 에 0 · 사전 입력은 학습 문서뿐 · 해설서 평가 문구 = 사전 항목 0개. 맞힌 33행은 사례집의 **병 이름 낱말 9개**(당뇨 · 비만 · 변비 · 아토피 …)가 원천을 건너 맞은 것이다. 놓친 37행은 **영유아 병 이름**(배앓이 · 영아산통 …)으로 사례집에 없다
- **구조적 0** — 사전에 단독판정 항목이 없는 호는 못 맞힌다: 식품 6 · 7 · 8호 · 표시광고법 2 · 3 · 4호. 식품 4호는 항목 46 이 있는데 적중 0 — 항목은 건강기능식품 신체 효과 낱말, 해설서 4호는 조제식 품질 주장이다
- 막힌 적중 274(⑰ 판) — 모호 143 · 적법중첩 131 은 D-156 대로 **단독 판정에 쓰지 않는다**
