# 판정 근거(source) 등급 기준 — 초안

- **작성**: psj (2026-09-14)
- **상태**: 초안 · 팀 논의 전 — `00_설계결정기록.md` D-번호 편입 전 단계
- **범위**: `/admin/sources` 화면 (목업 "판정 근거 관리")에서 쓰는 `source.grade` 값을
  L1~L4 로 어떻게 판정할지에 대한 기준표. 등급을 화면에서 매기고 승인하는 절차
  (2인 확인, D-66 · §8 ⑬)는 아직 안 정해져 있고, 이 문서는 그 절차가 참조할
  "판단 기준"만 먼저 정리한 것이다.

## 배경

목업 화면 안내문: *"L1 법적 기준 → L2 행정 기준 → L3 공식 참고 → L4 내부 검증.
커뮤니티·비공식 자료는 판정 근거로 등록하지 않습니다."*

`db/schema.sql` 의 `source` 테이블은 등급을 사람이 직접 입력하고, 다른 사람이
확인해야 저장되게 제약을 걸어뒀다:

```sql
grade_decided_by    TEXT NOT NULL,
grade_reviewed_by   TEXT NOT NULL,
CONSTRAINT ck_source_four_eyes CHECK (grade_decided_by <> grade_reviewed_by)
```

즉 등급 판정 기준이 주관적이면 판정자와 확인자가 서로 다른 결론을 낼 수 있고,
그러면 2인 확인 자체가 의미 없어진다. 그래서 **최대한 사실 확인으로 판단할 수
있는 기준**이 필요하다.

## 등급 판단 기준표

| 등급 | 정의 | 판단 기준 (해당하면 이 등급) | 예시 |
|---|---|---|---|
| **L1 법적 기준** | 법률·시행령·시행규칙 등 법 조문 자체 | 국가법령정보센터에 게재된 법률/대통령령/부령이며, 조문 번호로 특정 가능 | 「식품 등의 표시·광고에 관한 법률 시행령」 |
| **L2 행정 기준** | 정부·공공기관이 발행한 고시·행정규칙 | 관보에 고시되었거나 소관 부처가 공식 문서번호를 부여한 행정규칙/고시/지침 | 「건강기능식품 기능성 표시·광고 심의기준」(식약처 고시 제OOOO-OO호) |
| **L3 공식 참고** | 공공기관이 배포했지만 법적 구속력은 없는 안내·가이드라인 | 정부기관 명의로 발행됐지만 고시번호가 없는 해설서·가이드북·Q&A | 「식약처 광고 가이드라인(2026)」 |
| **L4 내부 검증** | 팀이 직접 정리·검증한 내부 자료 | 위 L1~L3 자료를 근거로 팀이 재정리했고, 원출처를 역추적 가능해야 함 | 「건기식 허용 표현 사전 v4.2」 |

## 판정자용 확인 순서

1. 국가법령정보센터에서 조문으로 검색되는가? → 예면 **L1**
2. 관보 고시번호(또는 행정규칙 번호)가 있는가? → 예면 **L2**
3. 정부·공공기관이 공식 발행한 문서인가(번호는 없어도 기관 명의)? → 예면 **L3**
4. 1~3 전부 아니지만, 원출처가 L1~L3 중 하나로 역추적되는 내부 정리 자료인가?
   → 예면 **L4**
5. 원출처를 특정할 수 없거나 커뮤니티/비공식 자료 → **등록 자체를 거부**
   (목업 안내문과 일치)

## 확인자(2인 확인) 역할

판정자의 "판단"을 재검토하는 게 아니라, 판정자가 확인한 **사실 근거**
(법령정보센터 링크, 고시번호, 발행 기관명)가 실제로 그 등급 조건을 충족하는지
재확인하는 역할로 좁힌다. 이렇게 하면 확인자 재량이 줄어 2인 확인이 형식적
서명이 아니라 실제 검증으로 작동한다.

## 남은 결정 사항 (팀 논의 필요)

- 이 기준표를 소스 등급(`source.grade`)에만 적용할지, `dict_entry`(표현 사전)
  등록에도 확장할지 — `dict_entry` 는 현재 2인 확인 제약이 스키마에 없음
- 화면에서 등급을 입력하는 흐름 자체(즉시 반영 vs 승인 대기 상태) — §8 ⑬
- `grade_decided_by` / `grade_reviewed_by` 를 채우는 주체가 항상 `governor`
  역할이면 되는지, 별도 권한이 필요한지
