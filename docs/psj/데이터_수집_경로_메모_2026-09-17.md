# 데이터 수집·적재 경로 메모 (2026-09-17)

> 작업 메모 — psj. 확정 내용 아님. 설계 결정은 `00_설계결정기록.md`(D-XX)가 단일 출처, 여기는 실행 절차 정리용.

## 전체 경로 3단계

### 1단계 — 원천 수집 (`collect/`)
`.env`에 API 키 필요. 키 넣는 법:
```
uv run python launcher.py setkey FOODSAFETY_KEY
uv run python launcher.py keys      # 값이 아니라 지문으로 확인
```

| 키 | 용도 | 발급처 | 시점 |
|---|---|---|---|
| `LAW_OC_KEY` | 법제처 API — 법령·고시 | open.law.go.kr, 이메일 @ 앞부분만 | 지금(1W) — 없으면 사전 구축이 통째로 멈춤 |
| `DATA_GO_KR_KEY` | 공공데이터포털 — 식약처 API 4종 | data.go.kr 활용신청, 즉시~1일 | 곧 |
| `FOODSAFETY_KEY` | 식품안전나라 — 건기식 기능성 원료 | data.go.kr 키와 다름, openapi.foodsafetykorea.go.kr에서 별도 발급 | 1W |
| `AIHUB_KEY` | AI Hub — 5층 코퍼스 | aihub.or.kr, **키와 별개로 데이터셋마다 승인 필요(GATED)** | 곧 |

수집 실행:
```
uv run python launcher.py collect <source_id>
```
소스별 수집기 매핑은 `collect/__init__.py`의 `COLLECTORS` 표가 단일 출처.

### 2단계 — 전처리 (`preprocess/`)
마스킹([P3]) → 정규화([P2]) → 문장분할([P4]) 순서로 자동 처리. `data/raw/`를 읽는 건 `collect`·`preprocess`만 허용(게이트로 막힘).

### 3단계 — 골든셋 꾸리기 (인코더 학습 데이터 최종 단계)
```
uv run python launcher.py golden --write
```
내부적으로 4단계 순서 실행:
1. `preprocess.split --write` — 분할(**반드시 먼저**, 평가 문구가 학습 자료로 새는 것 방지)
2. `preprocess.dictionary --dump` — 조문 사전
3. `preprocess.inject --dump` — 결함 주입(규칙 기반 위법화, train만)
4. `preprocess.golden --dump` — 물질화(문장+라벨을 최종 jsonl로)

`--write` 없이 실행하면 미리보기만 하고 아무것도 안 씀 — 먼저 이걸로 확인.

## 확인 명령
```
uv run python launcher.py inventory   # 이 기기에 뭐가 있는지 현황
```
