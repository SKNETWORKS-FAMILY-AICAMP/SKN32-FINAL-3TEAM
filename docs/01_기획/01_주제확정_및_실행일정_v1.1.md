## 6. 발표 준비 (W9~W10)

### 6-1. 데모 시나리오 — 두 장면 고정

```
[장면 1 - 진입점 A, 30초]
  위법 문구 붙여넣기
    -> 문장별 빨간 줄 + 근거 조문 + 위험도
    -> 대체 문구 3종 세트 (본문 + 필수 병기 문구 + 배치 지시)
    -> 재판정 통과 O

[장면 2 - 진입점 B, 45초]  ★ 하이라이트
  제품/세그먼트 선택
    -> 지향 키워드 칩: 초록 9개(통과) + 회색 3개(차단)
    -> 회색 칩 hover: "'눈 피로 회복' = 질병 표방 / 식품표시광고법 제8조"
    -> 통과 칩으로 카피 3안 -> 프론티어에 3점
    -> 균형안 클릭 -> 본문 + 병기 문구 + 배치 + 근거
```

> ★ **차단된 회색 칩이 데모의 핵심입니다.** 생성 도구가 아니라 **판정 코어를 품은 생성 도구**임이 한 화면에 보입니다.

### 6-2. 반드시 준비할 답변 3개

| 질문 | 준비된 답 |
|---|---|
| *"[심의케어](https://passtuneos.com/) 같은 게 이미 있지 않나요?"* | **우리가 먼저 인정합니다.** 그다음 — 선행 도구는 **건기식 단일 법령·검수 전용**. 우리는 **다법령 라우팅 + 판정 코어가 곧 생성기의 리워드 모델 + 진입점 B**. ⚠️ 「위험도 정량화」는 차별점에서 뺐습니다 |
| *"페르소나가 실제 소비자를 대변한다는 근거는?"* | **없습니다. 그래서 그 주장을 하지 않습니다.** 우리가 주장하는 것은 **「세그먼트 언어 정렬」**까지이고, 전환율은 말하지 않습니다 |
| *"취약계층을 정밀 타깃하는 것 아닌가요?"* | **먼저 인정하고 먼저 대응책을 제시합니다** — pain point 축을 **설계에서 제거**했고, 취약 세그먼트 감지 시 **판정 임계값을 강화**합니다 |
