### 1-3. ★ 이 두 표에서 읽어야 할 것 셋

**① 강사 미팅(8/31)의 「15만원/1건」이 확인됐습니다.** 기획서 1-5절의 「3~16.5만원」 범위와도 일치합니다.

**② 🚨 「재심의 무료」가 우리 가치 주장 하나를 무너뜨립니다.**
*"한 번에 통과시켜 재심의 비용을 아낀다"* 는 **쓸 수 없는 논거**입니다. 두 기관 모두 재심의가 무료입니다.
남는 것은 **비용이 아니라 시간**입니다 — 반려되면 회차를 다시 기다립니다.
그래서 **소요일 확보가 ③의 핵심**이 됩니다(§1-4).

**③ ★ 「상세페이지 5만원~」이 D-93의 근거를 하나 늘립니다.**
심의 기관이 **상세페이지를 과금 단위로 삼는다**는 것은, 그것이 실무의 작업 단위라는 뜻입니다.
D-93에서 출력 프로파일을 상세페이지·인스타로 잡은 것이 **자의적 선택이 아님**을 이 표가 뒷받침합니다.

| **회차 주기** (반려 시 다음 접수까지) | 같은 문의 | 반려의 실제 비용이 여기서 나온다 |

### 1-5. 🚨 법무법인 자문 단가 — 조사 방법을 바꿔야 합니다

공개 검색으로 나오지 않습니다. 로펌이 단가를 공표하지 않습니다.

**선택지**

- (a) 직접 문의 — 회신 편차가 크고 리드타임이 길다
- (b) **공표된 공공 자문 단가로 대체** — 중소기업 법률지원 사업 등
- (c) ★ **논거에서 뺀다** — 협회 수수료만으로 대체 비용을 세운다

**잠정 (c)를 권합니다.** 협회 수수료는 **공표된 확정 수치**이고, 자문 단가는 추정이 섞입니다.
D-75가 시장조사 보고서를 기각한 이유(*"큰 숫자를 인용하려다 시장 정의를 못 잡았다는 인상"*)가
여기에도 그대로 적용됩니다 — **약한 숫자를 하나 더 얹는 것이 강한 숫자 하나보다 나쁩니다.**

## 2. 🚨 주장하지 않는 것 — 먼저 못 박습니다

설계결정기록에 이미 적힌 경계선입니다. **이 문서에서도 지킵니다.**

> *"3~16.5만원은 협회 심의 수수료이고 **기업·중소 브랜드가 내는 돈**이다.
> **1인 셀러의 지불 의사는 검증되지 않았다.**
> 「제재가 이쪽에 몰려 있고 이들에게 법무팀이 없다」까지만 말하고,
> 「따라서 시장이 N억이다」는 말하지 않는다."*

- ❌ 심의 수수료 × 업체 수 = 시장 규모
- ❌ 1인 셀러도 15만원을 낼 것이다
- ✅ **이 일에는 현재 건당 15만원과 N영업일이 든다**
- ✅ **제재는 법무팀이 없는 쪽에 몰려 있다** (①이 채워지면 수치로)

## 3. ① 자체 산출 — 추가 수집 0

수집(S2-01 · S2-03 · S2-05)이 끝나면 **추가 수집 없이** 나옵니다 (수집리스트 S5-07).

```
입력   공정위 의결문(표시광고법 필터) + 식약처 행정처분결과 API + 과징금 고시(2026.7.1)
         │
산출   1) 부당광고 제재 건수 — 연도별 · 업종별(화장품/건기식/식품)
       2) 1건당 평균·중앙값 제재 수준 — 과징금액 / 업무정지 일수
       3) 위반 유형별 분포 — 무엇이 가장 자주, 무엇이 가장 비싸게
       4) 반복 위반 비율 — 2026.7.1 개정으로 가중이 50% → 100%
```

★ **이 계산은 제품의 일부입니다.** 위험도 산정의 「예상 제재 금액」이 같은 분포에서 나옵니다 —
D-74와 같은 **「하나를 만들어 두 번 쓴다」** 구조입니다.

> 🔄 **2026-09-21 정정** — **D-182(확정)가 금액 환산을 막았다.** 위험도는 **처분 일수(업무정지)의 서수**로 매기고 과징금 **금액은 계산하지 않는다**
> (매출을 모르고 묻지 않는다). 위 문단의 「예상 제재 금액」은 「처분 수준」으로 읽는다. 위 산출 ①-2 의 **과징금액**은 제품 쪽으로 가지 않는다.
