### 🔶 3번 — 재료는 다 있는데 한 곳에 모여 있지 않다

시장조사는 오히려 과잉이다(실측 2회). 부족한 것은 **BM 을 한 절로 세운 자리**다. 지금 수익 구조는 **7-6절(배포 형상) 안에 부산물처럼** 들어 있다 — *"배포 경계를 과금 경계와 일치시킨다"* 는 **배포 결정문이지 BM 서술이 아니다.**

- 필요한 것: `경제성_근거.md` 에 **「수익 구조」 절 하나** — 이원 과금(무료 판정 / 유료 생성) · 대체 비용 대비 가격 위치 · 고객 수 역산.
- 🚨 **미확보 2건이 그대로 남아 있다** (`경제성_근거.md` 1-4 · 1-5) — 협회 처리 소요일 · 법무 자문 단가. **「얼마나 빨라지는가」를 아직 숫자로 말할 수 없다.**
- 경쟁 비교표는 **부록 A-4** 에 있다. 제출본에서는 **본문으로 올린다** — 부록은 읽히지 않는다.

### 🔶 4번 — 🚨 그림이 한 장도 없다

```
02_프로젝트기획서.md   이미지 참조 0개 · mermaid 블록 0개 (264 KB 전부 글)
```

내용은 충분하다. **문제는 매체다.** 워드 양식의 「시스템 구성 기획」에 붙일 **구성도가 실물로 존재하지 않는다.** 지금 상태로 제출하면 아키텍처를 글로만 설명하게 되는데, 3-2·3-3 의 에이전트 구성은 **글로 읽으면 관계가 안 잡힌다.**

**최소 3장이 필요하다** —
1. **진입점 A(검수) 에이전트 흐름** — 3-2절
2. **진입점 B(생성) 에이전트 흐름 + 팬아웃·팬인** — 3-3절 · 5-9절
3. **배포 형상** — 7-6절 (클라우드=판정 / 온프레미스=생성, 과금 경계와 일치)

> 🚨 **이것은 기획 단계에서 만들어 두는 것이 싸다.** 5W~6W 의 「AI 시스템 아키텍처」 산출물이 같은 그림을 요구하고, 그때는 T4 가 피크다.

### 🔶 7번 — 배정은 끝났는데 기획서가 그것을 모른다

**사실원장에는 실명 배정이 있다** (2026-08-31 확정) —

| 이름 | 트랙 배정 |
|---|---|
| 오한빈 (팀장) | T1 데이터·거버넌스 · T2/T3 구조(harness) |

| 공동 | T2·T3 실험 = 설정 하나씩 분배 (D-94) |

그런데 **기획서 8-5절 첫 줄은 아직 이렇게 되어 있다** —

> *"**인원 배정은 하지 않습니다.** … 사람 배정은 착수 시점(W1)에 확정합니다."*

**기획서만 읽으면 R&R 이 비어 보인다.** 배정이 끝났으므로 이 문장은 이제 사실이 아니다.

## 2. `[기획] WBS_양식(2).xlsx` — 🚨 여기가 가장 크게 빈다

양식은 **Smartsheet 갠트 템플릿**이다. 요구 열 —

```
WBS 번호 | 작업 제목 | 작업 소유자 | 시작일 | 마감일 | 기간 | 작업 완료 비율
+ 갠트 격자 12주 × (월·화·수·목·금)
```

`docs/01_기획/03_작업일정.md` 가 가진 것과 대조하면 —

| 양식이 요구하는 것 | 우리 문서 | 판정 |
|---|---|:-:|
| 주차·기간·공휴일 | **2장 주차별 작업일 산정** (1W~9W · 작업일 38일 · 공휴일 4일 손실) | ✅ **초과** |
| 마일스톤 | **4장** (Phase 게이트 4 · 중간발표 9/15 · 기능동결 10/16 · 최종 10/26) | ✅ **초과** |
| **WBS 번호 체계** (1.0 / 1.1 / 1.1.1) | 없음 | ❌ |
| **작업 단위 분해** | 없음 — **산출물 단위**로만 배치돼 있다 (3장) | ❌ |
| **작업 소유자** (실명) | 없음 — **트랙 이름**까지만 (3장) | ❌ |
| **작업별 시작일·마감일·기간** | 없음 — **주차**까지만 | ❌ |
| **작업 완료 비율** | 없음 | ❌ |

### 🚨 갠트 격자가 우리 주차와 어긋난다

양식 격자는 **월~금 5칸**이 1주다. 그런데 우리 공식 주차는 **금요일 시작**이다 (1W = 8/28 금 ~ 9/3 목 · `03_작업일정.md` 2장).

**그대로 얹으면 모든 막대가 한 칸씩 밀린다.** 대응은 둘 중 하나다 —

1. **갠트는 달력 날짜로 채우고**, 주차 라벨(`1W`…`9W`)은 **별도 행에 병기**한다 ← 권장
2. 격자 헤더를 우리 주차 경계로 고쳐 쓴다 (양식 훼손)

> 12주 격자에 우리는 9주다. **남는 3주는 비우지 말고 선행 기간(8/17~8/27)을 앞에 붙이면** 격자가 오히려 맞는다 — `03_작업일정.md` 6장이 이미 그 기간을 작업일 9일로 산정해 뒀다.

### 필요한 일

**`03_작업일정.md` 3장의 산출물 표를 작업 단위로 한 단계 더 쪼개고 소유자·날짜를 붙이는 것** — 이것이 WBS 제출본의 실체다. 재료는 있다(산출물 20건 · 트랙 5 · 실명 배정 · 주차별 작업일). **없는 것은 분해와 배정뿐이다.**

## 3. `[모델배포]_요구사항 정의서_양식.xlsx` — 🚨 **문서 자체가 없다**

```
분류: 대분류 | 중분류 | 요구사항 ID | 소분류(기능설명) | 추가설명 | 비고
```

`docs/` 전체에서 **「요구사항 정의서」에 해당하는 파일이 검색되지 않는다.**

- `00_산출물현황.md` 는 이것을 **「1W~2W · 팀장 + 전 트랙」** 으로 잡아 뒀다.
- 🚨 **오늘이 1W 마지막 작업일(9/3 목)이다.**
- 기획서의 「요구사항 ①②③④」 는 **과정이 준 4대 요건**(수집·전처리·평가·배포)이지 **기능 요구사항이 아니다.** 이름이 같아서 채워져 있는 것으로 착각하기 쉽다.
