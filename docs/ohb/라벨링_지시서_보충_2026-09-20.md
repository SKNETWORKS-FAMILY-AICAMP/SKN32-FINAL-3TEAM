## 팀원이 할 일 — 이것만 읽어도 됩니다

1. 팀장이 보낸 두 파일을 받습니다 — `<내 이름>__round2_labelsheet.csv` · `유형번호표.csv`
2. CSV 를 **엑셀로 그냥 엽니다** (한글 안 깨집니다)
3. **`유형번호` 칸 하나만** 채웁니다

| 적는 것 | 뜻 |
|---|---|
| `1` ~ `8` | 그 유형 — 번호는 `유형번호표.csv` 의 **위에서부터** 보다가 걸린 것 |
| `1,5` | 둘 다 맞으면 쉼표로 (§3 에서 위에 있는 것을 먼저) |
| `0` | **범위밖** — 여덟 유형 어디에도 자리가 없다 |
| (비움) | **모르겠다** — 빈칸은 실패가 아니라 판단입니다. 억지로 채우지 않습니다 |

4. 헷갈린 점은 `메모` 칸에 자유롭게 적습니다 — 판정할 때 읽습니다
5. 다 했으면 **파일 이름을 바꾸지 말고** 팀장에게 보냅니다

**칸 설명** — `참고` 는 기관(식약처·행정심판·공정위)이 어떻게 분류했는지, `보기` 는 그 분류 안의 후보를 **번호와 함께** 보여 줍니다.
🚨 `보기` 밖의 번호를 적어도 됩니다 — **기관의 분류가 아니라 문구를 봅니다** (09-10 §5).

### ⛔ 하지 말 것

- `문구`·`지문` 칸 수정 · 행 삭제 — 고치면 가져오기가 **멈춥니다**
- **다른 사람과 상의해서 맞추기** — 독립으로 붙여야 일치도(κ)가 뜻을 갖습니다
- 모르는 것을 「일단」 채우기 — 빈칸이 낫습니다

## 왜 이렇게 바뀌었나 — 팀장 *「사람이 직접 하는 건 정확도가 떨어질 것 같은데」*

사람이 틀리는 것을 없앨 수는 없습니다. 그래서 **틀린 것이 드러나게** 짰습니다.

| 장치 | 무엇을 잡나 |
|---|---|
| **기관 분류 안에서 고르기** | 8개 중 고르지 않고 기관이 묶어 둔 2~3개 중 고릅니다 |
| **전원 겹침 30%** | 같은 행을 모두가 붙여 일치도(κ)를 잽니다 — 낮으면 사람이 아니라 **지시서**를 고칩니다 |
| **검증 행 20개** | 정답을 아는 문구(공정위 의결 주문)를 섞었습니다. 라벨로 쓰지 않고 **지시서가 통하는지** 봅니다 |
| **기존 시트 재검** | 1차 시트 248행을 **이미 붙인 사람 말고** 다른 사람이 가린 채 다시 붙입니다 |
| **판정** | 갈린 행만 모아 팀장이 정합니다 — 다수결이 아닙니다. LLM 답은 참고 칸으로만 둡니다 |

## 팀장(정본)이 할 일

```
uv run python scripts/label_round.py plan round2 --who 오한빈,권소라,소성민,박수진,이서은
(각자 채운 CSV 를 받는다)
uv run python launcher.py labelsheet import build/labels/<이름>__round2_labelsheet.csv --sheet data/derived/label_rounds/round2_labelsheet.jsonl
uv run python scripts/label_round.py compare --sheet data/derived/label_rounds/round2_labelsheet.jsonl build/labels/<이름>__round2_labelsheet.csv …
(판정표 build/labels/판정__round2_labelsheet.csv 의 `최종번호` · `판정자` 를 채운다)
uv run python scripts/label_round.py decide build/labels/판정__round2_labelsheet.csv --sheet data/derived/label_rounds/round2_labelsheet.jsonl
uv run python scripts/label_merge.py data/derived/labels/*.jsonl
```

- `plan` 은 **한 번만** 돌립니다 — 같은 이름으로 다시 돌리면 멈춥니다(표본이 갈린다 · 보충 09-17 §1)
- 시트·라벨은 **git 에 안 올립니다** — `derived-manifest --write` → 원장 커밋 → `data-publish` (D-249)
- 🚨 **행정심판 행**을 평가셋에 넣으려면 골든셋 계보표(`preprocess/lineage.py`)에 한 줄이 필요합니다.
  없으면 `golden --write` 가 「모르는 계보」로 **멈춥니다**(정상). 재배포 불가로 둘지는 판정입니다
