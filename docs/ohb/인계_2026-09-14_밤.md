### 3-2. 🆕 `db-drift` — 선언과 실제를 대조 (40번)

임시 DB **둘**을 옆에 세워 다섯 축을 대조한다: **열 · ENUM 값(순서까지) · 제약 · 인덱스 · 뷰 정의.**

```
① copylane_driftcheck_decl  ← db/schema.sql 직접 적용    = 선언
② copylane_driftcheck_head  ← alembic upgrade head       = 실제
```

🚨 **선언이 declare 한 객체만 대조한다.** head 에만 있는 것(런타임 7표 · `alembic_version`)은
**차이가 아니라** 참고로 이름만 낸다 — 선언에 없는 것을 차이라 하면 매번 빨강이 뜨고 곧 안 읽힌다.
⛔ **어느 쪽이 맞는지는 말하지 않는다.** 다르다는 것만 말하고 고치는 두 갈래를 낸다.

🚨 `scripts/db_fresh_check.py` 에 임시 DB 를 세우는 넷(`guard_real_db`·`make_db`·`drop_db`·
`alembic_head`)을 **공용으로** 뺐고 저쪽이 import 한다 — **지우는 명령이 두 벌이 되는 것**을 막았다 (D-99).

### 3-4. ✅ 별표에 인용 좌표가 선다 (0015 · 판정 A · 🔴 미커밋)

`citation()` 이 별표를 구조적으로 거부했고(계층이 「2.가.1」), 좌표 없는 근거는 판정에 못 간다.

**광고 문구가 실제로 걸리는 자리**다.

**판정이 걸린 자리 넷**

1. **번호는 머리글에서만 읽는다.** `annex_no`(파일명 일련번호)는 머리글 있는 24건이 전부 일치했지만

   ⛔ 반대로 **우리가 붙인 이름(`구역N`)은 포기한다** — 원문에 없는 말을 넣지 않는다.
3. **`LEFT JOIN` 이다.** `JOIN` 이면 `document` 행이 없는 청크를 **검색에서 통째로 지운다.**
4. **깊이 4는 안 옮긴다** — 실측 2행이고 **모양을 안 봤다** (D-188).

**게이트 셋** — 인용 21건(별표 10건 신설 · `gate` 표 신규 부착) · `test_모든_질의가_별표_번호를_싣는다`
(`d.annex_no`·`d.title`·**`LEFT JOIN`**) · `test_목_글자표가_두_벌인_채_갈리지_않는다`.
