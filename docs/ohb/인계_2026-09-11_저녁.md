## 0.5 🚨 이것부터

### ① 🔴 **원격이 바뀌었다** — `origin` 이 이제 공개 저장소다

```
origin   https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN32-FINAL-3TEAM.git   ← 정본 · 공개
backup   https://github.com/LukasBeanz/CopyLane_Final_project.git            ← 보관 · 비공개
```

`git push` 는 이제 **공개 저장소로 간다.** 브랜치 여섯 전부 `origin/…` 을 추적하도록 재설정했다
(`git remote rename` 이 브랜치 추적을 `backup` 으로 바꿔 버리므로 `branch -u` 여섯 줄이 필요했다 —
전환에서 가장 흔히 놓치는 자리다).

🚨 **`backup` 은 지우지 않는다.** PR #26~#29 의 이력이 거기에만 있다. **PR 은 git 객체가 아니라
GitHub 데이터라 push 로 안 따라온다** — 머지 커밋의 *메시지*만 이력에 남고, 그 번호는 공개
저장소에서 아무 데도 안 걸린다. 공개 저장소의 PR 은 **#1 부터 새로 쌓인다.**

★ **앞으로는 push 를 먼저 다 하고 그다음 PR.** PR 은 만들 때의 브랜치 상태를 잡아서,
푸시가 뒤에 오면 커밋 하나가 뒤에 남는다. 오늘 PR #1 에서 실제로 그랬고 #2 로 메웠다.

### ② 🔴 **09-17 안건의 전제가 틀렸다**

`violation_t` 에 「인정범위_초과」를 넣을지가 판정일 안건인데, **조문에 이미 자리가 있었다.**

> **식품표시광고법 시행령 별표1 제5호 아목** — 식약처장이 **인정한 사항의 일부 내용을 삭제하거나
> 변경하여 표현**함으로써 기능 또는 효과에 대하여 소비자를 오인하게 하는 표시ㆍ광고

D-185 가 잡은 `2024-19` 천마추출물이 정확히 이것이다. 그래서 안건이 바뀐다 —

    종전   "새 enum 값을 만들 것인가"
    지금   "기존 소비자_기만 + 근거조문 제5호 아목으로 충분한가"

🚨 그리고 **분리하면 태어나자마자 「측정 불가」**다 — 「넓음」이 **10건**뿐이라 D-40(30건 미만)에
걸린다. **못 재는 유형을 하나 더 만드는 셈**이다.
⬜ **「좁음 39 + 넓음 10 = 49」를 한 덩이로 본 전제도 재검토가 필요하다.** 좁음은 인정보다 *덜*
주장한 것이라 오인 소지가 낮다 — 안전 방향이고, 위반 라벨이 필요한 것은 넓음 쪽일 수 있다.

**판정 자리에서 `docs/ohb/violation_article_초안_2026-09-11.md` 를 펴면 된다.**
11값 전부의 초안 매핑 · 확정이 필요한 것 다섯 · 조문 원문이 그 안에 있다.

## 4. 🚨 함정 — 오늘 실제로 밟은 것

**① 커밋이 훅에 세 번 막혔다.** `trailing-whitespace` · `end-of-file-fixer` 가 **파일을 고치면서**
종료코드 1 을 낸다. 실패가 아니라 **훅이 고친 것**이고, `git add -A` 를 다시 하고 커밋하면 통과한다.
🚨 그때 `git push` 를 먼저 치면 **"Everything up-to-date"** 가 뜬다 — 올릴 커밋이 없어서다.
커밋이 실제로 생겼는지 `git log --oneline -1` 로 확인하고 밀 것.

**② 그 훅이 보존 폴더를 고치고 있었다.** `assets/brand/legacy/` 11개와 발표자료의 프로토타입
HTML 을 건드렸다 — **읽기 전용 보관소를 다듬는 것은 그것이 있는 이유를 없앤다.** 제외 규칙을 넣었다.
🚨 `.pre-commit-config.yaml` 은 **ASCII 전용**이라(파일 머리말이 그렇게 적어 뒀다) 한글 경로를
직접 못 쓴다 — 「비ASCII 문자로 시작하는 경로」로 잡았다.

**③ `.env.example` 이 스캐너 눈 밖에 있었다.** allowlist 에 경로 통째로 들어 있었고, 하필
**D-111 이 「예제 파일에 키가 들어갈 구조적 이유가 있다」고 적어 둔 바로 그 파일**이다.

**④ PR 을 푸시보다 먼저 만들면 커밋이 뒤에 남는다.** §0.5 ① 참조.

**⑤ 🔴 이 세션은 셸이 그 폴더에 못 붙었다.** Windows 9월 8일 업데이트 때문이다. 파일 읽기·쓰기는
됐지만 **명령을 못 돌렸다** — 그래서 코드 작업(재수집 · 벡터 배선)은 전부 미뤘다.
**테스트 못 한 코드를 게이트 176건이 있는 저장소에 넣지 않는다.**
