`질병_예방치료_표방` 으로 들어 있습니다.

> 8. **탈모 증상의 완화에 도움을 주는 화장품.** 다만, 코팅 등 물리적으로 모발을 굵게 보이게 하는 제품은 제외한다.

**맞게 잡은 것**이고, 「탈모약 수준…발모까지」는 고친 뒤에도 `의약품_오인` 으로 **그대로 잡힙니다.**

🚨 **이 문구 아홉은 제가 지어낸 것입니다 — `[임의]`.** 조문 인용과 매칭 결과는 실측이지만
**문장 자체는 표본이 아닙니다.** 성능 수치로 쓰면 안 됩니다 (D-191).

### 왜 이렇게 됐나 — 안전장치가 **식품 축에만** 있습니다

`preprocess/dictionary.py:205` 의 `단독판정 = not overlap and len(types)==1` 에서
`overlap` 이 대는 적법 목록은 —

```
approved_docs()  →  mfds_hf_ingredient_board  178문구  ← 전부 건강기능식품
```

**화장품 적법 표현 0종.** 그래서 화장품 어휘에는 `적법중첩` 심사가 **한 번도 돌지 않습니다.**
모듈 첫머리가 스스로 「차이는 완곡 표현과 **그 제품이 인정을 받았는가**다」라고 적어 두었으니
**설계는 이 축을 이미 알고 있었고, 비어 있는 것은 데이터 한 칸**입니다.

## 4. 🔄 **1판 정정 둘** — 전수를 재고 나서 뒤집힌 것

### 4-1. 「뒤집힘 4건」은 과장이었습니다 — **통째로 뒤집힌 것은 없습니다**

1판에서 저는 2013 별표가 현행법과 **4곳 뒤집혔다**고 썼습니다. 별표를 다 옮겨 놓고 보니
**어느 것도 통째로 뒤집히지 않았고, 좁은 표현 하나씩만 열렸습니다.**

| 2013 별표 금지 문장 | 현행 시행규칙 제2조 | 실제 |
|---|---|---|
| 「**탈모방지 및 양모, 발모** 효과가 있다.」 | **8호** 탈모 **증상의 완화** | 🔶 **방지·양모·발모는 여전히 금지.** 「증상 완화」만 열림 |
| 「아토피」·「여드름」 금지 / **「여드름성 피부에 사용하기에 적합하다(입증 시)」 허용** | **9호** 여드름성 피부 **완화**(인체세정용) | 🔶 **2013에도 조건부 허용이 있었다.** 조건이 「입증」 → 「기능성 심사」로 **바뀐 것** |
| 「임신선, **튼살을 제거 또는 완화**한다.」 | **11호** 튼살로 인한 **붉은 선을 엷게** | 🔶 제거·완화는 여전히 금지 |
| 「**가려움을 완화**한다(피부건조 기인 제외).」 | **10호** 피부장벽 회복 → **가려움 등 개선** | 🔶 일부 열림. **아토피 표방은 여전히 불가** |

⛔ **그러니 「낡아서 못 쓴다」가 아닙니다.** 별표의 금지 문장은 지금도 대부분 유효합니다.
🔴 **문제는 별표가 아니라 우리 사전의 입자입니다** — 별표는 「탈모**방지**」라는 문장을 금지했는데
우리 사전은 **「탈모」라는 낱말**을 들고 있습니다. §3 의 오탐은 거기서 나옵니다.

★ 그래서 **3층 금지의 근거를 「뒤집힘」이 아니라 「문서가 스스로 법적 효력 없다고 적었다」로
옮깁니다.** 1판의 근거 배치가 틀렸습니다.

### 4-2. 「대안 B 를 먼저」도 틀렸습니다 — **B 혼자서는 「탈모」를 못 풉니다**

1판에서 저는 「별표 허용 열을 `approved` 에 넣으면 「탈모」가 자동으로 빠진다」고 썼습니다.
**실측하니 안 빠집니다.** 2013 별표 허용 45종 **어디에도 「탈모」가 든 문장이 없기 때문**입니다
(탈모가 열린 것은 2020.8.5 시행규칙 개정이고 별표에는 반영이 없습니다).

```
A  2013 별표 허용 45종          단독판정 414 → 412  (-2)   ['붓기', '피부미백']
B  현행 시행규칙 제2조 11개 호      단독판정 414 → 413  (-1)   ['탈모']
A+B                          단독판정 414 → 411  (-3)   ['붓기', '탈모', '피부미백']
```

**둘 다 넣어야 §3 의 오탐 넷이 사라집니다.** 어느 한쪽만으로는 안 됩니다.
🔶 1판에서 제가 「B 의 효과 크기는 미측정」이라며 「틀릴 수 있는 자리」로 적어 둔 곳이
**실제로 틀린 자리였습니다.**
