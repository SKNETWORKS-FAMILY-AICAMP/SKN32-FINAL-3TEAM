## 1. 🔴 클로드가 옮겨 적은 2인 확인 서명 둘

**상황** — `scripts/registry_review.yaml` 의 두 서명이 검토자 본인이 아니라 클로드가 적은 것이다.
주석에 그렇게 적혀 있다 (`:251` `law_go_kr` 마스킹 정책 · `:689` `mfds_cgm_expc` 등재 — 둘 다
「2026-09-19 팀장이 『권소라 확인』을 전달해 클로드가 옮겨 적었다」).
프로젝트 지침은 `reviewed_by` 를 **사람만 채운다**고 하고, 채우면 D-66 이 무효가 된다고 적는다.
그때는 팀장의 현재 지시를 따랐다(검토 09-19 §의 기록). 그리고 `mfds_cgm_expc` 주석에는
「검토요청 §2 ③(법제처 OPEN API 이용약관 조건)은 결과가 적혀 있지 않다」가 남아 있다.

**용어** — *2인 확인(D-66)*: 판정한 사람과 다른 사람이 근거를 보고 서명해야 수집·사용 게이트가
열린다. 서명 칸이 **누가 적었는지**를 증명하지 못하면, 게이트가 열린 이유가 「확인했다」가 아니라
「누군가 칸을 채웠다」가 된다.

| 대안 | 얻는 것 | 떠안는 것 |
|---|---|---|
| (가) 그대로 둔다 — 주석이 경위를 밝힌다 | 일이 없다 | 지침과 어긋난 채 남는다. 외부 검토자가 보면 **2인 확인이 한 사람 손으로 채워진 사례**다 |
| **(나) ★ 권소라가 직접 확인한다** — 두 줄 옆에 본인이 `reviewed_note: 2026-09-2x 본인 확인` 을 커밋하거나 PR 댓글로 남긴다 | 서명이 본인 손을 거친다. 비용이 5분이다 | 권소라의 시간. ③ 이용약관 확인을 같이 해야 온전하다 |
| (다) 서명을 비우고 다시 받는다 | 가장 깨끗하다 | 비우는 순간 `mfds_cgm_expc` 수집 게이트가 닫힌다 — 5,129행이 「미서명 원천」이 된다 |

**권고 (나)** — 되돌리는 비용 없이 지침을 맞춘다. ③ 이용약관 확인 결과를 같은 커밋에 적는다.
🚨 이 파일에는 클로드가 손대지 않는다 (사람만 채우는 칸).

## 2. 🔴 행정심판 행의 계보 — round2 가 들어오면 골든셋 생성이 멈춘다

**새로 잰 사실** [컨테이너] — `scripts/label_round.py` `pool_decc()` 가 라벨 후보 행에
`"원천": "law_go_kr"` 를 단다(`:123`). 그런데 `preprocess/lineage.py` `GOLDEN_LINEAGE` 에는
`("law_go_kr", "real")` 이 **없다**(있는 것: `ftc_decisions_body` · `mfds_casebook` ·
`mfds_special_use_guide` 의 `real`, `mfds_hf_ingredient_board` 의 `approved`·`injected` …).
`lineage.py:32` 는 표에 없는 계보를 만나면 **멈춘다**(fail-closed · D-220 — 옳은 동작이다).
→ 팀원 round2 CSV 가 와서 행정심판 행이 `확정유형` 을 얻으면, 그다음 `golden --write` 가 멈춘다.
인계 §5-2 의 흐름(`label_merge` → `golden --write`)이 그 자리에서 끊긴다.

**용어** — *계보(lineage)*: 골든셋 행이 어느 원천의 어떤 종류(`real` 실사례 · `injected` 주입 …)에서

| 대안 | 얻는 것 | 떠안는 것 |
|---|---|---|
| **(가) ★ `("law_go_kr","real"): ("law_go_kr:golden", False)` 로 등재** | D-249 의 원칙(인용 광고 문구는 광고주 몫 → `False`)과 같다. 재결서 자체는 공공저작물이어도 **인용된 광고 문구**는 같은 논리 | 프래그먼트 `law_go_kr:golden` 을 `load_db.FRAGMENTS` 에도 한 줄 보태야 한다 (같은 커밋) |

**권고 (가)** — D-249 와 같은 선. 판정이 나면 lineage·FRAGMENTS 두 줄과 게이트(`test_label_path`)

## 3. 🟡 `/search` 에 재배포 축이 없다 — 지금은 새는 것이 없다

**상황** [컨테이너] — `POST /search` 는 인증 없이 조문 청크의 본문을 돌려준다. 거버넌스는
`app/retrieve.py` 의 WHERE 절(`source_use.allowed AND use_code='U2_rag'`)로 걸려 있다.
**재배포 가능 여부(`redistributable`)는 안 본다.** 오늘 레지스트리에서 `U2: allow` 이면서
`redistributable: false` 인 원천은 **0** 이다(49 전수) — 그래서 지금 새는 것은 없다.
새게 되는 조건: 누군가 재배포 불가 원천의 U2 를 열고 청크를 적재하는 순간. 그 원천 본문이
로그인 없이 통째로 나간다.

**용어** — *U2_rag*: 검색 근거로 쓸 수 있다는 이용 허가. *재배포 가능*: 원문을 남에게 그대로 내보내도
되는가. 둘은 **다른 축**이다 — 근거로 읽는 것은 되지만 원문을 그대로 보여 주면 안 되는 자료가 있다.

| 대안 | 얻는 것 | 떠안는 것 |
|---|---|---|
| (가) 그대로 — U2 를 여는 판정 때 사람이 본다 | 일이 없다 | 막는 자리가 **사람의 기억**이다 (D-117) |
| **(나) ★ WHERE 에 `redistributable` 을 한 줄 더 건다** — 불가 원천은 본문 대신 조문 좌표만 | 구조로 막는다. 오늘 결과는 안 바뀐다(해당 0) | 검색 코어 한 줄 + 게이트 한 건. 좌표만 내는 응답 모양을 계약(`contracts.py`)에 정해야 한다 |
| (다) `/search` 를 로그인 뒤로 | 노출 면이 준다 | 판정 API 와 같은 공개 경로라 화면 설계(ksr·lse)가 바뀐다 |

**권고 (나)** — 오늘 0건이라 지금이 싸다. 계약 변경이라 팀원 화면에 닿는지 먼저 본다.
