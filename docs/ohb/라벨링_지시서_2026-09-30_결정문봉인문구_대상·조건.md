## 0. 무엇을 하나

| | |
|---|---|
| 대상 | 봉인 평가셋(`split_manifest` 의 `test_sentence`) 결정문 **주문 문구** — 2026-09-30 동결 판 기준 68문서 119문구 (`guide_statute_round fs-input`) |
| 붙이는 것 | `대상` · `조건` (+ `주근거` 는 **원천 호를 그대로 옮긴다**) · `메모` |
| 붙이는 방식 | 독립 판독 둘 → 같으면 채택 · 다르면 팀장 판정표 (D-285) |
| 왜 | 봉인 문구 131행 검토(2026-09-30 · 모델 검토)에서 **이름만(28) · 원천 가림 상품명(24) · 광고 문구 아님(4)** 이 위반 양성으로 채점되고 있었다. 평가 모델은 **문구 하나만** 본다 — 문장만으로 판정되지 않는 행을 양성으로 두면 그 오답은 모델 탓이 아니다 |

- 🔴 **호는 새로 붙이지 않는다.** 의결서가 이 문구에 건 호(입력의 「원천 호」)가 정본이다(D-237). 판독은 그 호를 `주근거` 에 그대로 적는다(`공1`~`공4`). 두 호가 걸린 문서면 문구에 맞는 호 하나 또는 둘.
- 원천 호가 문구와 맞지 않아 보이면 `메모` 에 「원천 호 의문: …」 — 호를 바꾸지 않는다.

## 1. 붙이는 칸 (판독 TSV 한 줄)

`지문 \t 대상 \t 주근거 \t 부근거 \t 별표5목 \t 조건 \t 제외목 \t 메모`

| 칸 | 꼴 | 비고 |
|---|---|---|
| `대상` | `Y` · `N` | **N = 광고 문구가 아니다** — 의결서가 사실관계로 적은 설명 · 문장 조각이 광고 내용이 아닌 것(「피심인은 …」 · 「… 라고 광고하였다」의 앞뒤만) |
| `주근거` · `부근거` | `공1`~`공4` — **원천 호 중에서만** | 조건 D · M 이면 `-` 도 된다 |
| `별표5목` | `-` | |
| `조건` | `C` · `A` · `B` · `M` · `D` | 🔴 `L` 을 적지 않는다 — 원천이 위반이라 했다(적으면 팀장으로 간다) |
| `제외목` | `실증` 또는 `-` | |
| `메모` | 자유 | |

## 2. 조건 — 문구 **하나만** 보고 판정되는가

| 조건 | 뜻 | 예 |
|:-:|---|---|
| **C** | 문구만으로 위반이 선다 | 「경쟁사 제품은 발암물질 덩어리」 |
| **A** | 사업자·제품의 지위에 달린다(등록 · 인증 · 자격) | 「특허 받은 기술」 · 「○○협회 인증」 |
| **B** | 주장이 참인지 · 실증되는지에 달린다(표시광고법 제5조) | 「업계 최초」 · 「2배 오래갑니다」 |
| **M** | **무엇을 주장하는지가 문구에 없다** — 🔴 **이름만**(상품명 · 서비스명 · 요금제명 · 원천이 가린 상품명 `oo`) · 앞뒤 문장이 있어야 서는 조각 | 「GiGA LTE」 · 「노타모 5.5」 · 「광대역 LTE」 · 「뉴-에이맥스」 |
| **D** | 광고 문구이지만 주장이 아니다 — 표시사항 · 사용법 · 면책 | 「본 제품은 의약품이 아닙니다」 |

- 🔴 **이름만이면 M** — 이름 자체가 기만인 사건(원천 호가 공3 · 「진짜」 · 「천연」처럼 **이름 안의 낱말이 주장**)은 그 낱말로 판정한다: 「천연 ○○수」 → A. 낱말 없는 고유명사 · 모델명은 M.
- 🔴 **M 을 넉넉히 쓰지 않는다** — 문구 안에 주장이 있으면(「더 빠른」 · 「최초」) B · C 로 판정한다. 기준은 식품 지시서 §3 의 「주어 없는 문구의 주어는 제품」과 같다.

## 3. 판독과 채택 — 보도자료 지시서 §5 와 같다

- **같다** = 대상 · 조건 · 호 집합이 같다 · 보수 합성(C ↔ A·B → C) · D ↔ M → M
- 🔴 합의여도 팀장 — 조건 L · C·A·B 인데 호가 원천 호와 다름 (`fs_guard`)

## 4. 반영 — 골든 (`preprocess/golden.py`)

- 대기가 0 이면 봉인 결정문 주문 문구마다: **대상 N → 골든에서 뺀다**(수를 센다) · 대상 Y → `조건` · `판독` 칸을 붙인다(호 · 유형은 원천 그대로)
- M · D 는 채점하지 않는다(`eval_rule.scored`) · C · A · B 는 그대로 양성
- 🚨 이 판이 들어가면 **평가셋이 바뀐다** → 분할 입력 지문이 바뀌어 `split --write` · 동결을 다시 한다(봉인 문서는 그대로 · 문구 단위 표시만 바뀐다)
- 🚨 `split` 의 봉인 셈(문서 · 호 · D-40 의 30)은 문서 단위라 이 판을 모른다 — 문구 셈의 정본은 골든 · `eval_rule` 이다
