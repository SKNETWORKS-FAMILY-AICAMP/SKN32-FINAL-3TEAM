## 0. 왜 새 소스가 필요했나 — 1층 본체가 열리지 않았다

기획문서 1층은 공정위 의결서 경로를 **셋**으로 적어 뒀습니다.

| | data.go.kr | 레지스트리 | 상태 |
|---|---|---|---|
| 파일데이터 | 15103301 · 5,870건 | `ftc_decisions` ✅ 서명됨 | 🚨 **파일을 받을 수 없다** |
| 목록 API | 15103246 | `ftc_decisions_api` ✅ 서명됨 | 사건명·결정일자만. 광고 문구가 없다 |
| **본문 API** | **15103247** | ❌ **등재 자체가 없었다** | ← 이 요청 |

**🚨 파일데이터를 받을 수 없는 이유** (2026-09-02 실측):

> 제공형태: **기관자체에서 다운로드(제공데이터URL기재)** · URL `https://case.ftc.go.kr/ocp/co/ltfr.do` · 확장자 **PDF** · 전체 행 **5870**

data.go.kr 에는 **파일이 없습니다.** 등재만 하고 실물 PDF 는 공정위 사이트에 있으며 **일괄 다운로드가 없습니다.** 5,870개를 개별로 받거나, `case.ftc.go.kr` 을 별도 등재·판정해야 합니다(D-15 · 규약 6 robots 확인 포함).

목록 API 만으로는 **광고 문구가 나오지 않습니다** — 사건명·사건번호·결정일자·상세링크뿐입니다.

**→ 1층의 본체를 여는 실질 경로가 본문 API 하나입니다.**

## 2. 🚨 검토자가 따져 주셔야 할 것 — 셋

### ⓐ 서명이 덮는 곳과 실제로 부르는 곳이 갈린다

API 유형이 **LINK** 이고, `linkUrl` 이 **법제처**를 가리킵니다.

```
GET https://www.data.go.kr/tcs/dss/selectApiLinkUrl.do?publicDataPk=15103247
→ linkUrl: https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=cmtInfoGuide#ftc

실제 요청  https://www.law.go.kr/DRF/lawService.do?OC=..&target=ftc&ID=<결정문일련번호>&type=XML
```

인증이 **`OC`** 라 **`LAW_OC_KEY`** 를 씁니다 — 방금 서명하신 `law_go_kr`, 그리고 `ftc_decisions_api` 와 **같은 포털·같은 키**입니다.

🚨 `mfds_hf_ingredient` 에 다신 것과 같은 형태의 지적이 가능합니다 — *"검토자가 본 화면과 실제 이용 경로가 다르다"*. 다만 이번에는 실제 경로(법제처)의 이용조건도 **이미 확인돼 있습니다**(저작권법 제7조 + 공공데이터법, 영리 포함 자유 활용 보장 · `law_go_kr` 서명 근거와 같은 페이지).

### ⓑ 🚨 프래그먼트 구성이 `ftc_decisions` 와 **다르다**

`ftc_decisions`(PDF)에는 이 단서가 붙어 있습니다:

> 🚨 프래그먼트별로 등급이 갈린다 — 의결서 안 `<그림 N>` 광고 캡처는 광고주 이미지 저작물이라 **G1(미추출)**

**이 경로에는 그 문제가 없습니다.** XML 본문에 이미지가 들어오지 않습니다. **같은 원천이라도 경로가 프래그먼트 구성을 바꿉니다** — D-18 을 뒤집어 본 자리라 판정에 반영할지 봐 주십시오.

### ⓒ 마스킹 — 원천이 일부를 이미 가려 준다

실물 확인 (㈜24프로미 부당한 광고행위 건 · 2016서소1562):

```xml
<피심정보내용><![CDATA[주식회사 24프로미
서울 중랑구 용마산로89길 16, 1층(면목동)
대표이사 이ㅇㅇ]]></피심정보내용>
```

**대표자명이 이미 「이ㅇㅇ」로 가려져 옵니다.** 🚨 그래도 우리 마스킹을 끄지 않았습니다 — **원천의 정책이지 우리의 보장이 아닙니다.** 업체명과 피심인 **주소는 그대로** 옵니다 (D-17 대상).

## 3. 본문이 실제로 오는지 — 확인한 것

`type=XML` 로 부르면 결정문이 구조화돼 옵니다.

```
결정문일련번호 · 문서유형 · 사건번호 · 사건명 · 피심정보 · 회의종류 · 결정번호 ·
결정일자 · 의결문 · 주문 · 신청취지 · 이유 · 별지 · 결정요지 · 위원정보
```

🚨 **`type=HTML` 은 껍데기(1.8KB)만 오고 JS 로 채웁니다.** XML 이어야 본문이 옵니다.

「주문」에 금지된 광고행위가 원문으로 적혀 있습니다:

> 1. 피심인은 홈페이지에 **사실과 다른 조직도를 게재**하는 등의 방법으로 피심인이 대규모 조직을 갖춘 사업자인 것처럼 **소비자를 속이거나 잘못 알게 할 우려가 있는 광고행위**를 다시 하여서는 아니 된다.

최근 건도 실재합니다 — 디에이성형외과(2026.7.1.) · 에이비성형외과의원(2026.7.1.) · 뷰성형외과(2026.6.30.) 「부당한 광고행위에 대한 건」.

**★ PDF 보다 나은 점 셋**: ① 텍스트라 **OCR 불필요** ② 대표자명 **이미 마스킹** ③ **`<그림 N>` 캡처가 안 온다**(ⓑ).

## 5. 남는 것 (판정을 막지는 않습니다)

- **심의유형** 「개발단계: 자동승인 / 운영단계: 심의승인」 — 배포(U4) 시점의 선결 조건입니다. `ftc_decisions_api` · `mfds_hf_individual` · `cosmetic` 2건과 같은 조건입니다.
- **수집기 미작성** — 목록(`lawSearch`)으로 일련번호를 훑고 본문(`lawService`)을 받는 `collect/ftc_body.py` 가 필요합니다. `law_api.py` 와 같은 모양입니다.
- **모집단이 파일데이터와 다릅니다** — 목록 API 기준 8,255건이고 2006~2026 입니다. 파일데이터는 5,870건. 어느 쪽을 1층 모집단으로 삼을지는 별도 결정입니다.
