## 2. 제안

| # | 무엇 | 모양 (제안) |
|:-:|---|---|
| ①′ | 🔄 **근거 단위 칸** | `EvidenceArticle` 에 `disclosure: Disclosure \| None` — `need: list[str]`(밝혀야 할 것) · `effect: 확정 \| 분기`. 🚨 문장 단위(`SubstBranch`)에만 두면 행 4 가 풀리지 않는다. 이름·목록은 라벨의 `표시요건` 과 **같은 표**에서 온다 — 두 곳에 적지 않는다 (D-99) |
| ② | `accepted_evidence` 완화 | 지금 `min_length=1`. **표시만으로 풀리는 것**(3.아 · 3.거 · 3.너)은 실증 자료가 없다 → `accepted_evidence` 와 근거의 `disclosure` 중 **하나 이상** 있으면 된다(검증기) |
| ③′ | 🔄 증명서 가드 | **걸린 근거 전부가** 표시로 풀릴 때만 `Certificate` 를 막는다(검증기). 하나라도 C 면 증명서는 그대로 · 표시 지시는 표시로 풀리는 근거에만 |
| ④ | 층 3 규칙 | 주장 곁에 요구된 표기가 **없으면** → `effect` 대로: 확정이면 확정 위반 + 지시(「같은 광고에 밝히세요」) · 분기면 분기. **있으면** → 실증 분기 유지. 🔴 있음을 통과로 내리지 않는다 — 텍스트로는 그 조사·인용이 맞는지 모른다 (D-220) |
| ⑤ | 평가 대응 | 지시 문안이 `need` 를 담는지 — 해설서 채택 행의 `표시요건`(83행)이 정답이 된다 |
| ⑥ | 🆕 **방식은 새 칸이 아니다** | 위치·크기·언어는 D-93 자리 — `MediaProfile.disclosure_placement` · `RewriteSet.mandatory_note`(무엇을) · `placement`(어디에). 판정의 `need` 가 대체 문구의 `mandatory_note` 로 흐른다 |
| ⑦ | 🆕 **발동 규칙** (층 3) | 문구에 보이는 주장 → 그 조문. **경제적 이해관계**(35032 Ⅴ.6) → 문구가 **추천·보증 형식**(제3자의 사용 경험·평가로 읽힘)일 때만 · 분기. 가상인물(Ⅴ.5) → 검수에서 발동하지 않는다. 불인정 표시 문구(「체험단」 · 「AD」 · 「Sponsor」 …) → 표기 **있음**이 아니라 **없음**으로 본다 |

**효과를 정하는 규칙** — 출처 문언. 법령·고시가 「~하지 않고」 · 「밝혀야」로 적으면 `확정` · 공정위 지침이 「해당될 수 있다」로 적으면 `분기`.

## 3. 정하지 않은 것

- 「곁에」의 범위 — 같은 문장 · 같은 문단 · 같은 문서 중 어디까지 보는가 (D-120 문서 경계)
- 「추천·보증 형식」 검출 — 1인칭 사용 경험 · 「써 봤는데」 등. 검수 입력에 얼마나 오는지 재지 않았다
- 화면 — 지시 카드에 「밝혀야 할 것」 줄을 더할지 (ksr · lse)
- 확정/분기를 문언으로 가른 것은 조문 독해다 — 공정위 심결례는 코퍼스에 없다
- 「화장품 표시·광고 관리 지침」(미수집)에 체험기 규정이 있는지 — 있으면 화장품 행이 는다
