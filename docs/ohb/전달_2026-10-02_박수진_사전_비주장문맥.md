## 2. 🚨 시제품(`judge_stage1.py` · `judge_stage2.py`)에서 새는 자리 — 재현

작업공간에서 두 파일을 그대로 불러 돌렸다(인코더 확률은 지정값 · 식품 전제).

| 문장 | 인코더 | 현행 사전 | 새 사전 |
|---|---|---|---|
| 당뇨에 효험 있는 버섯 | 조용(0.0) | 보류 | 🔴 **확정 · 위반 없음** |
| 천식이 싹 사라지는 차 | 조용(0.0) | 보류 | 🔴 **확정 · 위반 없음** |
| 당뇨에 효험 있는 버섯 | 질병 0.9 | 확정 위반 | 보류 |

- 원인 ① — 1단계는 단독판정도 적법중첩도 아닌 항목을 **인코더가 동의할 때만** `dict_weak` 로 남긴다(`elif agrees(label)`). 강등된 항목은 인코더가 조용하면 신호가 없다
- 원인 ② — 2단계의 「신호 없음 → 확정 · 위반 없음」(⬜ 팀장 판정 대기) — W5 가 붙으면 R0 → 통과가 된다

**제안 (1단계 한 줄)** — `비주장문맥` 은 인코더와 무관하게 `dict_weak` 로 남긴다. 판정 그래프(`app/graph.py`)는 같은 규칙으로 고쳤다(D-311 — 자격 없는 적중은 **보류 문장의 유형 후보**):

```python
            elif row.get("신뢰도") == "적법중첩":
                add("overlap", ...)
            elif row.get("신뢰도") == "비주장문맥":          # 🆕 D-311 — 인코더와 무관하게 보류 신호
                add("dict_weak", label, [row["term"]], basis=row.get("근거") or (), span=span)
            elif agrees(label):
                add("dict_weak", ...)
```

- 🔴 `적법중첩` 이름으로 바꾸지 않은 이유 — 1단계가 적법중첩을 `overlap`(품목 전제 분기)으로 읽어 식품 전제에서 위반으로 돌린다. 주의사항의 질병 이름은 지위 문제가 아니다
- 2단계 「신호 없음 → 확정」은 D-269(사전 침묵 = 보류)와 충돌한다 — 팀장 판정 대기로 남았다(D-311 ⬜)
