    uv run python -m preprocess.ftc_extract --stage      # 단계 물질화 + 지난 판과 비교

    uv run python -m preprocess.hwp <파일> --verify       # 🔴 저작 도구 미리보기와 글자 대조

| ⑭ | 🔴 **금지 표현 사전을 그대로 쓰면 승인된 건기식 표시를 위반으로 잡는다** — 「기억력 개선」이 위반이자 적법이다 | 1층↔2층을 맞대고 (D-156) |
| ⑮ | `POLICY` 에 `person` 축이 있는데 **코드가 안 따랐다** — `org` 를 켜면 딸려 왔다 | 축을 걸어 보다 (D-157) |
| ⑯ | 사례집 목차 제목으로 본문을 찾으니 **호 다섯이 전부 「1쪽」**에서 잡혔다 — Ⅰ부가 법 §8① 을 **글자까지 같게** 전재한다 | 목차 대조기 (D-158) |
| ⑰ | 건기식 **제목**에 상호가 그대로 있었다 — `업체` 필드는 안 담았는데 **다른 문**으로 들어왔다 | 산출물을 열어 보고 (D-159) |
| ⑱ | 🔴 옛 인용 계수기가 **두 표현을 한 종으로** 셌다 — 「피로개선‘, ‘뇌건강」이 원장의 89종 안에 있었다 | 계수기를 합치다 (D-160) |
| ⑲ | 🔴 `mfds_sanctions` — **받은 행 5,381 = 선언 5,381 인데 유일 행 5,122** | 유일 행을 세고서야 (D-161) |
| ⑳ | 런처 메뉴 키가 겹쳐 `gate`·`check` 두 줄이 **보이는 채로 영영 안 눌렸다** | 전처리를 배선하다 (D-162) |

**곁가지** — `sys.path` 가드가 「들어 있나」를 봤다(막으려던 건 **가려짐**인데 검사한 건 **존재**).
`--pages 1` 탐침인데 `mark_collected` 가 찍혔다.
급감 검사 첫 판이 **원장만 보고 🔴** 를 냈다(파일은 지웠는데 원장은 append 라 **영영 운다**).
루프 변수 `a` 가 argparse 네임스페이스를 덮었다 — **출력은 다 찍힌 뒤 죽어 화면만 보면 정상**이었다.
🔴 `_REDACTED_NAME` 줄을 통째로 날려 가려진 이름 18건이 안 지워진 채 돌았다 —
결과 문자열 854/854 동일 · 산출물 627 동일 · **치환 원장 개수 하나(416→398)만 달랐다.**
🔴 `tests/test_mask.py` 의 `_REGISTRY_SOURCE` 가 2종에 멈춰 있어 **새 정책 셋이 한 번도 안 돌았다**
(그날 돌린 것은 `-m` 으로 추린 38건이었다).
🔴 사례집 계측기가 **한 원천의 수를 D-40 의 유형별 30건과 견주어** 🚨 를 찍고 있었다 —
