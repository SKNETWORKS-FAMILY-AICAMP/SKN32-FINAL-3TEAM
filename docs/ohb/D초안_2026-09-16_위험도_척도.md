## ① 발단 — 확정 둘이 서로 어긋나 있다

| | 뭐라고 했나 | 날짜 |
|---|---|---|
| **D-130** | 위험도는 5값 순서형. **R4 = 형사 위험 · 벌칙 조항** | 2026-09-03 |
| **D-182** | 위험도는 **처분 일수의 서수**로 매긴다. **형벌 상한이 필요하면 `penal_clause`(징역 n년 · 벌금 n원)가 이미 그 자리다** | 2026-09-10 |

D-182 가 나중이고 「연관: D-130」을 적었지만 **개정한다고는 적지 않았다.**
**형벌을 R 축에서 빼 놓고 R4 의 이름은 「형사 위험」으로 남겼다.**

그 결과 R4 를 낼 입력이 **어디에도 없다.** 처분 종류의 사다리가
`시정명령 → 정지 → 취소·폐쇄` 로 끝나고 그 위가 없기 때문이다.

⛔ 이것은 「지금은 안 쓴다」가 아니라 **이 설계에서 구조적으로 도달 불가**다. 둘은 다른 상태다.

## ② 실측 — 처분 종류는 조문이 사다리로 엮어 놨다

`data/raw/law/annex/013475_annex_0007_00.json` 「행정처분 기준(제16조 관련)」 74,234자 · 2,533줄.

⚠️ **파싱이 거칠다.** 병합 셀 ASCII 표라 항목 경계가 새는 자리가 있다(블록 1·3 의 「5)」에

위 목록은 **재료이지 판정이 아니다.** 2·3·4차는 맞대 보지 않았다.

```
시정명령 · 판매업무정지 60 / 90 / 120 / 180 / 270 / 360일
```

## ③ 결정안 — 위험도 척도는 **R0 ~ R3 네 단계**

| 값 | 이름 | 뜻 | 근거 |
|:-:|---|---|---|
| **R0** | 특이사항 없음 | 사전·산식에 걸린 것이 없음. 🚨 **「안심」·「적법」이라 부르지 않는다** (D-130 유지) | D-130 |
| **R1** | 주의 | **시정명령** 수준 · 또는 사전이 걸렸으나 **단독판정 자격이 없음**(적법중첩 19종·모호 103종) | 제14조 · D-156 |
| **R2** | 업무정지 위험 | 영업정지 · 품목제조정지 · 판매업무정지 · 광고업무정지 (**제19조 갈음 과징금 포함**) | 제16조①③ · 제19조 |
| **R3** | **영업 상실 위험** | 영업허가·등록 **취소** · 영업소 **폐쇄** | 제16조②④ |

**개정되는 것** — D-130 의 R2「업무정지 위험」·R3「과징금 위험」·R4「형사 위험」 세 이름표.

### 과징금이 별도 등급이 아닌 이유

**제19조(영업정지 등의 처분에 **갈음하여** 부과하는 과징금)** — 제목 그대로다.

> ③ 과징금을 기한 내에 납부하지 아니하는 때에는 … **과징금 부과처분을 취소하고**
>   … 영업정지 … 처분을 하거나

**서로 대체 가능하다. 같은 단계다.** D-130 이 R2(업무정지)/R3(과징금)로 갈라 둔 것이
법 구조와 맞지 않았고, 이것이 D-130 이 「R2·R3 의 순서는 미확정」을 남긴 원인으로 보인다.

🚨 **다만 과징금이 둘이다.** **제20조**(부당한 표시·광고에 따른 과징금)는 갈음이 아니라
**추가**이고, 대상이 **제8조제1항 제1~3호** + 2개월 이상 영업정지/취소/폐쇄를 받은 자다.
이쪽은 **금액이라 D-182 가 이미 뺐다** — R 축에도 근거 축에도 넣지 않는다.

## ④ R4 — 도달 불가로 두고, **되살리는 조건**을 적는다

`risk_t` ENUM 의 `R4` 는 **남긴다.** 지우면 마이그레이션·헤드 차원·QWK 척도·골든셋이
같이 움직이는데, 남기는 비용은 0 이다.

```
R4 는 이 설계에서 도달 불가다.
  사유 — 형벌은 R 축에 얹지 않는다. `penal_clause`(징역 n년 · 벌금 n원)가 그 자리다 (D-182).
  되살리는 조건 — **D-182 를 개정**해 형벌을 R 축으로 되돌리는 결정이 선행해야 한다.
```

⛔ 「나중에 쓸 수도 있다」로 적지 않는다. **되살리는 조건이 무엇인지**를 적는다
(D-21 — 의도적 제외와 미인지는 다른 상태다).

⬜ 저장소에 같은 어법의 결정이 있는 것으로 보인다 — **D-107 「범위 밖 기능은 지우지 않고
「비활성 + 사유」로 남긴다」.** ⚠️ **제목만 봤고 본문은 안 읽었다.**

## ⑤ 축을 셋으로 가른다 — 스키마가 이미 그렇게 생겨 있다

```sql
sanction_rule (violation_type, offense_count, sanction_kind, sanction_value, unit, risk_level)
              → 행정처분.  risk_level = R 등급  ·  sanction_value/unit = 수위
penal_clause  (violation_type, article, max_imprisonment_years, max_fine_krw)
              → 형벌.     제26조 10년/1억 · 제27조 5년/5천만
penalty_rule  (tier, base_rate, base_amount, …)
              → 과징금 금액.  ⛔ 안 쓴다 (D-182)
```

```
사전 매칭 → 유형
   │
   ├─ sanction_rule 에 행이 있다
   │     R     = max over 업종 of {시정명령→R1, 정지→R2, 취소·폐쇄→R3}
   │     수위   = sanction_value/unit      「1차 위반 시 영업정지 2개월」   ← 설명
   │     형벌   = penal_clause              「제26조 10년 이하 징역 대상」   ← 설명
   │
   └─ 행이 없다
         ⬜ 등급을 지어내지 않는다 — §⑦-나 판정 대기
         수위·형벌 줄은 나가지 않는다
```

### 업종을 `max` 로 접는 이유

같은 유형·같은 차수인데 업종 블록마다 처분이 다르다 — 실측:

```
의약품_오인 1차   블록1 영업정지 15일 · 블록3 영업정지 15일 · 블록4 시정명령
```

`ProductContext` 에 **업종이 없어** 코드로 가를 수 없다. D-09 가 같은 질문
(「여럿이 다른 답을 냈을 때 누가 이기는가」)에 `max` 로 답했으므로 **그 원리를 그대로 쓴다.**

★ 부수 효과 — 블록 4 만 보면 의약품 오인이 R1(시정명령)이 되어 **통과 문턱을 넘어간다.**
`max` 가 그것을 막는다.

⛔ **건기식 축은 `max` 로 접지 않는다.** 「영업정지 15일(**건강기능식품의 경우 1개월**)」이
괄호 단서로 있고, `ProductContext.has_recognized_function` 이 **입력에 있어 가를 수 있다.**
가를 수 있는 축을 접으면 일반식품 문구에 건기식 기준이 걸린다 — D-130 이 경고한
「경고 피로가 구조적으로 생긴다」 자리다.

### 수위·형벌은 「있으면 설명, 없으면 침묵」

계약의 기존 어법과 같다 — `citation()` 은 확신이 없으면 `None`, `_annex_citation()` 은
번호가 없으면 포기한다(부분 인용을 하지 않는다 · D-224).

⚠️ **다만 내부에서는 두 경우를 갈라야 한다** (D-188) —
ⓐ 별표에 그 유형 행이 **없다**(원천에 없다) / ⓑ 우리가 **아직 적재를 안 했다**(미실행).
화면에는 둘 다 안 내더라도 `doctor`·로그에서는 갈려야 「왜 안 나오지」에 답할 수 있다.

## ⑥ 🔴 곁가지 — 통과 문턱이 D-130 과 어긋나 있다

`app/contracts.py:85`

```python
#: 🚨 잠정값이다. D-125 의 통과 조건이 「위험도 ≤ 주의」인데, 다섯 값 중 어느 것이
#:    「주의」인지는 검증 ② 가 R2·R3 순서를 정한 뒤에 확정된다 (D-130).
PASS_RISK_MAX_PROVISIONAL = Risk.R2
```

**D-130 본문은 `≤ R1` 이라고 적었고 표에서 R1 = 주의가 확정이다.** 미확정이었던 것은
**R2 ↔ R3 의 상대 순서**이지 「어느 것이 주의인가」가 아니다. 주석이 D-130 을 잘못 읽었고,
그 결과 문턱이 **한 등급 느슨하다** — 「업무정지 위험」이 통과가 된다.

지금은 `is_pass()` 를 **아무도 부르지 않아** 드러나지 않는다(`route_after_judge` 가 verdict 만
본다). **하한이 들어오는 순간 살아난다.**

→ **`PASS_RISK_MAX_PROVISIONAL = Risk.R1`** 로 고치고 주석을 D-130 표에 맞춘다.
이 개정안에서 R2·R3 순서 문제 자체가 사라지므로 「잠정」이라는 말도 없앤다.

## ⑦ 판정이 남는 것 — 둘

**가. 이 개정안을 받는가** (§③④)

**나. 제재 기준이 없을 때 무엇을 낼 것인가**

사전은 걸렸는데 `sanction_rule` 에 행이 없어 처분 종류를 모르는 상태다.

| 낼 값 | 문제 |
|---|---|
| `floor = R0` | 🔴 D-130 이 「사전·산식에 **걸린 것이 없으면** R0」이라 했다. 걸렸는데 R0 은 문언에 어긋난다 |
| `floor = R1` | 🔴 문턱이 `≤ R1` 이라 **통과한다.** 사전에 걸렸는데 통과 — 안전 방향 위반 |
| `floor = R2` 기본값 | 🔴 근거 없는 등급을 지어낸다 (D-131 이 막는 결) |
| ★ **`verdict = no_basis`** | D-127 — 「위법 유형은 잡았는데 **대응 조문을 찾지 못함** · **위험도·유형은 유지** · 통과 ❌」. 통과도 안 되고 등급도 안 지어낸다 |

⚠️ **D-127 의 「대응 조문」이 별표1 조문인지 제재 기준인지 본문에 적혀 있지 않다.**
우리는 `retrieve` 가 별표1 조문을 붙이므로 그쪽 근거는 **있고**, 없는 것은 제재 기준이다.
둘을 같은 `no_basis` 로 볼 것인지가 판정이다.

## ⑨ 이 결정이 고치지 못하는 것 (D-188)

- **등급만 보는 사람은 형사 위험을 못 본다.** R3 가 최고인데 제26조는 10년 이하 징역이다.
  → 그래서 **`penal_clause` 적재가 선택이 아니라 이 결정의 전제**다. 다행히 유형만 알면
  채워진다 — **제26조(제1~3호 · 10년/1억) · 제27조(제4~10호 · 5년/5천만) 두 행**이면 된다.
  별표7 파싱도 업종도 필요 없다.
- **행정처분과 형벌이 병과된다는 사실**은 R 축에 안 담긴다. 설명 줄이 담는다.
- **업종을 `max` 로 접으면 과잉 경고 쪽으로 기운다.** D-09 의 트레이드오프(FN 과 FP 의
  비용이 자릿수로 다르다)를 그대로 받은 것이고, 그 대가는 그대로 남는다.
- 차수(1·2·3차)는 **코드로 판정할 수 없다** — 업체 전과를 모른다. **1차만 본다.**
  ⬜ 이 선택의 근거는 「하한의 뜻」에서 온 것이고 **원장에 D 번호가 없다.**

## ⑩ 트레이드오프

> 위험도 축에 행정처분과 형벌이 섞여 R2·R3 순서가 정해지지 않던 문제를 풀기 위해
> **축을 셋으로 갈랐고**, 그 덕분에 ① 등급 경계가 전부 조문이 그은 것이 되어 `[임의]` 가
> 사라지고 ② 과징금·형벌·일수가 각자 자기 자리에서 정확히 표현되고 ③ D-182 와 D-130 이
> 일치하는 대신,
> **척도가 다섯에서 넷으로 줄고 R4 가 도달 불가가 된다.** 그리고 **형사 위험이 등급으로는
> 드러나지 않아** 설명 줄(`penal_clause`)이 반드시 나가야 한다 — 안 나가면 화면이
> 「업무정지 위험」이라고만 말하고 10년 징역을 말하지 않는 **과소 표시**가 된다.

## ⑬ 깔고 간 가정

- **법 제8조제1항의 호 = 별표1 의 호 = `violation_t`** 로 보았다. 제8조제1항 원문(1~10호)과
  별표1(1~8호)을 대조해 확인했다. 🚨 **제8·9·10호(사행심·음란 / 상표 오인 / 심의 미필)는
  `violation_t` 에 없다** — `violation_article` 초안 §3-① 이 제8호만 지적했는데 9·10호도 없다.
  제27조가 제4~**10호**를 형사로 걸고 있으므로 이 셋은 「유형이 없어 판정 자체를 안 하는」 구간이다.
- **행정처분과 형벌이 병과된다**는 것 — 조문 구조에서 읽었다(서로를 배제하는 문언이 없고
  제30조 양벌규정이 별도로 있다). 🚨 **판례 코퍼스 84건에 영업정지 0건 · 취소·폐쇄 0건 ·
  둘이 같이 나오는 판례 0건**이라 실사례로 확인하지 못했다. 「없다」가 아니라 **안 봤다**다.
- **화장품법 축의 벌칙·행정처분 조문을 읽지 않았다.** 위 §③ 은 식품 축(013094·013475)에서
  세운 것이고, 화장품 축(002015·008741)이 같은 모양인지 확인하지 않았다.
  `penal_clause` 두 행도 식품 축만이다.
- **`sanction_rule`·`penal_clause`·`penalty_rule` 의 실제 행 수를 확인하지 못했다.**
  `sanction_rule` 0행만 2026-09-14 `doctor` 출력에서 보았다.
- 처분 종류의 전수는 **오늘 본 범위**다 — 시정명령 / 영업정지 / 품목제조정지 / 판매업무정지 /
  광고업무정지 / 영업허가·등록 취소 / 영업소 폐쇄. 별표 전체에서 더 나오면 R 배정이 한 번 더 필요하다.
