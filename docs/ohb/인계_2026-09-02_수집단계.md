## 3. 수집 규약 — 경로가 셋이고 게이트가 다르다 (D-109)

🚨 **이 셋을 섞지 않는 것이 이 프로젝트의 핵심 규약이다.**

| 경로 | 명령 | 저장 | `reviewed_by` | 막는 것 |
|---|---|:-:|:-:|---|
| **탐침** `registry.probe()` | `launcher.py probe <id>` | ❌ **저장 안 함** | 면제 | G1 · manual · GATED 미승인 · robots 미확인 크롤링 |
| **수집** `registry.require()` | `launcher.py collect <id> --use U1` | ✅ | **요구** | 위 전부 + 미서명 + `GRADE_CAP` 위반 |
| **세기** `ingest count` | `launcher.py count <경로>` | ❌ | 없음 | 게이트 없음 (읽기만) |

**왜 탐침이 있는가** — 검토하려면 열어봐야 하고, 열어보는 것은 수집이 아니다. 수집기만이 유일한
확인 수단이면 「판정 → 수집 → 확인」이 되어 **그 판정은 확인 없이 내려진 것**이 된다.

**`GRADE_CAP`** — 등급이 허용하는 용도 상한. 게이트가 강제한다.

```
G3 → U1 U2 U3 U4      G2 → U1 U4  (원문 미보관이므로 색인·인용 불가)
G1 → 없음             G0 → 없음   (fail-closed. 확인 후 2인 판정으로만 승격)
```

U1 학습 · U2 RAG 원문색인 · U3 화면인용 · U4 배포. **판정 단위는 FRAGMENT** 다 (D-18) —
한 소스 안에서 조각마다 등급이 갈린다. `redistributable` 은 **별도 축**이다 (D-71).

|:-:|---|---|
| ① | **두 건기식 게시판을 혼동**해 잘못 미채택했다 (kfia 협회 vs 식약처 식품안전나라) | 조건 문구를 인용할 때 **어느 사이트인지**를 함께 적는다 |
| ② | `kcia_guideline` 의 판정 근거가 **허위**였다 — "저작권은 대한화장품협회 귀속 명시 확인"이 공지·PDF 어디에도 없었다 | 🚨 **확인하지 않은 것을 「확인했다」고 쓰지 않는다.** 검토자가 재현 못 하면 서명이 무너진다 |
| ③ | `krei_food` 를 「문항 확인 = G0 해제」로 잘못 프레이밍했다 | **G0 는 「가치 미확인」이 아니라 「이용조건 미확인」**이다 |
| ④ | 단일 소스 탐침이 **전체 리포트를 덮어써** 32건 결과가 날아갔다 | 게이트가 「쓰기 횟수」를 세고 있었던 것이 원인. 게이트는 **횟수가 아니라 대상**을 본다 |
| ⑤ | `EXTRA` dict 중복 키로 `masking` · `fragment_note` 를 **조용히 날렸다** | 게이트 26 신설 |
| ⑥ | 게이트 17 이 **docstring 을 위반으로 읽었다** | 🚨 게이트가 산문을 검사하면 사람이 **주석을 지워** 통과시킨다. AST 로 본다 |
| ⑦ | 탐침이 수집기 결함을 **둘** 잡았다 (한글 URL 인코딩 · `require()` 가 GATED 미검사) | 열어보는 경로가 만드는 경로를 검증한다 |

## 8. 자주 쓰는 명령

```powershell
python launcher.py                       # 대화형 메뉴

python launcher.py collect <소스id> --use U1 --pages 1
python launcher.py count <경로>          # 받아 온 파일 세기
python launcher.py gate                  # 게이트 35개
python launcher.py check                 # 커밋 전 점검
python launcher.py registry              # data.js → data_sources.yaml 재생성
```
