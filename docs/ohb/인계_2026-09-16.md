## §5 레지스트리 — `cond` 가 fail-closed 가 됐다

```python
# scripts/gen_registry.py
- allow = 1 if v == "ok" else (1 if v == "cond" and s["grade"] == "G2" else 0)
+ allow = 1 if v == "ok" else 0
```

**`cond` 한 칸이 셋을 지고 있었다** — ① 법적 조건부(G2 쪽) ② **U 축에 「평가」가 없어서**
(`mfds_casebook` 의 note 가 직접 적었다) ③ 품질. 등급으로 가른 것은 셋이 등급과 상관되어
**우연히** 맞아떨어진 것이다.

| 쪽 | 축 | 원천 | 수집 | 성격 |
|---|--:|---|---|---|
| G2 + `cond` → allow | **8** | 5 | **0/5** | 🔴 조건이 코드에 안 닿는데 열려 있었다 |
| G3 + `cond` → deny | 4 | 2 | 2/2 | 과잉 제한(안전) — note 에 근거가 있다 |

**닫히는 8축은 전부 미수집이라 비용 0.** `use` 벡터가 바뀐 칸은 **10개 · 7원천**.

D-132(09-03)는 **제24조의2 제1항 직접 적용**으로 판정하고 「**격리는 판정 미결의 임시 동작이지

## §6 응답시간 — 예산의 단위가 확정됐다

| 구간 | 평균 | 최대 | 표본 |
|---|---|---|--:|

| ↳ SQL + 융합 (차감) | ≈ 51.5 ms | — | — |

🔴 **D-77 L3 는 「p50 / p95 / p99 · 평균은 쓰지 않는다」로 적는다.** 위는 평균이고 표본 4다 —

**✅ 요청당이다.** D-77 L3 단계 예산을 더하면 닫힌다 —

```

```

각 단계가 **한 번씩** 더해져 소계가 되고, 「문장 분할」이 같은 표 안에 있다.

`split` 이 스텁이라 지금은 문장 하나만 돈다 (D-127) — **증상이 안 보이는 것뿐이고 세우는 순간
만난다.** 그래서 배치 인코딩은 `split` 보다 나중이 아니라 **같은 작업**이어야 한다.

★ **모델 로드는 프로세스당 한 번**이다(`_model_cache`). `python -m scripts.graph_probe` 를 두 번
