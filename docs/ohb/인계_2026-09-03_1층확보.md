## 3. 🚨 이어서 작업할 때 반드시 알아야 할 것 넷

### ① 매칭은 정규화문, 보관은 원문 (D-117)

`preprocess/text.py` 의 `sep_norm()` 이 나열 구분자(`ㆍ · ․ ‧ ･ . 、 /`)를 `·` 로 편다. **같은 문자 함정을 세 번 밟고 만들었다.**

```python
if PATTERN.search(sep_norm(title)):   # ✅ 매칭에만
    keep(title)                        # ✅ 원문을 보관
title = sep_norm(title)                # ❌ 원문을 잃는다
```

🚨 **회피 표기 계수에는 정규화문을 넘기지 마라.** `sep_norm` 이 마침표까지 `·` 로 펴므로 **문장의 정상 마침표가 구분자로 둔갑**한다. 정규화가 지우는 것이 바로 회피 표기의 신호다.

### ② 원천이 준 식별자·링크는 그대로 쓴다 (D-118 ①)

목록의 `href` 를 분해해 번호만 뽑고 `view.do?ntctxtNo=<번호>` 로 다시 조립했다가 **5건이 전부 1,455 B 오류 페이지**로 왔다. 실제 파라미터는 `seq` 였다. 지금은 쿼리스트링을 통째로 색인에 저장하고 그대로 부른다.

### ③ 성공 판정에 크기 하한을 둔다 — 그리고 **판정 순서**가 중요하다 (D-118 ②)

오류 페이지에는 공공누리 표시가 없어서 「미부착」으로 읽혔다. **틀린 이유로 그럴듯한 결론이 나왔다.** 크기 검사를 공공누리 판정 **앞에** 두어야 한다.

### ④ 오래 도는 일은 한 단위마다 파일에 붙인다 (D-118 ④)

색인 4,348건을 메모리에 모아 마지막에 쓰다가 120장에서 죽자 통째로 사라졌다. **죽는 것을 막는 것보다 죽어도 이어받는 것이 싸다.**
