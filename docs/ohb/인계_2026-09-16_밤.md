위 대조는 **「기기 파일이 내가 쓴 것과 같다」까지**다. **「git 에 들어갔다」는 다른 것이다.**

**명령어 출력이 없이는 `git status`·`git log` 를 볼 수 없다** — `device_bash` 가 못 뜨는 동안
**커밋 범위는 사용자가 돌려 준 출력이 유일한 증거**다.

🔴 **이 날 커밋 여섯이 한 작업이다.**

```
4c05c35  D-229 … · 사전/평가셋 검토          ← 문서 2
c9b892c  D-229 …                            ← README · contracts · graph · 원장 · 스냅샷
3fc0a8e  D-228 … · 축별 형벌·차수 실측 …
b768174  D-228 … · penal_clause 네 행 …
b2cc145  D-228 … · D-218 스테이징 경로 …
8c43f21  D-228 … · 식품 축 초안 2판
```

제목이 거의 같고 **내용과 안 맞는다** — 클로드가 매번 「지금까지 쓴 것 전부」를 `add` 하고
누적 메시지를 붙였기 때문이다. 이미 커밋된 것은 조용히 빠지고 **메시지만 전체를 말한다.**
⛔ **되돌리지 않는다** — 워킹트리는 깨끗하고 내용은 전부 들어갔다. 히스토리만 안 읽힌다.
★ **앞으로 커밋 명령은 직전 커밋 뒤에 쓴 파일만 담고 메시지도 그 범위만 적는다** (D-218 에 적었다).
