## 5. 🔴 읽으면서 드러난 것 셋 — 여기가 설계 안건이다

### ① 「그 밖에 = 시정명령」을 표에 넣을 수 없다

블록 1 「거)」 · 블록 2 「4)」 · 블록 3 「카)」 · 블록 4 「2)다)」 가 전부 **시정명령**이다.
**원천이 「해당 목을 못 찾음」의 기본값을 직접 적어 두었다** — 우리가 정할 것이 아니다.

그런데 `violation_type` 이 `NOT NULL` 이라 **유형이 특정되지 않는 이 행은 표에 못 들어간다.**
→ 표가 아니라 **코드의 기본값**으로 둔다: *「4호 계열 유형인데 대응 목이 없으면 하한 = R1」*,
출처 태그 `[문헌]`(별표7 각 블록 「그 밖에」 행).

★ **이것이 ⬜ 판정 「나」**(제재 기준이 없을 때 무엇을 낼 것인가)**에 답을 준다.**
`no_basis`(D-127)가 아니라 **근거 있는 R1** 이다. 다만 통과 문턱이 `≤ R1` 이라 **통과로 나간다** —
「위반이 확정인데 통과」가 맞는가는 D-125 본문을 열고 따로 판정해야 한다.

### ② 비방·부당비교·뒷광고에 **전용 제재 행이 없다**

4)호 **문두**에는 *"다른 업체를 **비방**하는 … **부당하게 비교**하는"* 이 열거돼 있는데,
**하위 목 어디에도 이 셋의 전용 처분이 없다.** 그러면 「그 밖에 = 시정명령 = R1」로 떨어진다.

🚨 **이 셋은 우리 사전·골든셋의 주요 유형이다.** 「비방광고가 R1」은 직관에 어긋난다.

원인은 **축이 둘이기 때문**으로 보인다 — 비방·부당비교·추천보증은 **표시광고법**(공정위) 소관이고,
식품 별표7은 **식약처** 축이다. 표시광고법 제7조(시정조치)·제9조(과징금)를 **우리는 아직 안 읽었고
`sanction_rule` 에 그 축을 넣을지도 정하지 않았다.** D-183 은 식품·화장품 별표만 다뤘다.

### ③ 「제품 폐기」가 D-227 척도에 자리가 없다

1)호가 「영업정지 2개월 **+ 해당 제품 폐기**」인데, D-227 의 처분 종류 사다리
(`시정명령 → 정지 → 취소·폐쇄`)에 **폐기가 없다.** 지금은 정지 부분만 보고 R2 로 매긴다.
작은 구멍이지만 실재한다 — 폐기가 붙은 행과 안 붙은 행이 같은 등급이 된다.

## 6. A/B/C 칸 — D-59 가 「만들어야 한다」고 적은 매핑 표의 첫 조각

D-59 트레이드오프: *"위법 유형별로 A/B/C를 매핑하는 표를 만들어야 하고, 골든셋 라벨도 그만큼 늘어난다."*
**그 표가 아직 없다.** 스키마에는 `infeas_t AS ENUM ('A','B','C')` 가 이미 있다.

| `violation_t` | 사유 제안 | 근거 |
|---|:-:|---|
| `질병_예방치료_표방` | **C** 절대형 | 자료가 있어도 식품은 질병 치료 효능을 표방할 수 없다 (D-61 본문이 이 예를 든다) |
| `의약품_오인` | **C** | 〃 |
| `건강기능식품_오인` | **A** 자격형 | 기능성 인정 절차를 밟으면 같은 주장이 적법해진다 |
| 기능성 함량 부적합 | **A** | 인정 + 함량 충족이 자격이다 |
| `거짓_과장` | **B** 실증형 | 시험·조사 결과로 실증되면 쓸 수 있다 |
| `소비자_기만` | **B** | 〃 |
| `후기_체험기_기만` | ⬜ **미상** | 체험기는 실증으로 해소되는가, 아니면 형식 자체가 금지인가 — 조문 대조 필요 |
| `실증책임_위반` | **B** | 정의상 B 다 |

- **2·3·4차 처분**을 맞대 보지 않았다. 1차만 읽었다.
