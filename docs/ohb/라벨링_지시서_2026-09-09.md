## 0. 왜 사람이 하나

라벨은 대부분 **조문에서 자동으로** 나옵니다. 사례집은 식약처가 「제8조제1항제N호」로,
공정위 의결서는 「제3조제1항제N호」로 묶어 주고, 그걸 코드가 읽습니다. 사람 손이 안 갑니다.

**사람이 필요한 자리는 원천이 라벨을 뭉쳐 놓은 곳뿐입니다.**

    해설서   「거짓ㆍ과장ㆍ기만」이 한 덩어리다 → 셋 중 무엇인지는 문구를 봐야 안다
    사례집   5호가 「소비자 기만」과 「후기·체험기」를 함께 담는다

★ 그리고 **일치도(κ)가 이 라벨의 신뢰도**입니다. 발표에서 「정답은 누가 붙였습니까」에
답하는 것은 이름이 아니라 κ 입니다. 그래서 **일부는 두 사람이 겹쳐** 붙입니다.

## 3. 🚨 경계 — 실제로 갈리는 자리

**① 같은 표현이 위반이기도 적법이기도 합니다** (D-156)

```
위반  「기억력 개선」                      ← 인정 못 받은 제품이 말하면
적법  「기억력 개선에 도움을 줄 수 있음」    ← 인정받은 건기식이 완곡하게 말하면
```

**차이는 ① 완곡 표현이 있는가 ② 그 제품이 인정을 받았는가**입니다.
문구만 보고 못 고르겠으면 `확정유형` 을 비워 두고 **넘어가십시오.** 억지로 채우지 않습니다.

**② 낱말은 라벨을 감당하지 못합니다**

```
「다이어트」 「혈당」 「숙면」 → 사례집에서 두 유형에 동시에 붙어 있다
```

`guide` 248건은 20자 이상만 뽑았으므로 이 문제가 적습니다. 그래도 짧은 것이 나오면
비워 두십시오 — **빈칸은 실패가 아니라 판단입니다.**

**③ 한 문구에 둘 이상이 맞을 때**

`확정유형` 은 리스트입니다. 둘 다 적으셔도 됩니다. 다만 **②의 순서에서 위에 있는 것을
먼저** 적습니다. 셋 이상이면 대개 문구를 잘못 읽은 것입니다.

## 4. 어떻게 채우나

파일은 한 줄에 JSON 하나입니다. 세 칸만 고칩니다.

```json
{"문구": "장의 운동을 촉진하여 변비에 효과가 있습니다",
 "후보유형": ["거짓_과장", "소비자_기만", "후기_체험기_기만"],
 "확정유형": ["질병_예방치료_표방"],     ← 여기
 "붙인이": "권소라",                     ← 여기
 "붙인날": "2026-09-09"}                 ← 여기
```

🚨 **`후보유형` 밖의 값을 적어도 됩니다.** 위 예시가 그렇습니다 — 원천이 「거짓ㆍ과장ㆍ기만」
으로 묶어 놨지만 실제로는 질병 표방입니다. **원천의 분류가 아니라 문구를 봅니다.**

### ⛔ 하면 안 되는 것

- 다른 칸(`문구`·`후보유형`·`원천` …) 을 고치는 것
- 모르는 것을 「일단」 채우는 것 — **빈칸이 낫습니다**
- 서로 상의해서 맞추는 것 — **독립으로** 붙여야 κ 가 뜻을 갖습니다

### ✅ `--sheet` 를 다시 돌려도 안 지워집니다 (2026-09-09 이후)

예전에는 `extract ... --sheet 30` 을 다시 돌리면 채운 것이 **사라졌습니다.**
지금은 겹치는 행의 라벨을 이어받고, 잃을 것이 있으면 멈춥니다. 겁내지 않으셔도 됩니다.

## 5. 분담과 일치도

| | 몫 | 겹치기 |
|---|---|---|
| `casebook` 25건 | 2인이 **전량** 겹쳐서 | 25건 |
| `guide` 248건 | 5인 × 50건 | 그중 **각 12건씩 총 60건**을 옆 사람과 겹쳐서 |

겹치는 부분이 있어야 κ 가 나옵니다. 다 끝나면:

```powershell
uv run python scripts/label_merge.py data/derived/labels/*.jsonl
```

```
  κ ≥ 0.8   ✅ 「우리 라벨은 재현된다」— 그대로 씁니다
  0.6~0.8   🟡 갈린 항목을 셋째 사람이 봅니다
  < 0.6     🔴 라벨이 아니라 **이 지시서가 문제입니다** — 고쳐서 다시 합니다
```

🚨 **갈린 항목은 다수결로 덮지 않습니다.** 두 사람이 갈렸다는 것은 그 항목이 경계라는
뜻이고, 경계를 지우면 지시서가 영영 안 좋아집니다.
