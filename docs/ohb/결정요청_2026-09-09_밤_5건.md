```
User-agent: Googlebot
Disallow:/api/board/board.do?menu_grp=MENU_GRP33&menu_no=690$
```

## ③ `attribution` 은 완성된 문장이 아니다 — 렌더링이 미구현이다

D-132 가 형식을 정해 놨다.

```
제37조 출처 명시 | 기관명 · 자료명 · URL · 게시일 | BY 플래그 · 공공누리 제1유형 표기 문구 차용
```

`source.attribution` 은 **기관명·자료명**만 담는다. 나머지 둘을 넣지 않은 이유 —

- **URL** 은 `source.url` 에 있다. 문구에 복사하면 원본이 바뀔 때 문구가 낡는다 (D-54).
- **게시일** 은 **문서마다 다르다.** 소스 단위 필드에 박으면 전부 같은 날로 표시된다 (D-18).

🔴 **그래서 화면이 넷을 조립해야 한다.** 지금 찍으면 넷 중 둘이 빠진다.
`v_publishable_golden` · 화면 인용부가 `source.url` 과 `document` 의 게시일을 붙이는 자리다.

**판정: 조립을 어디서 하는가** — ⬜ DB 뷰 / ⬜ 애플리케이션 / ⬜ 화면 템플릿(Jinja2)

지금 **모델에만** 있다.

```python
# tests/test_governance_layout.py — test_모든_모델에_라이선스와_등급과_배포용도가_있다
```

같은 것을 소스에 걸면 **지금 하나가 걸린다.**

| 소스 | license | use | redistributable |

🚨 다만 `use` 축을 닫는 것은 **판정**이라 내가 하지 않았다.

**판정: ⬜ 게이트를 건다(= `kcia_guideline` 의 U1·U4 를 deny 로) / ⬜ 회신까지 그대로 둔다**
