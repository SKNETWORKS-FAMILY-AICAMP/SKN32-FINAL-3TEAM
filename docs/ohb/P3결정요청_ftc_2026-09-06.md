### 1-3. 왜 못 지우나 — 표본

```
피심인은 수급사업자인 (주)미래이엔지에게 건설위탁한 …
원사업자인 케이티건설 주식회사가 수급사업자인 문원건설 주식회사에 위탁한 …
중소기업자인 (주)창연실업에게 원사 포장용 박스를 …
이의신청인은 … 수급사업자인 (주)겨레석재산업에게 …
```

**이 이름들이 사건의 골자다.** 하도급 사건은 「누가 누구에게 무엇을 위탁하고 대금을
안 줬는가」이고, 담합 사건은 「누구와 누가 합의했는가」다. 거래 상대방을 지우면 사건이
사라진다. 그리고 그들은 **제재 대상도 아니다.**

앵커는 피심인 하나뿐이라 구조적으로 못 잡는다. 이건 규칙을 다듬어 될 일이 아니다.

### 1-4. ⛔ 그 과정에서 더 급한 것이 나왔다 — **개인 실명**

```
주식회사 경기고속 광주시 송정동 222 … 대표이사 허명회
주식회사 덕화스포츠 서울 서대문구 연희동 81-32 대표이사 김창범
위 피심인의 대리인 서진법률사무소 담당변호사 진종백, 김철수
```

🚨 **원천이 늘 가려 주지 않는다.** 가림 표기(`000`·`고ㅇㅇ`)는 **47.6%** 에만 있었고,
나머지 52.4% 는 안 가려진 것이었다. 나는 그 숫자를 보고 「원천이 처리해 놓았다」고 적었다 —
**숫자를 봤는데 뜻을 잘못 읽었다.**

→ ✅ **고쳤다.** 직함 뒤 실명을 `[대표]` 로 바꾼다. 직함은 남긴다 —
   지운 자국이 없으면 다음 사람이 「여기 이름이 있었나」를 못 본다.
   🚨 성씨 목록을 쓴다. 직함만 보고 뒤 2~4자를 지우면 「대표자 **표시광고**」에서
   **판정 어휘가 사라진다.** 성씨는 열린 추측이 아니라 닫힌 집합이라 근거가 된다.
   ⬜ 흔한 30여 개만 넣었다 — 드문 성씨는 못 잡고, `--survey` 가 잔여로 센다.

### 1-5. ⬜ 함께 나온 것 — **주소**

```
피 심 인 : 주식회사 X  서울 양천구 신정동 1254 신트리테크노타운 80…
```

업체명을 지우고 주소를 남기면 지운 의미가 줄어든다. ⬜ 판단이 필요하다.

## 2. ✅ 확인 완료 — 레지스트리가 이미 정해 두었다

```yaml
ftc_decisions_body:
  grade: G3
  use: {U1: allow, U2: allow, U3: allow, U4: allow}
  redistributable: true
  masking: >-
    업체명·상표·피심인 주소 즉시 마스킹, 원문 미보관 (D-17).
    🚨 대표자명은 원천이 이미 가려서 준다 — 그래도 우리 쪽 마스킹을 끄지 않는다.
```

세 가지가 이 결정을 좁힌다.

1. **U1(학습)·U4(배포)가 열려 있다** → 본문이 학습에 들어간다.
   「사람이 읽고 귀납하는 재료일 뿐」이라는 가정은 성립하지 않는다. **마스킹은 필수다.**
2. `masking:` 이 **「업체명」**이라고만 쓴다. 「피심인 업체명」이 아니다.
   반면 주소는 **「피심인 주소」**로 한정한다.
   ★ 같은 문장에서 하나는 한정하고 하나는 안 했다 —
     **업체명은 제3자를 포함해 읽는 것이 자연스럽다.**
   ⬜ 다만 이건 문언 해석이다. 팀장 확인 대상으로 남긴다.
3. **「상표」도 대상**이다. 오늘 나는 `mfds_sanctions` 의 제품명을 「판정 대상이라 보존」으로
   좁혔는데, `ftc` 의 상표는 **영업표지**(「청년피자」·「에듀플렉스」)라 성격이 다르다.
   ★ 「두 원천을 한 규칙으로 덮지 않는다」고 열어 둔 것이 맞았다.

🚨 `redistributable: true` 라 이 데이터는 **공개 배포 대상**이다. 마스킹 실패가
   내부에 머물지 않는다 (D-71).

### B. ⬜ 법인격이 붙은 자리를 **이름과 무관하게** 전부 `[업체]` 로

| 얻는 것 | 치르는 것 |
|---|---|
| 사전 없이 커버리지가 크게 오른다 | 「주식회사 대표이사」 같은 오탐으로 문장이 상한다 |
| 제3자·공동피심인이 한꺼번에 잡힌다 | 법인격 없이 쓴 이름(「세원」·「대우웨딩홀」)은 **여전히 남는다** |

### C. ⬜ 지금 상태로 두고 잔여를 원장에 기록

가장 싸고, 나중에 배포를 판단할 때 근거가 남는다.
🚨 **그 상태로 학습에 들어가면 되돌릴 수 없다** (D-71 — 섞인 뒤에는 어느 줄이 어디서
왔는지 모른다).

## 4. 제 권고 — **B + 잔여를 세는 것을 짝으로**

A 가 닫혔으므로 남는 것은 B 다. 다만 **B 하나만으로는 안 된다.**

```
B      법인격이 붙은 자리를 전부 [업체] 로          ← 커버리지를 올린다
+ 잔여  residual_orgs() 로 남은 것을 세고 원장에 적는다  ← 「됐다」로 읽히는 것을 막는다
```

🚨 **B 는 반쪽이다.** 「(주)창연실업」은 잡지만 두 번째 언급의 「창연실업」은 못 잡는다.
   `redistributable: true` 라 공개 배포까지 가는 데이터에서, 반쪽을 「됐다」로 읽는 것이
   오늘 문서 전체를 통틀어 제일 위험한 자리다.
★ 그래서 **지우는 것과 세는 것을 한 짝으로 넣는다.** 세는 쪽이 없으면 커버리지가
  올라간 만큼 안심하게 되고, 안심한 만큼 확인을 안 하게 된다.

### ✅ 2026-09-07 — 판정 (판정자: 오한빈 / 권소라)

**1. 업체명은 제3자를 포함한다.**
문언 논거(같은 문장에서 주소만 「피심인」으로 한정)에 **목적 논거**가 더해진다 —
같은 날 2인 확인 **판정 B** 에서 확인했듯 **화장품법 제28조의2** 는 「처분 대상자의
명칭·주소 및 대표자 성명」을 공표 항목으로 **명시**한다. 즉 **법이 공표를 예정한 것은
처분 대상자뿐**이고, 제3자는 공표 이익이 없다. 🚨 **제재 대상이 아닌 회사를 우리가
배포하는 데이터에 남길 근거가 없다.** 문언과 목적이 같은 방향이다.

**2. 주소는 「피심인 주소」 한정이 옳다.**
같은 조문이 주소를 **처분 대상자**의 항목으로 열거한다. 사양이 주소만 한정한 것은
우연이 아니라 정합적이다. 본문의 모든 주소로 넓히지 않는다 — 잔여 상위의 「서울」
1,622건은 대부분 관할·소재 서술이라 지우면 문장이 상한다(`mask_address` 가 시·도
단독을 이미 통과시킨다).

**3. 상표는 `mfds` 제품명과 다르게 본다.**
`ftc` 의 상표는 **영업표지**(「청년피자」·「에듀플렉스」)이고 `mfds` 의 제품명은
**판정 대상**이다. `mask_brand` 가 이미 앞말(영업표지·상표·서비스표·상호)을 요구해
**따옴표만 보고 지우지 않는다** — 인용된 위법 문구(「'바르는게 운동입니다'」)가 살아남는다.
🔄 2026-09-07 census 실물이 이 설계를 뒷받침한다: `'초유함량 국내 최대'`·
`'진짜 진간장을 찾아라'` 는 광고 문구이고 `'더스테이트몰'` 은 영업표지다.

## 5. 이 문서가 하지 않은 것

⛔ **`use` 와 `masking` 을 안 보고 하루를 짰다.** 초판이 §2 를 「확인 필요」로 둔 것 자체가
   순서가 뒤집혔다는 증거다 — 그건 결정 요청 사항이 아니라 **작업 시작 전에 읽었어야 할 것**이다.
   🚨 오늘 같은 모양의 실수가 여럿이었다(`가처분`⊂`허가처분` · 크기로 동일성 판단 ·
      2건으로 8,253건 추정). 전부 **원본을 안 보고 판단한 것**이다.

🚨 **6,244종은 오탐이 섞인 하한이다.** 지명(서울 1,622)·역할어(수급사업자 342)가 남아 있다.
   진짜 회사명이 몇 종인지는 **세지 않았다** — 「수천 종」이라는 규모만 확실하다.

🚨 **주소를 어떻게 할지 안 정했다** (§1-5). 사양에 없는 항목이다.

⬜ **공동 피심인 나열**(「A 및 B의 …」)은 앵커를 쪼개면 잡히지만 안 고쳤다.
   §3 의 방향이 정해지기 전에 고치면 버려질 수 있다.
