## 상황

D-293 은 산문 행정규칙(공정위 고시 · 지침 8 종과 36814 「식품등의 표시기준」 본문)에 원문 번호로 좌표를 주되 「경로가 문서 안에 하나뿐일 때만」 주기로 했다. 근거는 산문 노드 909 중 164(18%)가 같은 경로를 두 번 이상 가진다는 실측이었다(맥락 3 · 36814 162 · 34717 2).

원문 XML 로 다시 재니 **그 겹침은 원문 구조가 아니라 파서 결함**이었다.

1. **목 글자표가 「하」에서 끝난다** (`preprocess/law_norm.py` `JO` · 짝 `app/retrieve.py` `_JO`). 「하.」 다음의 「거. 너. 더. …」를 마커로 못 읽고 앞 항목 본문에 붙인다. 36814 의 「Ⅱ.1.하.1.가」는 원문의 「Ⅱ. 1. 거. 1) 가)」다. `PENDING_ALLOWED` 주석에 적힌 원문 번호(「Ⅲ. 1. 자. 2) 거) (2) (나)」)와 지금 경로(「Ⅲ.1.자.2.하.(2).(나)」)가 어긋나는 것도 이 때문이다
2. **마커 바로 뒤에 「 가 오면 못 읽는다** — 정규식이 띄어쓰기를 요구한다. 「3.「중요한 표시ㆍ광고사항 고시」와의 관계」(38124) · 「차.「식품위생법」…」(36814) 가 앞 항목에 붙는다
3. 같은 결함이 이미 좌표가 서는 별표에도 있다 — 013475 [별표 4]제1호하목(「거~커」목을 안음 · dev 749 행 중 23 행에서 화면 참고 조문으로 노출) · 008741 [별표 1]제3호나목3)(띄어쓰기 없는 「4)시장출하」를 안음 · 노출 0)

두 결함을 고치면 36814 의 겹침이 사라진다. 남는 겹침은 34717 하나다 — 본문 안의 열거가 상위와 같은 꼴 「1.」을 써서 형제 번호가 1…10 뒤에 다시 1, 2 로 간다. 원문 구조라 파서로 가를 수 없다.

- 전제 수 — 36814 겹친 노드 371 → 0 · 34717 겹친 노드 4 (원장 10-12 ③ · 클론 B 원문 XML 시뮬레이션 · 게이트 아님 · 이후 재측정 없음)
- 전제 수 — 파서 수정으로 바뀌는 별표 단위 37 중 2(013475 [별표 4] · 36122 [별표 2]) · 공정위 고시 · 지침 8 종의 모르는 마커 0 (같은 조건)

## 용어

- **경로**: 청크 `paragraph` 칸의 원문 번호 사슬 — `Ⅱ.2.나.(1)`
- **형제 순서 검사**: 같은 부모 아래 같은 꼴(숫자 · 가나다 · 원문자) 형제의 번호가 오르는지 보는 검사
- **삼킴**: 한 항목이 다음 항목의 줄을 본문으로 안은 것 — 다음 번호가 빠져 보인다

## 안건 1 — 맥락 3 의 정정과 결론의 조건

- D-293 맥락 3 을 정정한다 — 「겹친 164 는 파서의 목 글자표(가~하) 결함에서 왔다. 고치면 36814 는 0 이고 34717 의 같은 꼴 열거만 남는다」
- 결론의 조건을 넓힌다:

| 안 | 얻는 것 | 떠안는 것 |
|---|---|---|
| (가) 유일 조건만 그대로 | 바꿀 것이 없다 | 같은 꼴 열거가 1 부터 다시 시작하지 않거나 마지막 항목을 삼킨 경우는 겹치지 않아 유일 조건을 통과한다 — 틀린 좌표가 선다 |
| (나) ★ **유일 조건 + 형제 순서 검사** | 지금 상태에서 겹침 ⊂ 순서 깨짐이었다(371 ⊂ 397 · 4 ⊂ 18). 겹치지 않는 결함도 잡는다 | 칸 하나와 마이그레이션이 든다(0021 과 같은 꼴) |

**순서 검사 규칙** (다듬은 판)
- 번호가 되돌아가거나 겹치면 → 그 형제 묶음 전체의 좌표를 세우지 않는다
- 번호가 비면 → 앞 노드가 빈 번호의 줄머리 마커를 본문 줄로 안고 있을 때만 그 노드의 좌표를 세우지 않는다. 원문 자체의 빈 번호(36122 독성시험법 「5.」 아래 「나.」 없음)와 원문이 이어 매긴 번호(36122 「(2)」 아래 「(바)」부터)는 통과한다
- 결과 — 파서 수정 뒤 산문 18 노드(34717 `Ⅲ`) · 표 아닌 별표 1 노드(008741 `3.나.3`)가 좌표를 잃는다. 조문형 법령은 호 묶음 245 에서 깨짐 0 이라 걸지 않는다

## 안건 2 — 산문 좌표의 모양

- (가) 경로 그대로 `Ⅱ.2.나.(1)` — 「1.」과 「1)」이 둘 다 `1` 이 된다(36814 는 둘을 다 쓴다)
- (나) ★ **꼴 보존** — 파서는 읽는 순간 꼴을 안다. 산문 경로를 적는 한 줄만 바꾼다. 산문 청크 ID 는 경로를 쓰지 않아 ID 가 안 바뀐다. 별표 경로는 건드리지 않는다

## 안건 4 — 산문에도 「광고」 규칙을 넓히는가

참고조문 별표 허용규칙 초안의 (나)(위임 근거에 「광고」)를 산문에 넓히면 공정위 8 종은 모두 남고(「표시ㆍ광고」가 이름에 있다), 36814 「식품등의 표시기준」 본문은 빠진다.

- (가) 넓히지 않는다 — 36814 본문(표시 의무 · 영양 강조 기준 등)도 참고 조문 후보다. 영양 강조 광고(「무」 「저」 「고」)와 이어진다
- (나) 넓힌다 — 표시 기준이 광고 참고 조문을 차지하지 않는다
- 추천: **(가) 로 두고 재측정 뒤 다시 본다** — 36814 본문은 지금 코드에서 좌표가 없어 화면에 오르지 않는다. 집행 뒤 화면 탐침으로 무엇이 오르는지 보고 정한다
