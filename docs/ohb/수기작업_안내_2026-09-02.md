### 🚨 착수 전에 반드시 읽을 것

- **`meta_adlibrary` · `google_atc` 는 자동 수집이 약관 위반입니다.** 스크립트·확장프로그램·매크로
  **전부 금지**입니다. 레지스트리에 `status: manual` 로 박혀 있고, 수집기와 탐침 둘 다 거부합니다 (D-108).
- 🚨 **`meta_adlibrary` 는 아직 착수 조건이 안 섰습니다.** 실제 용도가 `test_holdout`(평가)인데
  용도 축 `U1`~`U4` 에 **평가가 없고**, G2(원문 미보관)와 골든셋 원문 보관이 **정면 충돌**합니다.
  **먼저 결정하고 옮기십시오** — 200건 옮긴 뒤 못 쓰게 되는 것이 가장 아깝습니다.
- 옮길 항목: 본문 카피 전문 · 헤드라인 · CTA 버튼 텍스트 · 랜딩 URL · 게재 기간.
- 🚨 **`kcia_guideline` 은 「표현 목록만」 취합니다.** 해설 문장·편집·배열은 협회 저작물입니다.
- 🚨 협회 공지 페이지에 **이용조건 문구가 없습니다** (2026-09-02 탐침). 문의 회신이 오면 재판정합니다.

## 부록 — 자주 나오는 질문

**Q. 그냥 스크립트로 긁으면 안 되나요?**
④의 두 건은 **약관이 금지**합니다. 나머지는 금지가 아니라 **로그인·승인이 사람을 요구**하는 것이라
자동화할 대상이 없습니다.

**Q. 왜 승인 전에는 열어보지도 못하나요?**
신청·승인 자체가 **접근의 조건**이기 때문입니다. 「받아서 지우는 것」과 「받지 않는 것」은 다릅니다.
탐침(`python launcher.py probe`)은 저장을 하지 않지만 **접근은 하므로** 같은 조건에 걸립니다 (D-109).

**Q. 내가 받은 데이터를 그냥 저장하면 되나요?**
🚨 **아닙니다.** `reviewed_by` 가 비어 있으면 수집기가 거부합니다 (D-66 · 게이트 15).
**S0-14 2인 확인 31건이 아직 0건**입니다 — 그것이 지금 전체를 막고 있습니다.

**Q. 확인해서 조건이 달라지면요?**
그것이 **이견**입니다. `reviewed_by` 를 비워 두고 `reviewed_at` + `dissent_note` 만 적어 주십시오.
팀장이 재판정합니다. **동의만 찍는 검토는 게이트가 아닙니다.**
