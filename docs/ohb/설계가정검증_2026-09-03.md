## ① 🚨 적법 라벨이 위법 라벨과 같은 분포에서 오는가 — **9/8**

### 왜 의심하는가

기획서 4-3 이 적어 둔 2층 소스 3종의 **실제 상태**가 이렇다.

| 기획서가 적은 것 | 지금 |
|---|---|
| ★ 기능성표시식품 심의완료 공개목록 — *"실제 심의를 통과한 **광고 문구** 100건+"* | 🚨 **`kfia_approved_list` G1 배제** (D-110) |
| 대한화장품협회 해설서 2025 | `kcia_guideline` G2 · **미서명** |
| 건기식 승인 기능성 문구 | `mfds_hf_ingredient` · `mfds_hf_individual` G3 ✅ — **각 1장만 수집** |

**소스가 죽은 것이 아니라 성격이 바뀌었다.**

```
위법 라벨  ←  공정위 결정문의 광고 원문       = 긴 문장 · 마케팅 문체
적법 라벨  ←  원료 기능성 표현 · 해설서 예시   = 짧은 조각 · 규정 문체
```

🚨 **두 클래스가 같은 분포에서 오지 않으면 모델은 「위법 vs 적법」이 아니라 「긴 광고 문장 vs 짧은 규정 문구」를 배운다.** 골든셋에서는 점수가 잘 나오고 실제 광고에서 무너진다.

### 어떻게 재는가

★ **길이만으로 분류기를 만들어 본다.** 문장 길이(+간단한 표면 특징)만 쓰는 로지스틱 회귀로 위법/적법을 가른다.

| 결과 | 뜻 |
|---|---|
| 정확도가 **높다** | 🚨 **지름길이 존재한다** — 인코더가 내용이 아니라 형태를 배울 수 있다 |
| 정확도가 **낮다** (≈ 무작위) | 분포가 겹친다 — 가정 성립 |

보조 지표: 문장 길이 분포 · 어휘 중첩률 · 종결어미 분포.

### 아니라고 나오면

1. ★ **`ftc_noviolation`(공정위 무혐의·심의절차종료) 판정을 앞당긴다** — 현재 `G0 · hold · 전 용도 deny`.
   🚨 **이것이 살아나면 같은 문서·같은 문체의 적법 라벨이 생긴다.** 5-3 표에도 *"(확인 시) 공정위 무혐의 결정"* 으로 이미 적혀 있다. **1번 검증의 자연스러운 해법이다.**
2. **결함 주입 골든셋 비중을 올린다** (D-25) — 같은 문장에서 위법/적법 쌍을 만들면 분포가 정의상 같아진다.
3. 그래도 안 되면 **5-3 클래스 균형 절을 다시 쓴다.**

**담당 이서은** · 데이터 `data/derived/ftc_layer1_triage.json`(737건) + 2층 실물

## ② 위험도가 4단계로 갈리는가 — **9/8**

### 왜 재는가

사실원장 「판정 축」이 **위험도 4단계 순서형**(형사 리스크 / 과징금 / 업무정지 / 주의)으로 확정돼 있다. 이 값은 **행정처분 기준 [별표]에서 나온다.**
🚨 **D-40** — 유형별 표본 30건 미만이면 「측정 불가」다. **4단계 중 30건에 못 미치는 단계가 있으면 4단계가 아니다.**

### 어떻게 재는가

`data/derived/law_annex/` **387행**에서 처분 축 값 분포를 센다. 단계별 건수 · 카테고리별 교차.

### 아니라고 나오면

- 단계를 **축소**한다 (예: 3단계) → **순서형 헤드 출력 차원**이 바뀌고 **화면 배지 수**가 바뀐다
- 즉 **판정 표시 계약(①)의 입력값**이다. 이것 없이 배지를 그리면 다시 그린다

**담당 소성민** · 데이터 `data/derived/law_annex/` (387행)

## ③ 위법 유형별로 30건이 나오는가 — **9/10**

### 왜 재는가

발표 핵심 지표 1번이 **「위법 유형별 Recall」**이다. 유형의 절반이 「측정 불가」면 지표가 기능하지 않는다 (기획서 2-4 ①).
그리고 **9/17 범위 확정(D-65)의 입력값**이다.

### 어떻게 재는가

1층 **737건**의 사건명·결정요지에서 행위유형을 분류하고 유형별 건수를 센다. **30건 이상인 유형이 몇 개인가.**
※ 기사형 제재 사례 건수(WBS 2.9)도 같은 작업에서 나온다.

### 아니라고 나오면

- 유형을 **묶거나 줄인다** → 9/17 범위 확정에 그대로 들어간다
- 🚨 **유형이 줄면 평가 표가 줄고, 발표 지표가 얇아진다.** 미리 알아야 대응할 시간이 있다

**담당 권소라** (S0-14 종료 후) · 데이터 1층 737건

## ④ 금지 표현 사전의 오탐률 — **9/10**

### 왜 재는가

D-123 이 **오탐을 네 종류로 갈랐다.** 그런데 **각 종류가 실제로 얼마나 나오는지는 모른다.**
🚨 「사전 패턴 정교화」로 가는 몫이 크면 그건 **개발 작업량**이고, 「보류」로 가는 몫이 크면 **제품 성격**이 바뀐다.

### 어떻게 재는가

사전 초판 **100 어휘**를 2층 적법 문구에 돌려 **FP 를 센다.** 걸린 사례를 D-123 의 4분류로 나눈다 —
`주입 슬롯` / `부정형 정형 문구` / `문맥 의존` / `추출 오류`.

### 아니라고 나오면

- 사전 패턴 재작업 규모가 나온다 → **사전 갱신 계약(③)의 입력값**
- 오탐이 아주 적으면 **오버레이 자체가 급하지 않다** — 우선순위를 내린다

**담당 박수진** (요구사항 v3.2 종료 후) · 데이터 사전 초판 100어휘 × 2층 실물

## ⑤ 경계 클래스가 얼마나 되는가 — **9/10**

### 왜 재는가

5-3 이 *"실무의 상당수가 경계에 속하고, **이것이 곧 Abstention 의 근거**"* 라고 적었다. **「상당수」가 몇 %인지는 아무도 모른다.**
보류 비율이 높으면 제품이 *"판정해 준다"* 가 아니라 *"많은 경우 보류한다"* 가 된다 — **발표 서술이 바뀐다.**

### 어떻게 재는가

1층 **C′ 208건**(전상법만 · 경계 사례로 남겨 둔 것) + 실증 필요 표현(표시광고법 제5조) 해당 비율을 추정한다.

### 아니라고 나오면

- 보류 비율이 높다 → 🚨 **그것을 약점이 아니라 제품 정의로 서술한다** (기획서 2-3 — *"모르면 모른다고 답한다"*)
- 보류 비율이 낮다 → Abstention 경로의 실증 표본이 부족하다 → 골든셋에 경계 케이스를 심는다

**담당 이서은 · 소성민** (①② 종료 후) · 데이터 1층 C′ 208건

## 이 배치가 푸는 것

**2W 에 이서은·소성민이 비어 있었다.** WBS 를 사람 기준으로 읽었을 때 드러난 공백이다.
다섯 검증이 그 자리에 들어가고, **팀장이 harness 를 만드는 동안 팀원이 데이터를 잰다.** D-94(구조는 한 사람, 측정은 분배)와 같은 형태다.

> 🚨 **화면은 지금 고치지 않는다.** 위 다섯이 나오면 **무엇을 고쳐야 하는지가 데이터로 정해진다.** 지금 고치면 팀원이 두 번 고친다.
> 다만 **범위는 데이터와 무관하다** — 매칭 7화면·백오피스 60화면은 기획서에 근거가 없으므로 **9/8 MVP 범위 승인은 예정대로 간다.**
