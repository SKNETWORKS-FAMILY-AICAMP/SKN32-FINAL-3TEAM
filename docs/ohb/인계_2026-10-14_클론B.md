2. **측정 요청을 원장 확인 없이 냈다** — 카드 17 그래프 · D-293 뒤 검색 재측정은 원장 10-13(A) ④ · 10-13(B) ① 에 이미 있었다
3. **합의 확정을 유형 정확도만 보고 권했다** — 확정이 되면 유형이 불가 사유 → 종착(증명서 · 지시)을 정한다. 사유 불일치(26%)까지 재고 (가) → (다) 로 바꿨다
4. **리랭커 「닫기」를 D-77 · D-84 ③ 확인 없이 권했다** — 「유형으로 좁힌 검색 뒤 다시 판정」으로 고쳤다
5. **기기 셸에서 git 을 두 번 실행했다**(`git diff --stat` · `git check-ignore`) — 읽기뿐이었지만 「git 은 팀장이 친다」와 어긋난다
6. **사실원장 끝에 빈 줄을 하나 더 써서** 커밋 전 검사(파일 끝 정리)가 커밋을 멈췄다 — 끝은 줄바꿈 하나

8. 🔄 **「17 행이 사실 주장」으로 범위를 넓게 보고했다** — 실증 고시 Ⅲ.3.② · Ⅱ.1 을 펴 보니 원재료 비율 · 전문 기관 표방은 일반 실증 문안이 맞았다(11 로 정정). 조문을 먼저 편다
9. 🔄 **(다) · (라)(사실 확인 분기)를 「설계가 정한 정답」으로 냈다** — 사실 확인 분기의 종류는 식품 별표 근거였고 표시광고법 축은 실증 대상이었다
