## §4 🔴 사고 둘

### ① `register` 가 원문을 딴 폴더에 넣었다 (D-245)

```
클로드가 준 절차:  register law_go_kr <파일> --use U1
cmd_register:      store.raw_dir(source_id) → data/raw/law_go_kr/
추출기:            data/raw/law/ 를 본다
결과:              화장품법 334노드가 사라졌다 (law_article 2,207 → 1,873)
신호:              없다. 게이트 337개 전부 초록. doctor 도 조용.
```

- **원인 둘** — ① 소스 id ≠ 원문 폴더인 소스가 **넷** ② 같은 매핑이 `inventory.ALIAS` 에 **따로** 있었다
- **내 몫** — `cmd_register` 의 docstring 이 *「`data/raw/<소스id>/` 로 복사하고」* 라고 **적어 두었는데도**
  나는 **읽는 쪽이 그 폴더를 보는지 확인하지 않았다.**
- **복구** — `Move-Item` 으로 판 이름을 붙여 `data/raw/law/` 로 옮기고 `adopt`. 조문 노드 **2,207 / 20건** ·
  `doctor --data --hash` 🔴 **0**
- ⬜ **「초록불인데 데이터가 사라진다」를 잡는 게이트가 없다** — 조문 노드 수의 **하한 래칫**이 후보다

### ② D-218 재발 — 「written」 응답과 옛 사본

```
1차 커밋   응답 written · 기기 89,262 B   ← 내 편집 5줄과 개행 게이트 85줄이 둘 다 없는 더 옛 판
```

- ⛔ **꼬리 절단이 아니다** — 파일 중간(336~340행)도 없었으므로 **옛 사본**이다
- ★ **2차가 같은 경로로 통했다** — 「새 경로만이 해법」은 아니다. 규칙은 **예방으로** 유지한다
