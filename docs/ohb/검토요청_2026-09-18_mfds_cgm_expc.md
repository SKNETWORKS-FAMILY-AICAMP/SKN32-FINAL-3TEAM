## 0. 무엇인가

**법제처 국가법령정보 「중앙부처 1차 해석」 중 식품의약품안전처분** — 민원 질의와 식약처 회답.
원본은 식약처 민원인안내서 「자주하는 질문집」(`m_1060`) 이고, 법제처가 공공데이터로 모아 연다.

| | |
|---|---|
| 접근 | 법제처 DRF OPEN API · `lawSearch.do?target=mfdsCgmExpc` (**2026-09-18 확인**) · 키는 기존 `LAW_OC_KEY` |
| 필드 (화면 · 본문 2건) | 제목 · 해석기관 · 해석일자 · 출처(책자명) · **【분류】** · 【질의요지】 · 【회답】 · 【관련법령】 |
| 층 (제안) | **1층 판정라벨** (+ 조건부 적법 사례) · ⛔ **3층 금지** — 화면 안내 「법제처 판단이 아니다 · 폐지·변경된 해석도 포함」 (D-138 선례) |

**왜 필요한가** — 두 건의 본문이 우리가 막혀 있던 자리에 **기관의 말**을 준다.

1. 「항균」은 **인체세정용 제품 + 인체적용시험 입증**일 때만 · 기초화장용 불가
   (인용 규범 「화장품 표시ㆍ광고 관리 지침」[별표 2] 는 **우리 코퍼스에 없다** — 법제처에 없는 민원인 안내서)
2. 「피부 장벽 기능 회복 · **가려움** 개선 기능성화장품」 + 「의약품이 아님」 → **심사 · 보고 효능 그대로면 표시 가능**
   — 같은 표현이 **제품 지위로 적법 ↔ 위반이 갈린다** (D-242 · `결정요청_2026-09-17_화장품축.md` §11)

⛔ **부족한 위반 유형(질병 · 비방 · 후기)을 채우는 원천은 아니다** — 제목 표본 100건에서 식품 쪽 질병 표방 0.

## 6. 마스킹 · 시점 · 중복

**마스킹 (제안)** — 질의요지에 업체명 · 제품명이 섞일 수 있다.
- 본문 2건에는 **없었다.** ⬜ 표본을 더 보고 정한다
- 제안: `org` 축 켬 · `person` 축 켬 · **제품명은 가리지 않는다** — 제품명이 곧 판정 대상 표현일 수 있다 (`mfds_press` 에서 `person` 을 끈 것과 같은 이유 · D-157)

**시점** — `해석일자` 를 **필수 필드**로 둔다. 화면 안내가 「당시 법령 기준 · 폐지·변경된 해석 포함」이라 적는다.
판정에 쓸 때 **현행 규정과 대조**한다 (D-138 과 같은 성격).

**중복** — 수집 원장(`data/manifest.jsonl`)과는 **0** (미수집). 원천 사이 —
- `foodsafety_faq` (hold) — 같은 식약처 FAQ 일 수 있다 ⬜ 대조 안 함
- 원본 책자 `m_1060` 안내서-1392 · 1395 · 1460 · 1463 — 법제처에 2026-08-26 해석까지 있어 **책자보다 넓을 수 있다.** 책자는 등재하지 않고 **누락 대조용**
