### `user_ad_preference` (선택 · 1:1)

lse 안 그대로 — `age_range` · `sex` · `channel` · `category_default`.
🚨 **이것은 회원의 인구통계가 아니라 「광고가 겨냥하는 대상」의 기본값이다.** D-68 이 기각한 것은 *「회원 성별·연령대로 맞춤 광고 제시」* — 회원 자신의 값이다. 칸 이름을 `target_age` · `target_sex` 처럼 **대상임이 드러나게** 바꾸기를 권한다. 헷갈리면 D-68 을 어긴 것으로 읽힌다.
`category_default` 는 판정 입력이 아니다 — 판정 카테고리는 우리가 판별한다(D-82). 판정 코드가 이 칸을 읽지 않는다는 게이트를 붙인다.
⬜ 마이페이지 「광고 기본값」을 이번에 안 돌리면 이 표는 뒤로 미룬다.

## 6. 쓰기 경로와 게이트

### 6-1. 관리자 쓰기 — 게이트를 허용 목록으로

지금 `tests/test_auth_boundary.py` 는 **`app/routers/admin.py` 한 파일**에서 `@router.post|put|patch|delete` 를 찾는다. 바꾸는 모양:

```python
#: 관리자 쓰기 허용 목록 — D-260 ⑦. 파일 → 허용하는 (메서드, 경로) 집합.
#: 🚨 여기 없는 파일·경로의 쓰기는 🔴. 거버넌스(admin.py · 등급 · 2인 확인)는 비어 있다.
ADMIN_WRITES = {
    "admin_board.py": {("POST", "/notices"), ("POST", "/notices/{notice_id}")},
    "admin_terms.py": {("POST", "")},
    "admin_cs.py": {("POST", "/tickets/{ticket_id}")},
}
WRITE_CLOSED_REASON = "거버넌스 쓰기(등급 변경 · 2인 확인 서명)의 절차가 미판정이다 (D-66 · D-260 ⑦)"
```

게이트가 보는 것 셋 —
1. `app/routers/admin*.py` **전부**를 훑는다(맥락 5의 사각). 구문 트리로 데코레이터를 읽는다 — 문자열이 아니라.
2. 허용 목록에 있는 쓰기 핸들러는 **본문에 `require_governor` · `csrf_ok` · `audit` 셋을 부른다** — 셋 중 하나라도 없으면 🔴.
3. 반대 대조 — 허용 목록 밖 경로 · 셋 중 하나를 빠뜨린 핸들러를 넣은 가짜 파일에서 🔴 가 나는지.

`test_막는_이유가_낡지_않았다` 는 그대로 둔다 — 문구에 「인증」이 없고 20자 이상이면 통과한다.

### 6-2. 사용자 쓰기

| 경로 | 무엇 | 지키는 것 |
|---|---|---|
| `POST /u/signup` | `user_account` 1행 | 이메일 정규화 · 비밀번호 Argon2id · 약관·면책 동의 필수 · 선택 동의 ①② 기본 해제 · CSRF · 시도 제한(`auth._Throttle`) |
| `POST /u/login` · `POST /u/logout` | 세션 | 아래 6-3 |
| `POST /u/mypage` | 이름·소속 · 선택 동의 ①② · (광고 기본값) | 로그인 필수 · **본인 행만**(P1-5 IDOR) · 이메일·비밀번호 변경은 이번 범위 밖 |
| `POST /u/cs` | `ticket` 1행 | 로그인 필수 · 본문 상한 · `read_capped`(본문 상한 · 보안점검 P2-11) |

🚨 지금 `user.py` 의 `POST /u/mypage` 는 **저장하지 않는다**고 적혀 있다(「가짜 성공을 그리지 않는다」 · D-147). 저장을 붙일 때 그 문구를 같이 바꾼다.

### 6-3. 세션 — 판정 필요 (`app/auth.py` 는 팀장 소유)

| 대안 | 얻는 것 | 떠안는 것 |
|---|---|---|
| (가) ★ **서명은 같은 함수, 쿠키는 따로** — `copylane_user` 쿠키 · 값은 `u:<uuid>` | 관리자 세션과 사용자 세션이 섞이지 않는다 — 사용자 쿠키로 관리자 화면을 못 연다 · 서명·만료 코드는 한 벌(D-99) | `read_session` 이 접두어를 가른다 — 게이트로 「`u:` 세션은 `require_governor` 를 못 지난다」를 잰다 |
| (나) 쿠키 하나에 역할 칸 | 코드가 짧다 | 역할 칸을 읽는 곳 하나가 빠지면 사용자 세션이 관리자 문을 연다 |

### 6-4. 에디션

관리자 화면은 **관리자 에디션에만** 붙는다(D-213 — 클라우드에선 404). 사용자 가입은 D-66 대로 클라우드 쪽 흐름이다.
데모는 한 기기에서 둘을 같이 띄운다 — 같은 DB 를 본다. ⬜ 실제 배포에서 두 에디션이 **같은 `user_account` 를 보는지**는 D-79(배포 경계)와 같이 정한다 — 이 초안 밖.
