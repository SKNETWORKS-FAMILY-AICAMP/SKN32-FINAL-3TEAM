# S0-17 실측 — 공정위 결정문 도메인·연도 분포 (2026-09-02)

> 인계 §4-ⓑ / `수집리스트.md` S0-17 의 **a · c잔여 · d** 를 한 번에 잰 기록.
> 수단: 법제처 국가법령정보 FTC 결정문 API, **문서화된 샘플 계정 `OC=test`, 읽기만.**
> 저장하지 않았고 수집기를 돌리지 않았다 (D-109 탐침과 같은 성격).
>
> 🚨 **정식 `LAW_OC_KEY` 로 재검증할 것.** 샘플 계정 기준 숫자다.
> 🚨 **모집단이 `ftc_decisions`(파일데이터 15103301, 5,870건)와 다르다.** 이 API 는 **8,255건**이고
>    연도가 **2006~2026** 이다. 두 경로의 숫자를 같은 것으로 세지 않는다.

## 0. 한 줄

**표시광고 관련 1,087건. 그중 우리 도메인(화장품∪건기식)은 91건.**
「2000년 신문·잡지뿐」이라는 걱정은 **모집단 착오**였고, 실제로는 **온라인 광고가 절반**이다.
대신 새 위험이 하나 나왔다 — **건기식은 2023년 이후 0건**이다.

## 1. 검색 방식

```
GET https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=ftc&type=XML
    &search=2          ← 본문검색 (1=사건명)
    &query=<질의>       ← 🚨 공백으로 나열하면 AND 로 동작한다 (실측 확인)
    &display=100&page=n
```

**AND 동작 근거** — `화장품` 195 · `표시광고` 1,087 인데 `표시광고 화장품` 은 **54**다. 둘 다보다 작으므로 교집합이다.

🚨 **가운뎃점은 깨진다** — `부당한 표시·광고` 는 **0건**을 낸다. 질의어에 `·` 나 조사를 넣지 않는다.

## 3. S0-17-c 잔여 — 도메인별 (「몇 건인가」)

| 도메인 질의 | 표시광고 AND | 도메인 단독 |
|---|---:|---:|
| `화장품` | **54** | 195 |
| `건강기능식품` | **42** | 99 |
| `식품` | **113** | 526 |
| `화장품` ∩ `건강기능식품` ∩ `표시광고` | **5** | (`화장품`∩`건강기능식품` = 31) |

### ★ 우리 도메인 = 54 + 42 − 5 = **91건**

주변 표현까지 넓히면 더 있다 — `건강식품` **63** · `건강보조식품` **10** · `다이어트` **14** · `기능성화장품` **2** · `의약품` **44**. 🚨 **합집합은 재지 않았다** — 이 API 는 OR 를 지원하지 않아 정확한 합집합은 **본문을 받은 뒤에** 세는 것이 맞다. 추정치를 적지 않는다.

> 🚨 **91건은 상한이 아니라 「언급 건수」다.** 본문검색은 *그 단어가 나오는가*를 셀 뿐, *사건의 도메인이 무엇인가*를 세지 않는다. 비교 대상으로 화장품이 언급된 타 업종 사건이 섞인다. **실제 도메인 사건 수는 이보다 적다.**

### ✅ 「2000년 신문·잡지」 우려는 해소된다 — 모집단 착오였다

인계 §4-ⓓ 가 걱정한 의결 제2000-99호는 **파일데이터** 쪽 건이다. 이 API 모집단에는 **2000년 건이 아예 없고**(2006 시작), 화장품은 **2012년이 가장 오래된 건**이다.

매체도 확인된다 — 표시광고 1,087건 중 본문에 **`인터넷` 536건(49.3%)** · **`홈페이지` 447건(41.1%)** · **`온라인` 283건(26.0%)**. **온라인 광고가 절반**이다.

## 5. 🚨 새로 나온 것 — 건기식이 2023년 이후 비어 있다

`표시광고 건강기능식품` 은 2022년이 마지막이다. 사건이 없어서가 아니라 **관할이 옮겨 갔을 가능성**이 크다 — 건기식 부당광고는 식품표시광고법 소관이고, 최근 제재는 공정위 의결이 아니라 **식약처 행정처분**으로 나간다. (기획문서가 인용한 「건기식 부당광고 5년 22,948건(2025 국감)」이 공정위 의결서 42건과 자릿수가 다른 것이 방증이다.)

**따라서 `mfds_sanctions`(I0470)의 값이 올라간다.** 최근 건기식 라벨은 거기서만 나온다.
→ **S0-17-b 실측이 더 급해졌다.** `LAWORD_CD_NM` 이 「식품 등의 표시·광고에 관한 법률」인 건이 몇 건인지.

## 6. 1층이 서는가 — 판단 재료

| | 규모 | 성격 |
|---|---:|---|
| 도메인 무관 표시광고 | **1,087** | 3요소(거짓·과장 / 오인 / 저해) 다중라벨 학습에 충분 |
| 우리 도메인 (화장품∪건기식) | **91** | 🚨 학습에는 작다. 그중 실제 도메인 사건은 더 적다 |
| 온라인 광고 건 | **536** (49%) | 표현이 현재 이커머스와 가깝다 |

**서기는 선다. 다만 「도메인 특화 판정」을 91건으로 학습할 수는 없다.**
현실적인 모양은 — 1,087건으로 **일반 판정**을 배우고, 91건은 **평가·few-shot**으로 쓰고, 도메인 특화 표현은 2층(`kcia_guideline` · `mfds_hf_individual`)이 사전으로 댄다. 🚨 **이것은 제안이지 결정이 아니다** — 설계결정으로 올릴지는 팀장 판단.
