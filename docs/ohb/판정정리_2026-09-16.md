세 번째는 「평가」라기보다 **검증**이다. 어느 쪽이든 **학습도 인용도 배포도 아닌 용도**이고,
축이 없어 `cond` 로 표현돼 있다. 축 신설 때 **하나로 묶을지 갈라야 할지**가 판정거리다.

### ②-1 `mfds_sanctions` 54 의 소재 — **클론 A 에 있다**

```
원장 path 162 | 디스크에 있음 54 | 최신과 일치 54
없는 것: page_0001__c20260910.json · page_0002__c20260910.json …
```

클론 A 는 **base 54개만** 갖고 있고 그 54개가 **전부 원장 최신과 일치**한다. base path 의 최신
행은 09-08 이므로 **클론 A 의 base = 09-08 바이트** — 클론 B 가 낡았다고 나온 바로 그것이다.

| | base `page_00NN.json` | `__c20260910` | `__c20260914` |
|---|---|---|---|
| **클론 A** | ✅ 09-08 | ❌ | ❌ |
| **클론 B** | 🟡 09-06 | ✅ | ✅ |

⛔ **그런데 옮길 값이 크지 않다.** 클론 B 가 내용으로는 더 앞서 있다 — 09-10·09-14 판을 갖고
있고 빠진 것은 **09-08 이라는 중간 스냅샷 하나**다. doctor 의 🟡 54 는 「뒤처졌다」가 아니라
**「판 사슬에 구멍이 하나 있다」**는 뜻이었다.

- 얻는 것: doctor 의 🟡 54 가 닫히고 클론 B 의 디스크가 자기 원장과 일치한다
- 얻지 못하는 것: **더 새 데이터가 아니다**
- 옮긴다면 확인 둘 — ① 클론 B 의 base 54개를 **덮어쓴다** ② 원천 파일이 대화창을 거친다
  (`mfds_sanctions` 는 G3 공개 웹이라 AI Hub 금지 조항에는 안 걸린다)

**⬜ 낮은 우선순위.** 오늘 아무것도 이것에 의존하지 않는다.

### ③ `mfds_press_index.jsonl` 은 **원문 색인이 아니다**

```
행 4,349 · 칸 {no, title, qs, topic} · 평균 길이 qs 115.8 · title 33.9
```

본문을 담는 칸이 없다. **게시판 목록 = 수집 표적 목록**이다. 4,349는 게시물 수이고 받은 원문은
**210개**다. U2 를 쓰고 있다는 증거는 index 가 아니라 **원문 210 파일 보관 그 자체**다.
