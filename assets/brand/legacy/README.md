# CopyLane 브랜드 자산

> **작성: 오한빈 (팀장)** · SKN Final Project · 최종 갱신 2026-08-16

> 전체 규칙은 `CopyLane_브랜드가이드.html` 을 여십시오. 이 파일은 요약입니다.

## 컨셉

D-04에서 **차선이탈방지(LKAS) 은유가 설계와 한 몸**이라는 이유로 CopyLane을 택했습니다.
심볼은 그 논리를 그대로 씁니다 — **위·아래 두 개의 차선**과 그 사이에 놓인 **C**.
경계는 법령이 정하고, 문구는 그 안에서 움직입니다.

## 색 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `brand/ink` | `#0C1A2B` | 워드마크·본문·어두운 배경 |
| `brand/blue` | `#2B5BD7` | 심볼의 C, 강조 |
| `brand/lane` | `#A6B8D1` | 차선, 보조 요소 |
| `verdict/pass` | `#0F7B4F` | 통과 |
| `verdict/caution` | `#B45309` | 주의 |
| `verdict/violation` | `#B42318` | 위법 |

🚨 **`verdict/*` 는 판정 표시 전용입니다. 브랜드 요소에 쓰지 마십시오.**
로고가 빨강이면 화면에서 「위법」으로, 초록이면 「통과」로 읽힙니다.
브랜드를 파랑 계열로 잡은 이유가 이것입니다.

## 파일

| 파일 | 쓰는 곳 |

## 규칙 요약

- 여백은 사방으로 **심볼 높이의 0.5배** 이상
- 가로 조합형·심볼 단독 **최소 24px**. 그 이하는 파비콘 버전
- 워드마크는 **Poppins Bold를 패스로 변환**해 두었습니다 — 폰트 설치가 필요 없고
  폰트 라이선스가 산출물에 따라붙지 않습니다 (저장소 라이선스 보류 중 — D-60)
- 국문 「카피레인」 병기 금지 (D-04)
- 비율 변경·기울임·그림자·그라디언트 금지
