# CopyLane 브랜드 자산

> **갱신 2026-09-11** · 이전 판(파랑 계열)은 [`legacy/`](legacy/) 에 있습니다.

## 무엇이 바뀌었나

2026-09-11 에 **그라디언트 로고로 전환**했습니다. 중간 발표 자료가 이미 이 로고를 쓰고 있어, 저장소만 옛 브랜드에 남아 있는 상태를 정리한 것입니다.

🚨 **이 전환은 옛 가이드가 명시적으로 금지한 것 셋을 뒤집습니다.** 숨기지 않고 적어 둡니다.

| 옛 규칙 | 지금 | 왜 |
|---|---|---|
| 브랜드는 **파랑 계열** | 🔴 보라~핑크 | 옛 가이드의 근거는 *"로고가 빨강이면 「위법」으로 읽힌다"* 였다. 핑크(`#F3609B`·색상각 ≈340°)와 위법 빨강(`#B42318`·≈5°)은 떨어져 있어 혼동 위험은 낮다고 보았다 |
| **그라디언트 금지** | 🔴 그라디언트가 정체성 | — |
| **SVG 가 원본** · PNG 는 파생 | 🔴 **라스터가 정본** | 아래 「한계」 참조 |

⬜ **심볼이 더 이상 차선을 그리지 않습니다.** 옛 심볼은 *"위·아래 두 개의 차선과 그 사이에 놓인 C"* 로 D-04 의 LKAS 은유를 그대로 형상화했습니다. 새 심볼은 **말풍선(문구) + 체크(검수) + 세로 패널 + 스파클(생성)** 입니다. 이름과 이야기(「경계는 법령이 정하고 문구는 그 안에서 움직인다」)는 그대로지만 **그림이 그것을 보여 주지는 않습니다** — 의도된 것인지 팀장 확인이 필요합니다.

## 색 토큰

로고 원본에서 **실측**한 값입니다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `brand/violet` | `#5B2EBC` | `copy` · 심볼 왼쪽 · 본문 강조 |
| `brand/magenta` | `#DF56A8` | 그라디언트 중간 · 스파클 |
| `brand/pink` | `#F3609B` | `lane` · 패널 |
| `brand/lilac` | `#8667E8` | 말풍선 밝은 면 · 보조 |
| `brand/gradient` | `#542DB8 → #FC649E` | **좌 → 우.** 방향을 바꾸지 않는다 |

**판정 색은 그대로 둡니다** — 브랜드가 바뀌어도 이 셋은 안 건드립니다.

| 토큰 | 값 |
|---|---|
| `verdict/pass` | `#0F7B4F` |
| `verdict/caution` | `#B45309` |
| `verdict/violation` | `#B42318` |

🚨 **`verdict/*` 는 판정 표시 전용입니다. 브랜드 요소에 쓰지 마십시오.** 이 규칙은 옛 가이드에서 그대로 살아 있습니다.

## 파일

| 파일 | 쓰는 곳 |
|---|---|
| `png/lockup-horizontal.png` | **기본.** 밝은 배경 — 문서 헤더 · 웹 상단 |
| `png/lockup-horizontal-reverse.png` | 어두운 배경 |
| `png/lockup-stacked.png` · `-reverse.png` | 정사각에 가까운 자리 · 발표 표지 |
| `png/symbol-color.png` · `-reverse.png` | 심볼 단독 |
| `png/wordmark-color.png` · `-reverse.png` | 이름만 표기 |
| `png/favicon-16/32/48/180.png` | 브라우저 탭 · 앱 아이콘 |

`-reverse` 는 **밝기만 올린 판**입니다 (HLS 에서 L 을 +30%, 색상·채도 보존). 어두운 배경에서 보라색 `copy` 가 묻히는 것을 막습니다.

### 마크다운에서 테마별로 바꾸기

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/brand/png/lockup-horizontal-reverse.png">
  <img src="assets/brand/png/lockup-horizontal.png" alt="CopyLane" width="340">
</picture>
```

## 규칙

- 여백은 사방으로 **심볼 높이의 0.5배** 이상
- **최소 크기** — 가로 조합형 **160px** · 심볼 단독 **32px**. 그 이하는 `favicon-16.png`
- 비율 변경 · 기울임 · 그림자 · **그라디언트 방향 변경** 금지
- 국문 「카피레인」 병기 금지 (D-04)
- 로고를 **판정 결과 옆에 나란히 두지 않습니다** — 색이 판정으로 읽힐 수 있습니다

## 🚨 한계 — 라스터가 정본입니다

**벡터 원본이 없습니다.** 이 폴더의 PNG 는 1774×887 래스터 한 장에서 파생했습니다. 그래서 —

- **인쇄 · 대형 출력에 쓸 수 없습니다.** 가로 조합형의 실효 해상도는 1328px 입니다
- **파비콘 16px 은 축소 산물**이라 형태가 뭉갭니다. 작은 크기 전용 심볼이 따로 필요합니다
- 배경은 **채도를 기준으로 걷어냈습니다**(흰 배경과 섞이면 채도가 비례해 줄어든다는 성질). 휘도로 자르면 체크표시 안쪽 흰색이 뚫립니다
- 워드마크 서체를 모릅니다. 옛 판은 *"Poppins Bold 를 패스로 변환"* 이라 적어 둘 수 있었지만, 지금은 **글자를 다시 조판할 수 없습니다**

⬜ **벡터 원본이 생기면 정본을 SVG 로 되돌립니다.** 그때 `CopyLane_브랜드가이드.html` 신규판도 만듭니다 — 지금 만들면 라스터 기준으로 굳습니다. 옛 가이드는 [`legacy/`](legacy/) 에 그대로 있습니다.
