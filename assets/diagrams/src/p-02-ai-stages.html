AI 파트 — 단계별 입력과 출력

무엇이 들어가고 무엇이 나오는가 · [실측]/[기획] · 2026-10-06
[실측] 구현돼 있고 재 봤다 [기획] 아직 안 만들었다 ⚠️ 판정 대기 — 결론을 적지 않는다
단계 (코어 노드 순서)입력출력없거나 실패하면
① split · classify실측문장 분할 · 품목 원고 · 제품 정보품목은 주어진 값만 쓴다 문장 목록 · 보낼 법식품·건기식 2법 / 화장품 2법 품목 없음 → 미확정 · 법 셋 전부🚨 사용자 화면은 품목을 보내지 않는다
② retrieve실측조문 검색 · 한 번 문장벡터(KURE-v1) + 어휘(ts_rank_cd) 두 갈래 후보 — 법마다 폭만큼섞지 않고 나른다 (D-291) 두 갈래가 돌았는지를 값으로 남긴다「못 찾음」과 「못 돌림」을 가른다
③ match_dict실측금지 표현 사전 문장 · 사전단독판정 자격 항목 / 자격 없는 항목 적중 · 원문 좌표자격 없는 적중은 유형 후보로만 (D-311) 못 훑음 → 미판정「안 돌았다」≠「안 걸렸다」
④ encode기획빈 노드 문장 위반 유형 후보 · 신뢰도확정 클래스 8종 (D-321) 인코더 모듈은 저장소에 있으나 그래프에 미배선값을 지어 넣지 않고 그대로 넘긴다
⑤ 법별 노드 셋 · merge_laws실측팬아웃 – 팬인 (D-267) ②의 후보 · ③의 적중 자기 법의 근거 · 적중만표시광고법 · 식품표시광고법 · 화장품법 보낸 법이 다 돌아왔는지 대조한다건강기능식품법은 노드가 없다 — 참고 전용
⑥ judge실측규칙판 — 인코더 전 문장 · 법별 근거 · 적중 확정 · 보류 · 근거 없음 · 미판정확정에는 근거 조문 · 뺄 구간 · 불가 사유 사전에 안 걸린 문장은 보류 (D-269)통과로 내지 않는다
⑦ assess_risk실측위험도 하한 확정 위반 · 제재표서명된 행만 읽는다 위험도 R0~R3하한은 제재 별표에서만 (D-305) 위험도 없는 확정 → 종착은 보류⬜ 기준이 없을 때 무엇을 낼지 판정 대기
⑧ premise_branches실측품목 분기 (D-319) 문장 판정 · 전제 여섯 전제마다의 판정 + 기준 문안처음에 전부 계산한다 — 다시 판정하지 않는다 판정 못 하는 전제 → 보류 + 분기품목 미확정에는 통과 표시가 없다
⑨ doc_rules기획빈 노드 문서 전체 문서 경고 · 보류의무 문구 유무 등 —
종착 (검수)실측루프 없음 (D-266) 코어 출력 보류 > 증명서 > 지시 > 통과증명서 조립기 실측 · 지시는 기획 재료 없음 문안이 없는 조합 → 증명서가 아니라 보류인코더 전에는 종착이 거의 전부 보류다
생성 (진입점 B · C) — 그래프
생성 노드 여섯 — 빈 노드 기획 keyword_screen → assemble → claim_ledger → rejudge → frontier · search_failed 계약과 라우터만 있다 · POST /generate · /compose 는 501
규칙 조립 4종 · 재생성 루프 기획 삭제안 · 사실 진술 치환 · 인정 문구 슬롯 · 실증 유지 (D-264) 총 라운드 3 · 세 거부는 한 카운터 (D-126) — 생성 상태에만 있다
페르소나 · 세그먼트 · sLLM 다듬기 · 각색 기획 설계만 (D-270) · ⚠️ D-270 은 「전제 정정 · 결론 재검 대기」(10-06)
그래프 밖 — 검수 화면의 「이 문장 고쳐 쓰기」
10-06 에 병합됐다 실측 POST /u/review/rewrite → 로컬 sLLM 서버 (Qwen2.5-3B-Instruct + LoRA · 별도 가상환경) 돌아온 문구를 앱의 판정 코어로 다시 판정해 같은 화면에 그린다
그래프에는 들어오지 않았다 실측 검수 응답의 후보 목록은 비어 있다 · 자격형 문장과 유형 없는 문장은 보내지 않는다 서버가 없거나 응답이 깨지면 후보를 그리지 않는다
⚠️ 판정 대기 D-265(검수는 대체 문구를 내지 않는다) · D-270(sLLM 은 설계만)과의 관계 · 승인 범위(실사용 / 시연) 모델 레지스트리 등재 · 라이선스도 미정

RAG 는 사실 · 파인튜닝은 형식(기획서) — 법령 지식을 모델에 주입하면 없는 조문을 지어낸다. 조문은 검색이 나르고, 판정에는 근거 조문이 붙어야 확정된다.
