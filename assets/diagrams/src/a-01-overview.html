🔴 판정 시각에 외부 API 를 부르지 않는다. 근거는 미리 만들어 두고, 요청 때는 읽기만 한다 — 원천이 죽어도 검수는 돈다. 검색은 벡터 + 어휘(ts_rank_cd)를 RRF 로 섞은 한 순위다 (D-193) · 리랭커는 아직 없다.

⚠️ 고쳐 쓰기 — 검수 화면의 POST /u/review/rewrite 가 같은 기기의 sLLM 서버를 부르고, 고친 문구를 앱의 판정 코어로 다시 판정한다(2026-10-06 병합). 그래프의 생성 노드는 그대로 빈 노드다. D-265 · D-270 과의 관계와 승인 범위는 판정 대기다.

「설계상 있다」와 「지금 돈다」를 같은 글씨로 적지 않는다. 점선·회색은 아직 없는 것이고, 초록은 실측으로 확인한 것이다.
